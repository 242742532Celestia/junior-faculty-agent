请按下面的 JSON 结构输出一份**教学幻灯片规格**（spec）。

这份 spec 会被本仓库自研的纯标准库 PPTX 生成器直接渲染成 `.pptx`，
并被教学规范审查器逐页审查。所以下面每条格式约束都必须满足。

```json
{
  "meta": {"title": "课程标题", "author": "授课教师", "subject": "本次课题"},
  "slides": [
    {
      "layout": "title",
      "title": "封面标题",
      "subtitle": "副标题"
    },
    {
      "layout": "bullets",
      "title": "这一页要让学生知道什么",
      "bullets": [{"text": "要点", "level": 0}],
      "notes": "讲授者讲稿：这一页怎么讲、停顿在哪、问什么",
      "footer": "数字图像处理 · 第 4 章"
    }
  ]
}
```

字段说明：

- `layout` ∈ `title`（封面）/ `section`（章节过渡）/ `bullets`（要点页）/
  `two-column`（两栏对比页）/ `quote`（引述页）/ `image-focus`（图为主）/
  `blank`（空白页）。**没有 `image` 就不要用 `image-focus`。**
- `bullets` 是数组，元素可以是 `{"text": "…", "level": 0}`，`level` 0 为一级、1 为二级。
- `two-column` 的分栏规则：**level 0 进左栏，level 1 进右栏**。
- `notes` 是**讲稿**（给讲授者看），`bullets` 是**正文**（给观众看）—— 两者必须分开，
  不要把讲稿写进正文。
- `footer` 是来源标注页脚。

硬性要求（审查器会逐条判，ERROR 级必须改）：

1. **封面只能有一个**，且必须在第 1 页（`layout: "title"`）；章节过渡用 `section`。
2. 每个正文页（`bullets` / `two-column` / `image-focus`）**必须**有 `title`，
   而且标题要是一个**断言**（"这一页要让学生知道什么"），不要写
   "小结/要点/内容/概况"这类分类词。
3. 一页**最多 6 条**要点；**单条最多 30 字**；**一页正文合计最多 120 字**；
   标题**最多 20 字**。超了就拆页或把长句挪进讲稿。
4. 每个正文页**必须**有 `notes`（讲稿，至少 10 字）。
5. **不要**出现"如上图/如下图/见下表"这类线性指代 —— 幻灯片是并置版面，观众看不见"上图"。
6. 出现数据、百分比、研究结论类表述的页面要写 `footer` 标注来源。
7. **不要**出现"待补充/待定/TBD/XXX"这类占位符。

页数：按 90 分钟一节课给 10–14 页。
