请重新生成**一页**教学幻灯片（spec 的一个 slide 对象）。

这次是**增量重生成**：整份课件已经写好了，只有**一页**需要重写。
你看到的是这一页在整节课里的位置（所属模块、所属环节、该环节的教师/学生活动与设计意图），
以及同环节的其他页。**只输出这一页**，不要输出整份 spec。

```json
{
  "layout": "bullets",
  "title": "这一页要让学生知道什么",
  "bullets": [{"text": "要点", "level": 0}],
  "notes": "讲授者讲稿：这一页怎么讲、停顿在哪、问什么",
  "footer": "课程名 · 第几次课"
}
```

字段说明：

- `layout` ∈ `bullets`（要点页）/ `two-column`（两栏对比页）/ `quote`（引述页）/
  `image-focus`（图为主）/ `blank`。**没有 `image` 就不要用 `image-focus`。**
- `bullets` 是数组，元素 `{"text": "…", "level": 0}`，`level` 0 为一级、1 为二级。
- `two-column` 的分栏规则：**level 0 进左栏，level 1 进右栏**。
- `notes` 是**讲稿**（给讲授者看），`bullets` 是**正文**（给观众看）—— 两者必须分开。
- `footer` 是来源标注页脚。

硬性要求（审查器会逐条判，ERROR 级必须改）：

1. **不要**输出 `id` 字段（页面 id 由系统按原位保留）。
2. 正文页必须有 `title`，而且标题要是一个**断言**（"这一页要让学生知道什么"），
   不要写"小结/要点/内容/概况"这类分类词。
3. 一页**最多 6 条**要点；**单条最多 30 字**；**一页正文合计最多 120 字**；
   标题**最多 20 字**。超了就拆页或把长句挪进讲稿。
4. 正文页**必须**有 `notes`（讲稿，至少 10 字）。
5. **不要**出现"如上图/如下图/见下表"这类线性指代。
6. 出现数据、百分比、研究结论类表述的页面要写 `footer` 标注来源。
7. **不要**出现"待补充/待定/TBD/XXX"这类占位符。
8. **不要**编造事实：涉及具体数据、文献、参数时，若上下文里没有，就写一般性表述，
   或把要点聚焦在概念关系上。

另外：这一页**必须与同环节的其他页不重复** —— 重写它是因为它原来那版有问题，
不是让它再说一遍邻页已经说过的内容。
