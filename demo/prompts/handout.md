请生成一份**学生阅读版讲义**（自学者可独立使用的教学材料）。

⚠️ 注意：本仓库另有**一份**「逐页讲稿讲义」，它是**从课件规格派生**的、讲稿与课件逐字同源，
给讲授者上课用。**你不要写那一份**。你要写的是给**学生课后自学**用的这一份。

```json
{
  "title": "讲义标题",
  "sections": [
    {
      "heading": "章节标题",
      "body": "正文段落（Markdown，可用列表、公式、行内代码）",
      "intuition": "这一节要建立的直觉（先讲直觉，再给形式化）",
      "terms": [{"term": "术语", "meaning": "一句话解释"}],
      "check": "学生读完能回答的问题（1–2 个）"
    }
  ]
}
```

硬性要求：

1. **每个概念必须给出「直觉 → 形式化」的桥梁** —— 先让学生有画面，再给式子。
2. **不要**把课件的要点逐条抄一遍。讲义是自学者可独立使用的材料，不是课件的文字复制。
3. `terms` 是本节的术语表；`check` 是读完能自问自答的问题。
4. **不得编造**任何事实性内容：数据、文献、公式出处、参数数值 —— 需要而没有的，
   写一般性表述并放进 `needs_manual_check`。
5. **不得**出现"待补充/待定/TBD/XXX"这类占位符。
6. 中文正文，术语中英并列（首次出现时）。
7. `needs_manual_check` 列出所有"本该由教师提供但没有"的信息。

只输出一个 JSON 对象，不要输出任何解释文字、不要用 Markdown 代码块包裹。
JSON 必须能被 json.loads 直接解析。
