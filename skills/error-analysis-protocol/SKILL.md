# 错误分析协议

## 这个技能解决什么

学生把整本习题册的错题用红笔涂满，写着"粗心""没看清""没学过"——除了红圈，找不到任何可操作的信息。

教师在批注上写"注意审题"，学生下次照样错，因为"审题"根本不是一种可以练习的动作。

一道题错了五分之一的同学，错的却是五种不同的原因，被统一归为"概念不清"讲了一遍，结果是能听懂的那部分人受益，真正的障碍原封不动。

学生改完错题当场就会了，三天后回到原样；教师布置的订正变成了抄写答案。

错误被当成要藏起来的失败，学生在考试中撕掉草稿纸，怕暴露自己不会。

错误分析要产出的是**可教的错误类型**，不是可指责的标签。这个协议把一轮错误分析固定成五步：采集 → 编码 → 归因 → 干预 → 复测，每一步都有产出物、判定阈值与时间盒，并且强制区分"错误类型"与"成因假设"。

## 什么时候用

**用**：

- 某次作业或某章练习的正确率明显偏低，需要判断问题出在概念、程序、策略还是表达。
- 学生反复在同一类题上失分，需要把"粗心"翻译成具体缺陷。
- 单元测验后要做一次错误分析，作为下一轮教学与练习设计的输入。
- 教师想用错题做课堂材料，但怕变成"晒错题羞辱"。
- 学生自学时建立了错题本，但只有答案没有分析，需要给它加分析结构。

**不用**：

- 只是要标准答案与解析（那是讲解，不是分析）。
- 错误的成因已明确且单一（例如符号抄错、格式不合规），直接讲规则更快。
- 学生还没有基本概念与前置技能，此时错误无法编码，应先补概念。
- 题目或评分标准本身有误（学生集体失分），先查题目与评分。

## 输入

**必填**：

1. 学生错误产物：一份作业、一次小测或一组答题记录（需含学生作答与题号）。缺省按"最近一次作业的作答纸"处理。
2. 任务与评分标准：题目、满分、评分细则。缺省按"课程现行评分标准"处理，并在输出中标注为假设。
3. 涉及的知识点范围。缺省按"该次任务覆盖的全部知识点"处理。

**可选**：

4. 样本范围：全员分析还是抽取典型学生（建议先抽 8–12 份，避免教师负担失控）。
5. 可用教学时间。缺省按 1 学时（45 分钟）的工作坊设计。
6. 是否允许同伴互评。缺省按"允许，但教师先编码再发"处理（同伴只负责描述现象，不负责判定原因）。
7. 是否纳入过程性评价。缺省按"纳入，权重 ≤10%"处理。
8. 课程思政要求。缺省按"在'诚实面对错误'的话语上自然融入"处理。

## 执行步骤

1. **先排除"不是学生的问题"。** 检查题目是否有歧义、是否超出教学范围、评分标准是否前后一致、是否因排版或录入错误导致集体失分。集体失分且无规律时，先改题目，不要先改学生。
2. **采集。** 把每个错误抄成一条记录：题号、错误原句（原样抄写，不要转述）、标准答案要点、分值。同一学生在同一知识点上的重复错误合并计数，但保留全部原句。
3. **编码。** 按模板 B 的五类给每条错误打一个主类型（只能一个主类型），并标注严重度（阻断性 / 步骤性 / 表述性）。"粗心""不认真"不是编码结果，它是尚未分析的占位词。
4. **把编码变成归因假设。** 同一类型下如果出现 ≥3 个学生呈现同一现象，才提出一个成因假设（用"可能因为……"表述），并用模板 C 的最小诊断题去验证。3 个以下的不做假设，只做个别反馈。
5. **配干预动作。** 按模板 D 给每类错误配一条可练的动作（重做、改例题、口头解释、对比邻近题型等），规定时间盒与学生要交出的东西。
6. **设计复测。** 用模板 E 安排 3–7 天后的同构不同题复测，预先写好判定标准（同一错误类型复现率 ≤20% 视为通过）。
7. **课堂化。** 若要进课堂，用模板 F 的错题工作坊流程：先匿名、只描述现象、集体分类、最后才讨论原因，避免变成点名批评。

## 从干预到独立：撤架判定与最小学习记录

干预做完不等于学会了。五步流程里最容易被跳过的一环是：**凭什么撤掉支持、凭什么说"他自己会了"**。本节给出可核对的撤架判据、复核题构造规则与一份最小学习记录。

### ① 撤架判据（硬）

- 撤架的依据是**学习者承担了原来需要帮助的关键动作**，**不是**"翻到下一页"，也**不是**"练够了规定次数"。
- 撤架前先回答一个问题：**"刚才那一步，是学习者做的，还是我替他做的？"** 答不上来就不能撤。
- 撤架时撤的是**具体某一项支撑**（步骤卡、方向性提示、示范中的一步），不是一次撤光所有支持。
- 一次只撤一项，撤完立即复核。撤一项就崩，说明依赖的不是那一项，退回归因步骤重做假设。

### ② 错误类型 → 支持方式 → 撤架时点 → 复核任务

| 错误类型 | 首选支持 | 撤架时点（学习者做了什么就可以撤） | 复核任务形态 |
|---|---|---|---|
| 概念型 | 反例辨析 / 前提对比 | 能自己举出一个反例，并说清它为什么推翻原说法 | 同结构、换现象的新题，能判断对错并给理由 |
| 程序型 | 流程图 + "下一步做什么"空框 | 能自己填出下一步且不漏关键步 | 同流程、换数据的新题 |
| 策略型 | 同类题结构归纳 | 能说出这类题的共同结构 | 换情境的新题，能选对方法并说理由 |
| 表达型 | 固定检查行（单位 / 数量级 / 格式） | 能自己跑完检查行并订正 | 新题，要求写出检查过程 |
| 动机型 | 降难度到可完成的一步 + 即时反馈 | 交出非空草稿 | 一题能独立完成的最小任务 |

**撤架时点以"学习者实际做出的动作"为准，不以教师觉得"差不多了"为准。**

### ③ 复核任务的构造规则（硬约束）

- 复核用**同构不同题**：结构与考点相同，数据或情境更换。
- 复核题的答案**不得与示范题 / 受助题碰巧重复**，否则可能只是套用上一题答案。
- 复核仍须结合**理由或关键动作**判断，不能只看对错。
- 需要加大难度时**另标为新挑战**并检查先备知识，不要混进撤架复核。

### ④ 结论的表述边界

- **单次错误、单次复测通过，都不得写成"已掌握"。** 一次通过只支持"同结构换表面后、没有提示也做对了"。
- 不得据单次表现给能力标签，不得写"他总是……"（比"避免固定能力标签"更严）。
- 复测样本不足时（少于模板 E 规定的 4–6 题）结论只能是"暂未复现"，不能写"已消除"。
- 一次通过后应再排一次**延迟复核**（再隔 3–7 天）；两次都通过，才允许写"该错误类型在本次任务范围内未复现"。

### ⑤ 最小学习记录

把本技能已有的模板串成一条可核对的记录：

| 字段 | 从哪来 | 要求 |
|---|---|---|
| 最初独立尝试 | 模板 A 错误原句 + 题号 | 原样抄写，不转述 |
| 实际提供了什么帮助 | 模板 C 诊断结果 + 模板 D 干预动作 | 写清是否已看过目标答案 |
| 帮助后学习者自己完成了什么 | 课堂 / 课后产出 | 只写实际发生的 |
| 撤了什么支持 | 新增字段 | 写清撤的具体哪一项 |
| 复核中实际发生了什么 | 模板 E 复测记录 | 写实际表现与理由 |
| 下一步 | 独练 / 继续支持 / 补充教学 / 暂时结束 | —— |

**未发生的尝试保持待完成；无回应时不预填成功、误解或进步。** 记录以可核对的作品与动作描述为主，不写"看起来进步了"。

## 输出模板

### 模板 A｜错误清点表（一行一条错误）

| 编号 | 学生 | 题号 | 错误原句（原样抄写） | 标准答案要点 | 失分 | 主类型（模板 B） | 严重度 |
|---|---|---|---|---|---|---|---|
| E-01 | | | | | | | 阻断 / 步骤 / 表述 |
| E-02 | | | | | | | |

要求：错误原句必须原样抄写。把学生的推导过程记下来，比只记最终答案有用得多。

### 模板 B｜五类错误编码判据（一个错误只取一个主类型）

| 类型 | 识别特征 | 典型原句 | 可能的认知成因（假设，非结论） | 可练的干预动作 | 不属于本类型的信号 |
|---|---|---|---|---|---|
| 概念型 | 前提、定义、定理用错 | "因为温度越高电阻越大，所以……" | 概念边界没建立，把局部规律当成普遍规律 | 用反例做概念辨析：举一个与该说法矛盾的例子 | 计算步骤都对，只是符号取值问题 |
| 程序型 | 步骤、公式、顺序错 | "先代入了……再……" | 缺少可执行的步骤表征，或步骤记不牢 | 画流程图并逐步口述，做"下一步该做什么"的空框练习 | 结果与理由不一致，且理由本身是对的 |
| 策略型 | 方法选择错（方向性问题） | 直接套用了不相干的模型 | 没有把问题特征与可用方法对应起来 | 给 6 道同类题，只问"这类题共同的结构是什么" | 方向对但某一步算错 |
| 表达型 | 思路对，写法/单位/格式不合要求 | 数量级差 10 倍、单位缺失 | 解题结果的外部表示没有规范训练 | 强制写出单位与数量级检查行，作为固定步骤 | 结论本身不成立 |
| 动机型 | 不写、乱猜、抄答案 | 空白、乱码 | 任务难度与时间安排不匹配，或缺少意义感 | 降难度到可完成的一步，并给即时反馈 | 同一学生其他题正常作答 |

**编码禁令**：不许写"粗心""不认真""态度问题""马虎"。出现这些词说明分析没有完成，退回第 3 步重新编码。

### 模板 C｜归因假设与最小诊断题（每条假设配 1 题）

| 归因假设（用"可能因为…"） | 最小诊断题（1 道，5 分钟内可答） | 若诊断成立 | 若诊断不成立 | 样本量 |
|---|---|---|---|---|
| 可能因为把"必要条件"当成"充分条件" | "若 A 则 B，能否由 B 推出 A？举一个反例" | 补充分必要条件的辨析练习 | 改查程序型或策略型 | ≥3 人同一现象 |

规则：诊断题必须能用 5 分钟内、1–2 句话的答案判定，不得用需要长篇论述的题目。

### 模板 D｜干预动作卡（每类错误一张）

| 字段 | 内容 |
|---|---|
| 错误类型 | |
| 干预动作 | 例：改例题（把原题的数据换一个，条件不变） |
| 为什么选这个动作 | 例：保留结构、只换表面信息，可排除记忆性错误 |
| 时间盒 | 例：课堂 10 分钟 / 课后 20 分钟 |
| 学生要交出的东西 | 例：3 道改例题 + 1 段口述说明 |
| 完成判定 | 例：3 道全对且能说出"哪一步变了" |
| 教师要看的证据 | 例：过程稿（不是终稿） |

### 模板 E｜复测设计表

| 复测项 | 内容 |
|---|---|
| 复测时间 | 错误发生后第 __ 天（建议 3–7 天，写死） |
| 题型 | 同构不同题：结构与考点相同，数据/情境更换 |
| 题数 | 4–6 题（少于 4 题判别力不足） |
| 判定标准 | 同一错误类型复现率 ≤20% 为通过；>20% 则该类型回到第 4 步重做假设 |
| 记录方式 | 错因复现率表（按类型分列） |

### 模板 F｜课堂错题工作坊流程（1 学时 45 分钟）

| 时段 | 教师动作 | 学生动作 | 产出 |
|---|---|---|---|
| 0–5 分钟 | 说明规则：只描述现象，不评价人；错误匿名 | 领取匿名错误条 | 错误条 |
| 5–18 分钟 | 主持分类，把错误分到五类（学生可质疑） | 参与归类、提出反驳 | 班级分类清单 |
| 18–30 分钟 | 挑 2–3 类做归因，出最小诊断题 | 现场作答 | 诊断结果 |
| 30–42 分钟 | 讲干预动作，示范 1 题 | 完成 1 道改例题 + 口述说明 | 个人改错稿 |
| 42–45 分钟 | 布置复测与截止时间 | 记录复测日期 | 复测计划 |

### 模板 G｜归因误判对照（教师自查）

| ❌ 容易下的结论 | ✅ 应当先做的检查 |
|---|---|
| "学生粗心" | 同一错误是否在同类题上稳定复现？稳定复现就不是粗心 |
| "概念没学会" | 用一道同结构、换表面的题测；若对，问题在程序或策略 |
| "讲过了就是没记住" | 间隔 3 天后复测仍错，才能归到记忆提取 |
| "这次讲完就好了" | 复测用同构不同题，且判定标准预先写死 |
| "这个错误说明能力差" | 错误类型是可变的，同一学生在不同类型上的分布会变 |
| "错得多就得多讲几遍" | 先编码：若 70% 属于表述型，多讲几遍毫无作用 |

### 模板 H｜撤架与复核记录表

| 错误编号 | 错误类型 | 已给支持 | 撤架触发动作（学习者实际做的） | 复核题与判定 | 复核实际表现 | 结论边界 | 下一步 |
|---|---|---|---|---|---|---|---|
| E-01 | 概念型 | 反例辨析 | 自己举出反例并说明为什么 | 同构换现象新题（判断对错 + 给理由） | | 单次通过：仅支持"同结构换表面、无提示下做对" | 独练 |
| E-02 | | | | | | | |

要求：撤架触发动作栏只填**学习者实际做出的动作**；复核实际表现栏填实际发生的情况（做对 / 做错 / 部分 / 未作答），不填推测；结论边界栏不得出现"已掌握""已消除"。

### 模板 I｜最小学习记录单（一条错误一份，逐次填空）

| 字段 | 本次填写 |
|---|---|
| 最初独立尝试（原句 + 题号） | |
| 实际提供了什么帮助（含是否已看过目标答案） | |
| 帮助后学习者自己完成了什么 | |
| 撤了什么支持（具体哪一项） | |
| 复核中实际发生了什么（表现 + 理由） | |
| 下一步（独练 / 继续支持 / 补充教学 / 暂时结束） | |

配套规则：未发生的尝试保持"待完成"；无回应时留空并写"无回应"，**不预填成功、误解或进步**。

## 中国高校语境要点

- **学时制**：完整错题工作坊 1 学时（45 分钟）；若课时紧张，保留"0–18 分钟分类 + 30–42 分钟改错"两段共 30 分钟，诊断题改为课后线上提交。
- **评价制度**：错误分析过程适合做过程性评价（错题工作坊产出 5% + 复测成绩 5%），终结性考核权重相应下调，合计必须 100%，以课程大纲为准。
- **班级规模**：40 人以上不宜全员逐条分析。做法：教师先抽 8–12 份做编码，形成分类清单后全班用；每个学生仍要完成个人改错稿。
- **毕业要求支撑**：错误归因与改错记录支撑"问题求解""终身学习"类毕业要求指标点的达成过程证据，引用本校指标点原文表述。
- **课程思政**：把"如实记录错误、不掩盖、不甩锅"作为工程职业素养的一部分自然融入——例如讨论"工程师在记录里隐瞒一次误操作会带来什么后果"。错误条必须匿名，避免变成批斗会。
- **学术诚信与 AI**：改错稿必须由学生本人完成，AI 生成的解析不能作为订正证据；AI 可用于解释概念，但学生要能口头讲清自己错在哪。
- **教材与参考书**：若引用错题本范例或教辅，需给出可核验书目信息（有 ISBN 写 ISBN，无则写"待补充"），不得编造 ISBN。
- **复测与正式考核的关系**：复测若与期中 / 期末冲突，复测结论**不替代**正式成绩（复测只是教学证据，不进成绩册）。
- **复测题与题库的关系**：复测题目要避开已公开的期末题库，否则复测会退化成"考背过的东西"，失去撤架复核的意义。
- **班级层面的撤架交代**：抽 8–12 份做编码时，撤架判据要在**全班层面单独交代一次**（哪些错误类型已经可以撤支持了），但"哪些同学已经可以自己做了"**不能凭印象点名**。
- **过程材料的归档**：撤架与复核记录属过程性评价材料，权重 ≤10% 且与期末权重合计 100%（以课程大纲为准），可归档进教学文件备查。

## 易错点

- ❌ 用"粗心/不认真"给错误定性 → ✅ 回到模板 B 重新编码；写不出类型就说明分析没做完。
- ❌ 一次错误给一个原因 → ✅ 编码取一个主类型，成因只能作为"可能因为"的假设，并要用最小诊断题验证。
- ❌ 全班逐条分析，教师被拖垮 → ✅ 先抽 8–12 份编码，产出分类清单后全班复用。
- ❌ 讲完就算改完 → ✅ 必须有 3–7 天后的同构不同题复测，判定标准事先写死。
- ❌ 订正变成抄答案 → ✅ 干预动作必须产出过程稿（改例题 + 口述说明），不看终稿。
- ❌ 在全班面前点名展示学生的错 → ✅ 匿名化；课堂只讨论错误类型，不讨论人。
- ❌ 忽略"集体失分"信号 → ✅ 先查题目与评分标准，集体失分往往是任务设计问题而非学生问题。
- ❌ 把错误类型当成能力标签 → ✅ 错误类型是可变的，措辞避免"他总是……"。
- ❌ 撤架 = 翻到下一页 → ✅ 撤架依据是学习者承担了原来需要帮助的关键动作。
- ❌ 练够规定次数就撤支持 → ✅ 次数不是依据；看学习者是否做出了关键动作。
- ❌ 把原题复述当独立应用 → ✅ 复核必须同构不同题，结构可比、表面不同。
- ❌ 复核题答案与示范题碰巧重复 → ✅ 复核答案不得与示范 / 受助题重复，否则可能只是套用上一题答案。
- ❌ 一次通过就写"已掌握" → ✅ 只写"同结构换表面、无提示下做对"，并安排延迟复核。
- ❌ 无回应时在记录里预填"进步了" → ✅ 未发生的尝试保持待完成，无回应不预填成功、误解或进步。

## 自检清单

- [ ] 已排除题目歧义、超纲、评分不一致等非学生原因
- [ ] 每条错误都有原样抄写的错误原句与题号
- [ ] 每条错误只标一个主类型，且无"粗心""不认真"等词
- [ ] 每条错误都标了严重度（阻断/步骤/表述）
- [ ] 只有出现 ≥3 人的同一现象才提出成因假设
- [ ] 每条假设配了一道 5 分钟内可判定的最小诊断题
- [ ] 每类错误都配了可练的干预动作，含时间盒与交出物
- [ ] 已排定 3–7 天后的同构不同题复测（4–6 题）
- [ ] 复测判定标准（复现率 ≤20%）事先写死
- [ ] 课堂使用时错误条已匿名
- [ ] 过程性评价权重 ≤10%，与期末权重合计 100%
- [ ] 已要求过程稿而非终稿，并写明 AI 不得代做订正
- [ ] 撤架依据是"学习者承担了原来需要帮助的关键动作"，不是翻页或练够次数
- [ ] 每次只撤一项具体支撑，并写清撤的是哪一项
- [ ] 复核题结构可比、表面（数据 / 情境）不同
- [ ] 复核题答案与示范题 / 受助题不碰巧重复
- [ ] 复核判定结合了理由或关键动作，不只看对错
- [ ] 结论限定在实际条件内，未据单次表现写"已掌握"或能力标签
- [ ] 样本不足（少于 4–6 题）时结论写"暂未复现"而非"已消除"
- [ ] 最小学习记录六字段填全，无回应处未预填
