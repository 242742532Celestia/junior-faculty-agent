# 课堂观察协议设计器

## 这个技能解决什么

四类"观完等于没看"的现场，任一命中就该用本技能：

- 观课表上写着"教学态度认真、气氛活跃"，评完课没人说得清学生到底做了什么。
- 同一节课三位老师各用一张表，一个说互动好、一个说讲太多，学院无法横向比较。
- 事后想回录像找证据，只剩结论没有时间点，讨论又退回到"我觉得"。
- 新教师旁听一学期记了一堆感受，却拿不出一个下节课能改的动作。

本技能把这些场景换成一张**当场能填、事后能复算、跨人能比对**的观察记录表，
并规定"从看到什么"到"判成什么"之间必须走过的推断步骤。

## 什么时候用 / 什么时候不用

**用：**

- 公开课、教学比赛、师范生教学技能评审，需要统一口径的评分与证据留存
- 学院听课常规，需要半年后仍能调出记录的档案
- 同一专题（同一课程不同班、同教师不同轮次）的横向比较
- 教研组用录像做课例研究或小规模教学研究
- 新教师上岗前后的跟踪听课

**不用：**

- 录像收音、字幕、机位本身不合格——先修记录技术，否则只是重听噪音
- 想评估"学生学得怎么样"——那是测量与数据分析，不是课堂观察
- 学生入学第一周的适应情况——此时看到的多是环境陌生，应先做学情调查
- 未取得学生知情同意却要拍脸的观察

## 输入

**必填**

| 项 | 说明 | 缺省处理 |
|---|---|---|
| 课程与章节 | 课程名、章节标题、授课教师 | 无：口头确认本节内容后再定维度 |
| 观察目的 | 诊断性 / 评估性 / 研究性 / 常规检查 | 无：默认诊断性，维度取 10 项 |
| 记录载体 | 纸质表 / 电子表单 / 录像 / 音频 | 无：纸质勾选 + 24 小时内补录证据 |
| 人力与时间 | 观察者人数、单次可旁观时长 | 无：按 2 人 × 1 节设计 |

**可选**

- 课程大纲与本节 3 条教学目标（强烈建议，决定维度映射）
- 旧观课表（可借字段结构，不照搬措辞）
- 录像编号规则、保存期限与匿名化要求
- 是否需要抽样、抽多少

## 执行步骤

1. **先写用途句**："这份记录读完要做的决定是＿＿"。写不出来就不要开始设计。
2. **目标翻译成行为指标**：取本节 3 条教学目标，每条配 2 个可观察的学生行为；
   教师行为只在直接影响学生反应时记录。
3. **按用途定维度数量**：诊断性 8–12 项，评估性 5–7 项，研究性另按变量定义；
   超过 12 项的表，现场一定填不完。
4. **配观察者与信度方案**：至少 2 名观察者独立记录，重叠课次 ≥ 30%
   （一学期 10 次课，至少重叠 3 次）。
5. **定记录方式**：每个维度在"计数 / 时间戳 / 等级"中三选一，写清粒度（默认 5 分钟窗）。
6. **预填一节**：拿真实录像或真实课堂试填，看每 5 分钟能否在 30 秒内记完，字段够不够用。
7. **定稿与归档**：观察表定稿稿、教师培训说明、录像与文字记录的保存位置和保留期同时交付。

## 输出模板

**表 A 协议元信息**

| 字段 | 填写 |
|---|---|
| 协议编号 | 年-院-序号（如 2026-物工-03） |
| 课程 / 章节 / 班级 | |
| 日期 / 时长 | |
| 观察者编号 | 观察者 A / B（不写真名，事后映射） |
| 记录载体 | 纸质 / 电子 / 录像编号 |
| 用途句 | 本记录用于决定： |

**表 B 观察维度定义表**（设计阶段填，一次定稿）

| # | 观察维度 | 可观察指标（学生侧优先） | 记录方式 | 粒度 | 对应教学目标 |
|---|---|---|---|---|---|
| 1 | | | 计数/时间戳/等级 | 5 分钟 | 目标 1 |
| 2 | | | | | |

每个维度的等级锚点写死三档，语言统一：

- 1 分 = 该窗口内无该行为出现，或仅教师单方发起
- 3 分 = 该行为出现 1 次以上，部分学生有可见响应
- 5 分 = 该行为出现 2 次以上，且多数被抽样学生有可见响应

**表 C 课堂观察记录表**（现场填，每 5 分钟一行）

| 时段 | 学生侧可见行为（数量或原话） | 教师侧动作 | 学生产出证据 | 判断 | 存疑标记 |
|---|---|---|---|---|---|
| 0–5 | | | | | |
| 5–10 | | | | | |

行数 = 课堂分钟数 ÷ 5；45 分钟 1 学时 = 9 行，90 分钟连堂 = 18 行。

**表 D 证据→结论推断链**（观察后 24 小时内独立填写，观察者互不看）

| 步骤 | 写什么 | 判定规则 |
|---|---|---|
| 1 观察事实 | 只写看得见的：第几分钟、谁、做了什么、说了什么 | 不得含"因为/所以/说明" |
| 2 事实计数 | 出现在几个 5 分钟窗、涉及几名被抽样学生 | 单窗=1；≥2 窗且 ≥2 生=稳定模式 |
| 3 中间编码 | 归入表 B 的哪个维度、属于哪一档 | 只能用已有锚点，不新造类别 |
| 4 教学判断 | 一句教学语言（如"提问后未留等待时间"） | 必须能被第 1 步直接支持 |
| 5 反证检验 | 至少 1 条相反观察或替代解释 | 找不到反证则置信度降为"中" |
| 6 建议动作 | 下一节课可执行的一个动作 | 必须能回溯到第 1–3 步 |
| 7 置信度 | 高 / 中 / 低 | 高=≥2 窗 + ≥2 生 + 反证检验通过 |

**表 E 观察者校准表**

| 维度 | 观察者 A | 观察者 B | 差异（0 / 1 / ≥2 档） | 原因说明 |
|---|---|---|---|---|
| | | | | |

逐项一致率 = 一致项 ÷ 总项，目标 ≥ 0.80；Cohen's κ ≥ 0.60 视为可用，≥ 0.80 为良好；
差异 ≥2 档的维度必须复训并重测该维度。

**表 F 观察后 48 小时报告模板**（限一页）

| 段落 | 内容 | 上限 |
|---|---|---|
| 三个最强证据 | 表 D 第 1 步原句，带时间点 | 3 句 × 50 字 |
| 两个待验证判断 | 表 D 第 4 步 | 2 句 |
| 一个可执行动作 | 下节课可做 | 1 句 |
| 一个待观察指标 | 下次要看什么 | 1 句 |

**时间盒**：现场每 5 分钟 ≤ 30 秒；课后再编码 ≤ 25 分钟；校准会 ≤ 40 分钟；报告 ≤ 20 分钟。

## 中国高校语境要点

1. **学时口径**：45 分钟 1 学时，两学时连堂 90 分钟，行数按 18 行填；
   连堂后半段注意力下降，单列"第 60 分钟后学生产出"一项。
2. **大班抽样**：60 人以上不统计全班参与率，固定抽 9 人（3 排 × 每排 3 人，避开前两排），
   每位被抽学生记一个标记，使"有响应的学生"有分母。
3. **形成性评价衔接**：维度中固定含"教师如何获取理解证据"一项，与一般提问观察分开记录。
4. **毕业要求支撑**：评优听课的表增加"支撑毕业要求指标点"列，只写占位编号，查不到写"待补充"。
5. **课程思政**：判据是"是否用本专业真实问题自然引出价值讨论"；
   出现口号式贴标签反而要记为负例。
6. **排课约束**：避开期中期末复习周、答疑日与监考日；同一课程不同班的观察尽量排在一周内，
   减少内容差异带来的干扰。
7. **录像与隐私**：含学生的录像需知情同意；记录匿名化（用编号），默认不外传，保留 30 天后删除。
8. **工作量折算**：若用于工作量认定，观察时长与记录时长分别申报，不按"一节 45 分钟"折算。

## 易错点

- ❌ 维度写"教学态度认真""气氛活跃" → ✅ 换成可数行为，如"5 分钟窗内未被提问的学生人数"
- ❌ 一张表塞 20 多个维度 → ✅ 现场维度 ≤ 12，其余改为课后访谈提纲
- ❌ 一个人记录直接出结论 → ✅ 2 人独立记录，重叠课次 ≥ 30%，报告逐项一致率
- ❌ 记录写"我觉得学生没听懂" → ✅ 写"00:12–00:17 提问 X，3 名被抽样学生无回应，1 人答错"
- ❌ 观察者先商量再记 → ✅ 各自独立记录，24 小时内合稿，合稿只做差异标注
- ❌ 结论一步跳到"教师不会提问" → ✅ 走表 D 七步，第 2 步先数清窗数与人数
- ❌ 观察结论写进学生成绩册 → ✅ 观察只用于发展性反馈与改进建议
- ❌ 拿一次课当常态 → ✅ 单次课只写"本次观察"，趋势判断至少 3 次同类课

## 自检清单

- [ ] 已写出用途句，并能对应到一个具体决定
- [ ] 每个维度都有指标、记录方式、粒度、1/3/5 锚点
- [ ] 维度数 ≤ 12，且每个维度标注了对应教学目标
- [ ] 记录表行数 = 课堂分钟数 ÷ 5
- [ ] 已安排至少 2 名观察者与重叠课次 ≥ 30% 的安排
- [ ] 校准方式写明一致率或 κ 的算法与复训触发条件
- [ ] 推断链 7 步全部填完，置信度有依据
- [ ] 报告中每个结论都能回溯到带时间点的证据句
- [ ] 已写明知情同意、匿名化方式与保留期限
- [ ] 未把观察记录用于终结性成绩评定
