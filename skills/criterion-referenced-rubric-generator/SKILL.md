# 评分量规生成

## 这个技能解决什么

教师写评分标准，最常写出来的是这样：

> 优秀：内容充实、分析深入；
> 良好：内容较充实、分析较深入；
> 合格：基本完成；
> 不合格：未完成。

这样的"量规"没法用。两位老师判同一份作业给分差两档；学生看完不知道自己该往哪改；
最后评分变成"印象分 + 心情分"。更麻烦的是，它把质量差异说成了程度差异，
而学生真正需要的区分是**行为差异**——"在不给模板的情况下自己列出了变量"
和"照着给定框架填空"，这是两类不同表现，不该只是"好"和"较好"。

另一种翻车方式更隐蔽：量规维度写成"内容完整 / 结构清晰 / 语言表达"，
与课程目标毫无关系。判分看起来很规范，实际测的是写作文风，
学生把公式推导写对却拿不到分。

量规的本质是**把"够好"翻译成可被第二个人独立复核的行为描述**。
好的量规能让两个陌生教师判同一份作业，给出同一个等级。

## 什么时候用 / 什么时候不用

**用**：
- 需要一份学生能照着改、老师能照着判的评分依据（期末大作业、实验报告、课程论文）
- 多人分工批改同一批作业，需要统一口径
- 课程有等级体系（优秀/良好/合格/不合格）需要可复核的切分点
- 学生抱怨"分数没道理"，需要把评分依据摊开

**不用**：
- 只要一个总分、不需要分维度反馈的快速打分（用 `single-point-rubric-designer` 更省事）
- 目标本身还没定，评分标准无从谈起（先做 `backwards-design-unit-planner`）
- 纯客观题自动判分、离散数学计算题对答案（不需要等级描述）
- 只想润色一份已有量规的措辞（那是文字编辑，不是量规生成）

## 输入

**必填**（缺任一项先出草稿并把假设标出来）：
1. 评分对象：作业题目 / 任务要求原文（学生看到的就是这份）
2. 对应的课程目标或子目标清单
3. 评分用途：终结性考核 / 形成性反馈 / 两者兼用（用途决定等级数量与严格程度）
4. 等级体系：是否采用「优秀 / 良好 / 合格 / 不合格」四档
5. 本项在总评中的权重

**选填**（没有就留空，写进"需人工核验清单"，**不许编**）：
6. 课程各项考核权重构成（用于合计 100% 校验）、学生人数与批改工时
7. 往届学生作品（可作锚点样例）、教材版本与对应章节（ISBN 需真实，查不到写"待补充"）
8. 毕业要求指标点编号（**用户没给就留空**，不要自造指标体系）

## 执行步骤

1. **先定"这个作业要评什么能力"，再定维度。**
   把任务书逐句标注：哪一句要求学生做出可观察的动作。只保留与这些动作对应的维度。
   常见误区是照抄"内容 / 结构 / 表达"三件套——只有当任务确实要求"组织论述"和
   "书面表达"时，它们才配成为维度。筛子：**这个维度拿满分，学生在目标能力上就真的更强**。

2. **给每个维度写"达成定义"。**
   一句话说明这个维度做到什么程度算"合格"，用可观察行为描述。
   例（维度：实验方案设计）：合格 = 能独立列出自变量、因变量、控制变量并说明各自操作方式；
   "做得比较到位"不是达成定义。

3. **选等级体系与评判方式。**
   四档（优秀/良好/合格/不合格，与高校等级体系一致，推荐）/ 三档（形成性快判）/ 五档（高权重且批改工时允许）。
   评判方式二选一：**整体评判**（先给总等级再回溯理由）或**分维度评判**（先各维度给等级再合成）；
   终结性考核优先分维度（可复核、可申诉）。

4. **写等级描述，写"相邻等级的判别行为"。**
   这是量规质量的分水岭。合格与良好的差别不是"较好地"，而是：
   合格——能按给定框架列出变量；良好——能在给定框架外自己选变量并说明为什么。
   每个相邻等级之间必须存在**一条能判定的行为分界**，否则等级会重叠，判分时必然向中间塌陷。

5. **把等级锚定到具体作品。**
   每个等级准备 1 份典型学生作品（或匿名化片段）作为锚点，写清它为什么落在这个等级、错在哪。
   没有锚点的等级描述只是形容词，判分时仍会漂。

6. **分配维度权重与分值。**
   权重按"该维度对目标达成的贡献"分配，不按篇幅（规范占三成篇幅时权重仍可低）。
   **各项权重加总必须恰好 100%**；等级与分数的换算规则要写明（如百分制 + 等级线）。

7. **做判分校准。**
   取 3–5 份真实学生作品，两位评分者独立打分并记录差异；差异超过一档的样本进入仲裁，
   仲裁结论回写进等级描述。校准记录要留档——它是"两个陌生教师能判出一致"的证据。

8. **产出学生版量规。**
   完整版给教师，学生版做成"我要做到什么 / 我怎么知道自己做到了"的清单。
   学生版不是教师版的删字版，而是把等级描述翻译成自查问题。

9. **收口：列出不确定项。**
   凡属推断（"这批作业质量普遍在良好档"）标「假设」；
   缺的事实信息（锚点样例、权重、ISBN、指标点）标「待补充」。

## 中国高校语境要点

- **课时与考核时长的配套**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。
  终结性考核若含开放题，量规的维度数量要服从实际考试时长——学生 120 分钟要写完
  6 个维度的内容，本身就是权重设计失当。
- **评价制度分工**：形成性评价用**学生版量规 + 三档**，用于自评与同伴互评，缩短反馈回路；
  终结性考核用**教师版四档 + 权重合成**，用于留证与可复核。两版不混用，
  避免学生拿"自评标准"去要求阅卷宽严。
- **权重构成**：课程平时成绩与期末成绩各项百分比必须**加总恰好 100%**；
  量规内部的维度权重也加总到 100%。任何一处凑整都要在表 4 标出来。
- **等级体系**：用「优秀 / 良好 / 合格 / 不合格」，等级线由院系/课程组给定；
  用户没给就留空，不要自行定及格线，也不要套用 K-12 的 band 体系。
- **不及格档要写具体**：不是"未完成"，而是"未提交 / 提交但未回应任务要求 /
  存在无法弥补的事实性错误"——三种情形的补救路径不同（补交、重写、不可补救）。
- **毕业要求支撑**：量规若对应某条毕业要求指标点，编号由院系给定，**没给就留空**，
  在表 1 旁标"待补充"，不要自造编号体系。
- **课程思政**：思政目标只有在能写出**可观察行为**时才配设成评分维度；
  写不出行为（"提升家国情怀"）就不设维度，不要用不可判的维度拉高或压低分数。
- **实践与实验环节**：操作规范、数据记录准确性与分析深度要**分成不同维度**，
  否则实验课变成"格式分"竞赛。注明实验部分的学时数、分组方式与考核占比。
- **教材与参考书**：ISBN 需真实并与任务书对应章节一致，查不到写「待补充」，不许编造。

## 易错点

- ❌ 维度写成"内容/结构/表达"三件套 → ✅ 每个维度回溯到一条目标与任务书原文
- ❌ 等级用"非常好/较好/一般/差"的形容词梯度、描述没有可观察动作 → ✅ 写相邻等级的判别行为，每条描述含一个可被第二个人复核的动作
- ❌ 权重按篇幅分配、且加总凑整 → ✅ 按目标贡献分配，逐项校验到 100%
- ❌ 没有锚点样例 → ✅ 每个等级配 1 份典型作品并写明归级理由
- ❌ 只发教师版量规 → ✅ 同时产出学生版自查清单
- ❌ 整体评判与分维度评判混用 → ✅ 一次只选一种评判方式，合成规则写进表 4
- ❌ 思政维度写成不可判的品质词 → ✅ 写不出可观察行为就不设该维度
- ❌ 编造等级线、指标点编号、ISBN → ✅ 查不到写「待补充」并列入核验清单

## 自检清单

- [ ] 每个维度都对应一条目标与任务书原文要求，无"凑数维度"
- [ ] 每个维度都有一句可观察的"合格达成定义"，等级数量与评判方式（整体/分维度）已确定并写明
- [ ] 每两个相邻等级之间都有一条可判定的分界行为，每个等级有锚点样例与归级理由
- [ ] 维度权重加总 = 100%，课程各项权重加总 = 100%
- [ ] 等级与分数的换算规则、等级线已写明（未定的标"待补充"）
- [ ] 判分校准记录表已建立，跨档样本有仲裁结论
- [ ] 学生版量规已产出，是自查清单而非教师版删减
- [ ] 不合格档的三类情形分别写明；思政维度均具备可观察行为，否则未设
- [ ] 毕业要求编号、ISBN 等事实项：真实或已列入待补充，无编造

## 交叉技能

- 目标过大、维度划分不清 → `competency-unpacker`；等级逻辑是否自洽 → `coherent-rubric-logic-builder`
- 只需一个总分阈值的场景 → `single-point-rubric-designer`
- 量规所依据的考核是否真测到目标 → `assessment-validity-checker`
- 作业错误类型的诊断依据 → `gap-analysis-from-student-work`、`error-analysis-protocol`
- 反馈文本怎么写才有用 → `feedback-quality-analyser`
- 形成性评价的整体设计 → `formative-assessment-loop-designer`；命题与题目设计 → `exam-question-bank`
- 学段与课时制度换算 → `he-context-adapter`
