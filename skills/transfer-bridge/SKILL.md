# 迁移桥接任务设计器

## 这个技能解决什么

- 课后练习全对，期末把题目换了个说法，全班卡住。你以为是"粗心"，其实是学生只记住了题目的表面。
- 学生在实验室用方法 A 处理了 10 组数据，换一台仪器、换一个样品，方法 A 就不会用了——他以为方法跟设备绑在一起。
- 上一届学生总结的"万能方法"到你这届不灵了，因为你的教材换了案例、换了术语，结构没变但表面全变了。
- 你在习题课上大量讲"这道题怎么解"，学生听得点头，却从没有一次被要求"这个方法和上节课那个像在哪里"。
- 学生能背出方法名和步骤，但让他"自己找一个可以用它的地方"，他一个也举不出来。
- 期末综合题失分，你按"知识点没讲"来补救，补完还是错——真正缺的是桥，不是知识点。
- 能力相近的两个学生，一个在新情境里能自己找到旧方法，一个反复找不到；差别常常不在能力，而在于是否做过"对比—归类—命名"这类桥接动作。

本技能做的是：**明确从哪迁移到哪、属于哪一层迁移（近/中/远）、用哪种桥接任务类型、需要什么脚手架、迁移失败时先怀疑什么**。

## 什么时候用

用：

- 讲完一个方法/模型之后，需要让学生在**不同表面上**再用一次。
- 章节或单元收尾，把若干方法整合到同一个真实问题里。
- 期中/期末前，诊断学生是"知识点缺口"还是"迁移桥缺口"（两者补救方式完全不同）。
- 新学期开课，把上学期的经验接过来（如"上学期用过的方法在这里也管用"）。
- 实习、毕业设计、企业项目前的"方法迁移准备"。

不用：

- 单纯重复同一方法的机械练习（那是 `practice-problem-sequence-designer`）。
- 学生连前置知识都没掌握时——先补知识点，桥接无从搭起。
- 目标是记忆事实或术语（迁移不解决记忆问题）。
- 一次任务里同时要迁移 3 个以上方法——桥会塌。

## 输入

必填：

| 输入项 | 要求 | 缺省处理 |
|---|---|---|
| 起点能力 | 学生已经稳定掌握的方法/概念（写具体行为） | 无则先确认前测结果；不确认时按"待核验"标注 |
| 终点情境 | 学生要在一个什么样的新情境里使用它 | 无则本技能只给桥接任务类型清单，不出题 |
| 本轮迁移层级 | 近 / 中 / 远（三选一，写死一档） | 默认"近迁移"，并写明本轮不做更远的一档 |
| 学生规模与课时 | 人数、可用于桥接的时间 | 按 60 人、10 分钟处理 |
| 已有误区清单 | 学生以前在哪一步犯过错 | 无则用模板 C 的默认类别，由教师课前补充 |

可选：

- 教材与真实案例来源（用于换表面而不造事实）。
- 学生已完成的桥接任务历史（避免重复同一类桥）。
- 课程思政融入点位置（可放在真实情境的选择上）。

## 执行步骤

1. **写清"迁移位差"。** 明确：起点会做什么 → 终点要在新情境里做什么 → **新在哪里**。新可以出现在：表面特征（数字、材料、术语、场景）、结构关系（要素之间的对应关系）、规则/约束（新增条件）。必须写清属于哪一类新。
2. **定层级与期望证据。** 近迁移=同构换表面；中迁移=表面与部分结构都变；远迁移=表面与结构都变但同属一个抽象类。每层给一个可观察的达成证据（如"能指出新情境中的哪个要素对应方法里的哪个角色"）。
3. **选桥接任务类型。** 四类里选 1–2 类：对比归类任务、变式替换任务、诊断判断任务、逆向构造任务。每类有固定的指令句式（见模板 B）。
4. **搭脚手架，保留一个必须自己填的空。** 脚手架分三级：完全脚手架（给对照表）、半脚手架（给提示语）、无脚手架（只给目标）。本轮默认半脚手架；必须留一个"学生必须自己填的判断"（如"新情境里谁扮演方法中的 X 角色"），否则学生只是在按答案做填空。
5. **埋表面陷阱。** 在新情境里放一个"看起来像 A 其实是 B"的线索（如变量名相似、图形相似、术语相似），并配一道"看破"题（问：这个相似点为什么不能照搬？）。陷阱必须有明确的正确答案解释。
6. **写判定与分诊。** 桥接成功/部分成功/失败的判据写死；失败时按模板 C 分诊到：起点知识缺失 / 类比误导 / 抽象过度 / 表述陷阱干扰。
7. **排时间盒与复核。** 桥接任务限时 8–12 分钟（课堂内），并规定失败后的补救动作（不是重讲，而是换一层再搭）。

## 输出模板

### 模板 A：迁移位差与层级定义表

| 项 | 内容 |
|---|---|
| 起点能力（学生已会） | 能在 ___ 条件下用 ___ 解决 ___ 类型的问题 |
| 终点情境（新） | 在 ___ 情境中，面对 ___ 信息，需要 ___ |
| 新在哪里 | 表面特征变 / 结构关系变 / 规则约束变（三选一或多选，逐项写） |
| 本轮层级 | 近 / 中 / 远（本轮只做这一档） |
| 达成证据 | 学生交出 ___，其中必须包含 ___（如指出对应关系 + 一句理由） |
| 本轮不做 | 更远一档的迁移（写明留到哪一节） |

### 模板 B：四类桥接任务（选 1–2 类，附指令原话）

| 类型 | 指令原话（学生看到的第一句） | 学生产出 | 适合的"新" | 常见失效 |
|---|---|---|---|---|
| 对比归类 | "这两个案例看起来不一样，请指出它们在做同一件事，并说出对应关系。" | 对应表 + 1 句理由 | 表面变、结构不变 | 学生只描述差异不指出同构 |
| 变式替换 | "把条件改成 ___，用同样的方法做一遍，并说明哪一步因此变了。" | 解法 + 变化说明 | 表面变 | 学生沿用原答案不改步骤 |
| 诊断判断 | "下面 3 个情形里，哪一个可以用这个方法？哪一个看着像但不能用？写出判断依据。" | 选择 + 依据 | 表面变 + 需要区分边界 | 学生凭直觉不写依据 |
| 逆向构造 | "给出一个结果，反推需要用这个方法做什么。" | 逆推步骤 | 结构变 | 学生逆推成正向步骤 |

### 模板 C：脚手架与"必须自己填的空"

| 支架级别 | 提供什么 | 适用轮次 | 撤除时机 |
|---|---|---|---|
| 完全脚手架 | 要素—角色对照表、关键词清单、示例句式 | 首轮桥接 | 下一轮换成半脚手架 |
| 半脚手架（本轮默认） | 2–3 条提示语 + 一个填空位 | 常规 | 学生连续 2 次达标即撤 |
| 无脚手架 | 只给目标与约束 | 复习/迁移巩固 | — |

| 必须自己填的空 | 示例 | 为什么不能替学生填 |
|---|---|---|
| 新情境中的角色对应 | "新情境里的 ___ 对应方法中的 ___" | 填了就没有迁移发生 |
| 理由句 | "之所以能用，是因为 ___" | 理由是抽象化的关键证据 |
| 失效条件 | "当 ___ 变时，这个对应就断了" | 直接迁移的边界识别 |

### 模板 D：表面陷阱卡

| 陷阱编号 | 表面上像什么 | 实际不同在哪 | 陷阱出现在题目的哪一部分 | "看破"题与正确答案 |
|---|---|---|---|---|
| T1 | 变量名/术语与原案例相同 | 在方法里承担的角色不同 | 题干第 2 句 | "为什么这里的 ___ 不能照搬 ___ 的做法？答：它承担的是 ___ 角色" |

### 模板 E：迁移失败分诊表

| 学生失败表现 | 先查哪一项 | 追问（让学生自己说） | 补救动作 | 预期回到哪一层 |
|---|---|---|---|---|
| 完全用不上旧方法 | 起点知识是否可用 | "你打算先拿它做第一步的哪件事？" | 回到原案例，做一次角色标注 | 近 |
| 用上了但结果错（表面陷阱） | 是否被相似线索误导 | "你把 X 当成了 Y，它们真的等价吗？" | 给出陷阱卡，重做 | 近 |
| 照搬旧步骤，忽略新条件 | 新约束是否被注意到 | "题里多了一条 ___，旧步骤哪一步要变？" | 变式替换任务（半脚手架） | 中 |
| 会做但说不出为什么 | 是否缺少显性抽象 | "你能不看题说说这条规则管什么吗？" | 回述检查 + 理由句填空 | 中 |
| 会用但举不出新情境 | 是否缺少"自选情境"练习 | "生活中哪里也有这个结构？" | 自选情境任务（教师只给标准） | 远 |

### 模板 F：桥接任务单（学生版，教师布置与学生自选分列）

| 环节 | 教师布置（必做） | 学生自选（可选） | 时间盒 |
|---|---|---|---|
| 破冰 | 读新情境，写下你认为"最像旧方法"的环节 | 可选：先与同伴交换直觉（须各自写下自己的版本） | 3 分钟 |
| 桥接 | 完成桥接任务（类型：___） | 可选：选择"变式替换"或"诊断判断"其中之一 | 8 分钟 |
| 填空 | 填写角色对应空 + 理由句 | 可选：再补一条失效条件 | 4 分钟 |
| 看破 | 回答陷阱题 | 可选：自己出一道同类陷阱给同伴 | 3 分钟 |

> 自选项不得改变认知要求：两条路径都要产出对应表与理由句，评分口径一致。

## 中国高校语境要点

- **大班实施**：60–120 人的桥接任务用"个人 3 分钟破冰 + 同桌 5 分钟比对 + 全班讲评 5 分钟"。全班统一收一份答案会掩盖差异；采用抽 3–4 份当堂讲评。
- **时间盒**：桥接任务课堂内 ≤ 12 分钟；桥接必须安排在**讲授之后、方法讲解之前或紧接其后**，不要放在学期末突击。
- **过程性成绩**：桥接任务产出物（对应表、理由句）计入过程性考核时按"迁移表现"单列，权重 ≤ 平时成绩的 10%，规则第一周公布；不按对错计分。
- **真实素材优先**：换表面时优先使用真实行业/实验/工程数据（来自公开可信来源），不要编造数据或政策文件；引用具体教材与案例时核验真实书名与版次，ISBN 未核验写"待核验"。
- **课程思政自然融入**：在"自选情境"环节里要求学生选择一个与自己专业/社会生活相关的真实问题作为迁移目标，价值引领来自"把方法用在该用的地方"，不额外贴标签。
- **毕业要求支撑**：桥接任务的角色对应表与理由句是"方法可在新情境中使用"的过程证据，可纳入课程目标达成度材料。
- **工作量折算**：设计桥接任务与逐题分诊属课外教学工作量，按学院口径登记。

## 易错点

- ❌ 换皮不换骨（只换数字/名称） → ✅ 明确写出"新"属于表面、结构还是规则，并至少在结构或规则上动一次。
- ❌ 一次桥接三四个方法 → ✅ 一轮只桥接一个方法，桥太宽会塌。
- ❌ 脚手架把答案填完了 → ✅ 保留一个"学生必须自己填的对应空 + 理由句"，填完即失效。
- ❌ 没有陷阱，迁移只能是表面复制 → ✅ 每轮至少埋 1 个表面陷阱并配"看破"题与答案解释。
- ❌ 失败后重讲一遍原方法 → ✅ 失败先分诊（模板 E），按失效类型换桥接层级。
- ❌ 桥接任务出现在学期末突击 → ✅ 桥接紧跟方法教学，间隔太久等于新知识。
- ❌ 用"会做"代替"会迁移" → ✅ 达成证据必须包含显性对应关系与理由。
- ❌ 把迁移失败全归为"学生基础差" → ✅ 分诊表先排除"类比误导"和"新约束未察觉"。
- ❌ 自选情境没有质量标准 → ✅ 自选情境同样要填角色对应与理由，评分口径一致。

## 自检清单

- [ ] 起点能力与终点情境都已写成可观察行为
- [ ] 已写清"新在哪里"（表面/结构/规则）
- [ ] 本轮只做一档迁移层级，并写明更远一档留到哪节
- [ ] 达成证据包含显性对应关系 + 理由，而非只看结果
- [ ] 桥接任务类型已选定并写好指令原话
- [ ] 脚手架级别已定（本轮默认半脚手架）
- [ ] 至少保留一个学生必须自己填的空
- [ ] 至少埋 1 个表面陷阱，并有"看破"题与答案解释
- [ ] 失败分诊四类已写，且各配追问与补救动作
- [ ] 课堂时间盒 ≤ 12 分钟，并安排讲评
- [ ] 教师布置与学生自选已分列，自选项不降低认知要求
- [ ] 真实素材已核验来源，未编造数据或书目信息

## 交叉技能

- → `learning-progression-builder`（把迁移层级接进进阶路径）
- → `competency-unpacker`（拆解起点能力，确认桥接起点站得住）
- → `practice-problem-sequence-designer`（桥接任务在练习序列中的位置）
- → `worked-example-fading-designer`（做半脚手架与撤除安排）
- → `error-analysis-protocol`（失败表现的错误类型归类）
- → `teach-back-evaluator`（迁移失败的"说不出理由"用回述补）
- → `cognitive-load-analyser`（检查桥接任务是否负荷过重）
- → `differentiation-adapter`（当差异来自能力而非桥接时改用分层）
