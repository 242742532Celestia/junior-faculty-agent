# 教师探究循环设计器

## 这个技能解决什么

教师自己就是最好的研究资源，但常见的几种空转让这件事做不成：

- 问题写成"为什么我们班学生不爱学"——没有观察对象，没有计量的东西。
- 半年改了五件事，哪件有用说不清，最后归因成"学生一届比一届差"。
- 只收集支持自己想法的证据，结论写得像论文，但换一届学生就不成立。
- 前后测用了不同难度的题，把题目难度差异当成了教学效果。
- 探究做完就结束，结论没进教案，第二年从头再来。

本技能把教师探究压成**一个现象、一个干预、一轮复测**的最小闭环，
并要求每个结论都能回溯到可复核的证据，而不是回溯到记忆。

## 什么时候用 / 什么时候不用

**用：**

- 想搞清某个反复出现的教学现象（作业错误、课堂沉默、实验组织混乱）
- 准备做一次小范围教学改革试点，需要设计前后对比
- 写教学论文或申报书，需要一个完整的探究过程记录
- 新教师第一学期想建立"用证据改进"的习惯

**不用：**

- 探究学生心理疾病或家庭困难（需要专门伦理与专业支持）
- 需要因果结论的正式研究（应走研究设计流程，见交叉技能）
- 单纯的数据分析（看已有数据即可）
- 只有一次课、无复测条件的临时安排

## 输入

**必填**

| 项 | 说明 | 缺省处理 |
|---|---|---|
| 待探究现象 | 能看见、能计数的行为或错误 | 无：先做一次错误率统计，把现象缩到一句话 |
| 可用的证据来源 | 作业、录像、观察记录、随堂测、成绩分布 | 无：默认从作业错误率开始 |
| 可用周次 | 一学期内能占几周 | 无：默认 6 周一轮，一学期 1–2 轮 |
| 学生样本 | 班级与人数 | 无：默认本班全体，做单组前后比较并标注局限 |

**可选**

- 往轮探究的结论与未解问题
- 课程目标与毕业要求支撑（探究问题须挂得上）
- 教师能实际控制的变量清单（设备、作业形式、提问方式、分组规则）
- 学生问卷或访谈的伦理审批状态

## 执行步骤

1. **把现象写成一句可检验的陈述**：含对象、行为、范围、频次或错误率，不含原因。
2. **定基线**：用现有证据算出当前水平（错误率、频次、比例），作为复测的比较基准。
3. **写竞争性解释**：至少 2 个互斥解释，其中一个必须与"教师可控的教学变量"有关。
4. **设计单一干预**：只改一个可控变量，写清改什么、保持什么、从哪节课开始。
5. **安排证据采集**：明确来源、样本、时间点、采集方式与已知局限。
6. **先写判定标准**：干预开始前就写下"达到什么算改善"的阈值，避免事后找标准。
7. **实施与复测**：按计划采集复测证据，与基线逐项对比。
8. **判类型并再循环**：结论只能是支持 / 不支持 / 混合三类，写清强度限制，生成下一个问题。

**表 F 干预设计**

| 项 | 填写 |
|---|---|
| 改变的变量 | 只写 1 个，且必须是教师可控的教学变量 |
| 保持不变的部分 | 教材、课时、班级规模、评价方式 |
| 起始课次 | 具体日期 |
| 实施次数 | ≥ 2 次（一次无法区分偶然） |
| 退出条件 | 出现＿＿情况即停止 |
| 复测方式 | 与基线同一指标、同一口径 |

**表 G 证据→结论推断链**

| 步骤 | 写什么 | 判定规则 |
|---|---|---|
| 1 事实 | 列出基线与复测的具体数值与出处 | 数值须能定位到具体材料 |
| 2 口径核对 | 两次测量的题、评分人、时间窗是否一致 | 不一致则标注"口径不可比" |
| 3 差值 | 复测 − 基线 | 写绝对差与相对变化 |
| 4 竞争解释检验 | 哪个解释与数据更相容，另一个为何被削弱 | 两个解释都要评 |
| 5 替代解释排除 | 列出数据无法排除的其他原因 | 至少 1 条 |
| 6 结论类型 | 支持 / 不支持 / 混合 | 只允许这三类 |
| 7 强度与再循环 | 结论强度限制 + 下一个问题 | 单组前后比较须写明强度有限 |

**表 H 结论与再循环**

| 项 | 填写 |
|---|---|
| 结论 | 支持 / 不支持 / 混合 |
| 关键证据 | 一条可复核的证据 + 出处 |
| 强度限制 | 如：无对照、单组前后比较、教师本人实施 |
| 对教学文件的修改 | 具体改哪一条教学安排 |
| 下一个问题 | 写成一句可检验的陈述 |

## 中国高校语境要点

1. **学期节奏**：16 周一学期，探究循环占 6 周，一学期最多 2 轮；排课冲突时优先保复测那一次。
2. **前后可比**：前后测必须同题、同分值、同一评分口径、在同一周内完成；换题必须给出等值说明。
3. **大班统计**：60 人以上用错误率与频次统计，不用均值；全班作业全批成本高时，可按"关键题"全批、其余抽样，并写明抽样方式。
4. **课程目标对齐**：探究现象必须能挂到某条课程目标上，否则结论无法写进教学文件。
5. **毕业要求支撑**：若课程支撑某毕业要求指标点，探究结论要说明是否影响该指标的达成证据。
6. **课程思政**：涉及价值讨论的环节，证据里加入"学生观点分布"，看是否只有一种声音。
7. **过程性考核**：干预若改变平时成绩构成或作业形式，须按学院程序调整课程大纲，权重合计必须为 100%。
8. **学生数据伦理**：作业与问卷数据去标识（匿名编号）；对外分享前移除可识别信息；问卷须说明用途与知情。
9. **教材与题目引用**：引用教材章节或题号时须与实际版本一致（附真实 ISBN，查不到写"待补充"），不得编造。

## 易错点

- ❌ 问题写成"学生为什么不爱学" → ✅ 写成含对象、行为、范围、错误率的现象句
- ❌ 一次改五个变量 → ✅ 只改一个可控变量，其余写进"保持不变"
- ❌ 只收集支持自己想法的证据 → ✅ 事先写出至少 2 个互斥解释
- ❌ 前后测换题换难度 → ✅ 同题同分值同口径同周完成，否则标注不可比
- ❌ 用及格率或平均分判定改善 → ✅ 用同一错误率或关键行为频次判定
- ❌ 把学生素质当干预变量 → ✅ 干预必须是教师可控的教学变量
- ❌ 无对照就宣称"我的教学起作用了" → ✅ 结论写"支持/不支持/混合"，并写明强度限制
- ❌ 证据靠回忆与印象 → ✅ 证据须可复核：作业、记录表、录像时间码
- ❌ 结论不进教学文件 → ✅ 结论表最后一列是"对教学文件的具体修改"
- ❌ 一次做多个问题 → ✅ 一轮一个问题，问题句超过 1 个就拆轮

## 自检清单

- [ ] 现象句含对象、行为、范围与数字，不含原因
- [ ] 基线已算出，且与复测同口径
- [ ] 至少 2 个互斥解释已写，其中一个指向可控教学变量
- [ ] 干预只改 1 个变量，退出条件已写
- [ ] 判定阈值在干预前写定，事后未改动
- [ ] 证据采集计划含来源、时间点、样本与已知局限
- [ ] 观察记录表只记预定义指标，粒度 5 分钟
- [ ] 推断链 7 步完成，结论类型合法
- [ ] 强度限制写明（含"无对照"这类前提）
- [ ] 结论已转成教学文件的具体修改
- [ ] 学生数据已去标识，伦理要求已核对
- [ ] 教材与题目引用与实际版本一致或写"待补充"

## 交叉技能

→ `hypothesis-generation`（把现象句转成可证伪假设与竞争性解释）
→ `experimental-design`（前后测、对照与最小实验设计）
→ `statistical-analysis`（错误率与差值的判读，避免过度解读）
→ `gap-analysis-from-student-work`（作业证据的差距分析）
→ `error-analysis-protocol`（错误样本的错因编码）
→ `lesson-observation-protocol-designer`（课堂证据的采集协议与记录表）
→ `he-context-adapter`（学期节奏、考核权重与数据伦理映射）
