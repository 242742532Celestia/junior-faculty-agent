# 讲师风格画像与讲法参考

## 这个技能解决什么

教师想"照着某位名师的路径讲自己的课"，多半只能凭印象模仿几个口头禅，结果**形似神不似**：语气像了，讲法逻辑没学到；更糟的是，把原课课件里的错误、名师对争议的个人主张、原课那些本学科并不成立的事实一起搬进了新课。

本技能给出**证据驱动**的两段路径：

1. **提取**——从课堂转写稿（transcript）、讲义、板书与幻灯关键帧（keyframe）里，把"这个人怎么讲"提取成一张**可核验的风格画像（teacher style profile）**：每条主张锚在具体证据位置，带频次与置信度（confidence）。
2. **翻译**——把画像翻译成**新课可直接执行的设计动作**，写进教学设计，而不是给出一串形容词。

两条**根本区分**，任何时候不能混：

- **风格 ≠ 身份**：只复现"怎么讲"，绝不复制这个人的生平、观点、背书、个人主张与立场。讲法参考（lecture reference）指的是**可观察的教学行为**，不是人格。
- **风格证据 ≠ 事实来源**：实录里出现的事实**不能自动**被搬到新课；新课涉及的概念、数据、结论、案例都要**独立核验**。

## 什么时候用

用：

- 教研组开展"名师讲法讲堂"，需要把一位教师（或一堂公开课）的讲法**讲清楚、可复现**时；
- 教师希望对齐某位名师的课堂组织方式，需要有证据的参照坐标时；
- 需要为某门课提炼"这门课应该怎么讲"的**讲法规范**时；
- 需要做**个人讲法诊断**，或把讲法迁移到**新课题、新学情、新课时**时。

**不用**：

- 要复现某人的**观点、主张、立场或背书**时（那是表达问题，不是教学设计问题）；
- 要搬运原课的**内容、题目、案例、图表**时（本技能迁移的是讲法，不是内容）；
- 手上只有二手描述时（那是印象，不是证据）；
- 需要课堂实时互动诊断或逐句评分时。

## 输入

**必填**（缺任一项时先按默认起草，并标为假设）：

- **课堂录像的转写稿**：按时间顺序、带时间戳的文本。
  - 只有录像、还没转写稿时：**可以先转写**，但必须说清——**转写质量就是本轮证据的上限**；转写错了、漏了、说话人混淆了，后续画像只能标低置信度。
  - 转写稿不完整（只有开头几页、只有片段）时，先说清缺哪一段、缺在哪里、缺段影响哪些判断。
- **板书 / 课件的关键帧影像**：用于提取**视觉风格**。影像不可读（拍糊、只有讲课头的画面、没有板书特写）时：**不得推断视觉风格**，输出模板写"无视觉证据，不推断"。
- **本次要讲的课题**（用户指定）：迁移的落脚点。课题不定，画像没有翻译对象。

**选填**（**没给就留空，不编**）：讲义、作业、问答记录；原课学科、课时与班额；目标新课学情与课时；录像授权方式。

**材料质量自检（动手前先做）**

| 自检项 | 判据 | 不满足时怎么办 |
|---|---|---|
| 转写完整性 | 从头到尾连续，无跳段 | 说明缺段位置，缺段处不作风格推断 |
| 转写分页 | 能翻到最后一页 | 有分页就翻到底；只读到开头视为未完成 |
| 时间戳 | 每段能否定位到时间点 | 无时间戳时用"第几页第几段"定位，并注明定位方式 |
| 关键帧可读性 | 板书/幻灯内容是否看得清 | 不可读则该维度留空，标"无视觉证据，不推断" |

## 执行步骤

**5 条原则**

1. **通读优先于检索**：主张须建立在**通读到底**的印象上；检索只核对频次与上下文。
2. **主张必须可追溯**：写不出**具体位置**的主张不成立。
3. **模式与偶发分开**：一次出现是**用语**，跨场次重复才是**习惯**。
4. **讲法与事实分开**：原课说了什么是**关于原课的证据**，不是新课可直接用的知识。
5. **画像必须能执行**：只写画像名字不合格，必须落到**具体设计动作**。

**步骤 1 · 确认派生物就绪**

- 按上表逐项核对材料；材料没准备好时**先说要什么**：哪段转写缺了、要几张什么角度的关键帧、录像是否可读。
- **不许拿不完整的证据硬编画像。** 宁可先交"材料清单 + 补齐后做什么"的短回复，也不要用半个证据源凑完整画像。

**步骤 2 · 从第 0 页读到最后**

- **不许只读开头。** 稳定特征多在中后段（重复、复述、临场调整），开头常是仪式化片段。
- 边读边记这些维度（与表 1 一致）：开场与过渡、口头禅与称呼、句式节奏、例证习惯、互动习惯、言说与视觉分工；每个维度记下**位置**与**原话片段**。

**步骤 3 · 用关键帧看视觉风格**

- 只在关键帧**可读**时提取：板书密度、幻灯构图与层级、用色、教师位置与手势、言说与屏幕的对应关系。
- 不可读或不存在时：视觉维度**留空**，填"无视觉证据，不推断"，并在自检清单勾选"已确认无视觉证据"。

**步骤 4 · 用检索验证假设**

- 通读形成的假设逐条回到转写稿检索，核对**频次**与**上下文**；检索的作用是**证伪**不是**发现**，命中一次不能支撑一条主张。
- 检索结果与通读印象冲突时**以频次与分布为准**，并把冲突写进置信度说明。

**步骤 5 · 区分"习惯"与"一次性用语"**

判定规则（本技能默认阈值，可按材料密度调整并写明理由）：

| 判定 | 条件 | 处理 |
|---|---|---|
| 一次性用语 | 只出现 1 次，或每次都处在同一具体情境 | 不进画像；确有价值者列为"单次用语" |
| 偶发特征 | 重复出现但集中在同一节课、同一单元 | 降置信度，标注"样本内集中，跨场次未验证" |
| 稳定习惯 | 次数达到默认阈值，且**分布在 ≥ 2 次课 / ≥ 2 个教学环节** | 进画像，标注频次与覆盖范围 |

- 阈值写清楚是多少；材料不足时宁可标"样本不足，不下判定"。

**步骤 6 · 形成风格画像**

- 每条主张写成一句可核验的陈述：**在这位教师的课堂里，〈可观察的行为〉，证据在〈位置〉，出现〈频次〉，置信度〈高 / 中 / 低〉**。
- 置信度按"证据强度 × 覆盖广度"给出：多处跨场次重复且上下文一致为高；重复但集中或受转写质量影响为中；单次或推断为低。**低置信度项必须标出，不得单独支撑迁移决策。**

**步骤 7 · 迁移到新课**

- 每条主张翻译成**具体设计动作**：不说"他善于用具体例子"，而说"每个核心概念后先给一个来自学生生活的具体例，再给一个抽象模型，二者成对出现"。
- 迁移分三类：**直接迁移**（讲法结构）；**需改写迁移**（原讲法依赖特定学科内容时，说明在目标学科里怎么换载体）；**不可迁移**（个人主张、原课事实、原课特有学科内容、原课评价立场——写入不可迁移清单）。
- **新课涉及的事实独立核验**：原课说过的数据、结论、案例，在新课里使用时重新找依据；找不到依据就不写。产出落到教学设计文件（大纲、单元教学设计、讲稿提纲、幻灯大纲）。

## 中国高校语境要点

- **实录噪声**：口头语、方言词、学生提问、板书声、点名与铃声不是风格信号，先剔除；但**课堂问答记录**是一手证据（教师如何接住学生的错误）。
- **课时结构与班额差异**：一节课与两节连堂的节奏、复述密度、互动次数都不同；大班与录播课同样不同。名师在大班里的"一次点名 + 一次集体应答"到小班会显得笨拙——**迁移前按目标课结构与班额重排互动动作**。
- **语速与信息量**：转写后的文字量不等于课堂信息密度；把"话多"当"讲得清楚"是常见误判，要看**单位时间的概念推进量**。
- **PPT 与板书混用**：高校课堂常见"一半 PPT 一半板书"；迁移时不只搬视觉风格，还要搬**分工方式**（哪些内容留白板现场写）。
- **学生肖像、声音与录像授权**：课堂录像含学生面部与声音，属个人信息；未获授权的，不在教研材料中保留可识别影像。录制、留存、调阅与二次使用按学校现行规定执行。学生发言作**课堂互动证据**时引用前脱敏。

## 易错点

- ❌ 只读开头就下结论 → ⚠️ 稳定特征多在中后段 → ✅ 从第 0 页读到最后，缺页先说明。
- ❌ 把一次出现的口头禅当风格习惯 → ⚠️ 一次出现是**用语**，不是**模式** → ✅ 按频次与跨场次分布判定。
- ❌ 用"我觉得他比较……"当证据 → ⚠️ 印象无法被他人复核 → ✅ 每条主张指回具体位置与原话片段。
- ❌ 没有可读关键帧却写视觉风格 → ⚠️ 凭空补全，读者会当观察结论 → ✅ 填"无视觉证据，不推断"。
- ❌ 把风格和学科事实混在一起 → ⚠️ 原课数据被当成新课的既定知识 → ✅ 事实独立核验，无依据不写。
- ❌ 迁移只写画像名字不给具体动作 → ⚠️ 下游拿到的是形容词 → ✅ 每条主张转成可执行动作，指明落在哪个文件。
- ❌ 用画像模仿身份（生平、观点、背书） → ⚠️ 这已不是讲法参考，是替别人代言 → ✅ 只提取可观察的教学行为。
- ❌ 同一套画像套到所有课程 → ⚠️ 讲法受学科、班额、课时结构约束 → ✅ 按目标课题、班额、课时结构分别给动作。
- ❌ 证据位置写"某处""大约在中间" → ⚠️ 无法核验的指认等于没有证据 → ✅ 写时间戳、页码或关键帧编号。
- ❌ 不标置信度 → ⚠️ 下游把低置信度主张当定论执行 → ✅ 每条主张标高 / 中 / 低。
- ❌ 画像越写越长却不可执行 → ⚠️ 篇幅淹没可执行部分 → ✅ 不能落到设计动作的主张移出画像。
- ❌ 材料不全也照样出完整画像 → ⚠️ 缺段处的风格被静默脑补 → ✅ 先交材料清单与补齐计划。

## 方法论依据

本技能不编造文献编号，方法论基础是以下四条通用实践原则：

1. **基于证据的风格提取**：每条关于"怎么讲"的主张都可追溯到具体证据位置，并伴随频次与置信度；不可追溯的印象不构成主张。
2. **从描述到设计指令的转译**：描述性结论只有被翻译成具体设计动作才具备教学价值，这是"翻译段"的理由。
3. **迁移与不迁移的分离**：讲法可迁移、身份不可迁移、事实须独立核验——避免"学风格"变成"抄内容"或"替人代言"。
4. **不从"像"推导"是"**：相似的外在表现不保证相同的教学机制；迁移时保留**可观察行为与组织结构**。
