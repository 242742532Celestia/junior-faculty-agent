# 教学幻灯片设计器

## 这个技能解决什么

教师做课件最常见的失败不是"不会做"，而是**把教案抄成了幻灯片**：
一页塞九条要点、页标题写成"其他"、讲稿一个字没有、图表贴上去不标来源。
这样的 PPTX 技术上合格，作为教学材料是废的。

而这些问题**肉眼难发现、评审也难说清**——"这页字太多了"是感受，
"要点超过六条、单条超过三十字、正文没有讲稿备注"是判据：
前者吵不出结果，后者可以自动判定。

本技能给出从教学目标到**逐页课件脚本**的设计规则，并把每条规则配成
**可判定的阈值**：一页一个认知任务，标题是一句可判真假的话，
讲解进讲稿，事实带来源。

> **本技能只管"写什么"，不管"怎么生成文件"。**
> 规格 JSON 的字段契约、版式几何、字号色板、PPTX 生成命令、溢出判据与
> PowerPoint 实开验收，全部在 `teaching-slide-builder`。
> 两者的边界：**本技能产出内容与阈值，那个技能产出文件与证据。**

## 什么时候用

用：

- 已有教案或讲稿，要转成能投影放映的课件时；
- 已有 PPT，但拿不准"是不是太满""标题有没有信息量""图要不要标来源"时；
- 给学习平台准备可下载课件（要求可编辑、上传不跑版）时；
- 做微课、翻转课堂等短时高密度课件，需严格控页数时；
- 教研室互审课件，需要一套**共同判据**而不是个人口味时。

**不用**：只需要海报或单张图时；只需要纯文字讲稿时；做的是**研究成果汇报**
（从论文重构叙事）时；需要实时互动与动画演示时。

## 输入

**必填**（缺项时先按默认起草并标为待核验假设）：本节课的**认知目标**
（学完能做什么、能说出什么）；时长与页数预算；受众（年级、专业背景、
是否跨专业）；素材（要点、图表、公式、案例）。

**选填**（**没给就留空，不编**）：授课设备（投影 / 智慧黑板 / 机房 / 板书为主）；
交付形态（只放映 / 发学习平台 / 存档送审）；已有课件文件；数据来源清单与可公开范围。

**不编造原则**：本技能不生成事实性内容。标题、要点、数据、来源必须来自输入素材
或教师本人确认；宁可留空白页让人补，也不要替教师杜撰一个"研究表明"。

### 阈值的机器可读形式（唯一出处）

下面这段是**阈值数字的唯一出处**。审查器（`teaching-slide-builder` 的
`slide_spec_lint.py`）里有一份同名字典，仓库守卫会**机械比对两者**——
改了这里的数字却忘了改代码（或反之），守卫立刻变红。

```python
LINT_THRESHOLDS = {
    "max_bullets": 6,          # 一页最多几条要点
    "max_bullet_chars": 30,    # 单条要点最多几个字符
    "max_title_chars": 20,     # 页面标题最多几个字符
    "max_body_chars": 120,     # 一页正文最多几个字符
    "max_image_bullets": 4,    # 图 + 要点时，要点最多几条
    "min_notes_chars": 10,     # 讲稿最少几个字符
    "max_notes_chars": 800,    # 讲稿最多几个字符
}
```

## 执行步骤

### 第 1 步：锁定这一页要解决的认知任务

不写"讲什么知识点"，要写"**看完这页学生应该能做什么 / 说出什么**"。
一个认知任务对应一页，一页解决不了两个任务就拆页。「讲误差传播」不合格，
「让学生能判断一次测量中哪些环节引入了误差」合格。写不出合格版本，
说明这页的教学目标本身没定，先回去定目标。

### 第 2 步：判定该页属于哪种版式

**表 1 · 七种版式的选择判据**

| 版式 | 什么时候用 | 不要用它的信号 |
|---|---|---|
| **title** | 整节课的开场，**全文唯一且必须在第 1 页** | 想再放一个扉页 |
| **bullets** | 一组并列要点（不超过 6 条），以文字为主 | 要点超 6 条却不想拆页 |
| **two-column** | 两组内容需**同页对照** | 两组之间无对照关系，只是凑版面 |
| **image-focus** | 一张图/表/公式是本页唯一信息主体 | 图只是装饰，正文才是重点 |
| **quote** | 把一句权威表述立起来做锚点 | 引一句自己写的话 |
| **section** | 分节、换章、转场，交代"现在讲到哪" | 想用它做第二个封面 |
| **blank** | 现场手写、板书、演算，放映时需要留白 | 还没想好这页要干什么时 |

> 各版式在规格 JSON 里的字段要求（哪些字段必填、图片怎么放、两栏怎么分）
> 见 `teaching-slide-builder` 的「规格 JSON 的字段契约」。

### 第 3 步：写断言式标题

页标题不是**主题词**，是**这一页的结论**。断言式标题（assertive title）是可判真假的
陈述句：「其他」不合格，「三种数据来源里只有一种能追溯到原始记录」合格；
「实验步骤」不合格，「每一步都保持低温，直到 pH 回到中性」合格。

标题长度上限 **20 字**（`max_title_chars`）。审查器对纯分类词
（其他、概况、总结、要点、背景、方法等）给出 INFO，**加了限定语的分类词它抓不到**，
断言性主要靠你自己把关。自检法：把标题念出来，若像"这一节讲……"就重写。

### 第 4 步：切分要点

每条要点是**一个完整命题**（主谓宾齐全、可独立成立），不是一个词组。

**表 2 · 长句拆分前后对照**

| 写法 | 问题 | 拆后 |
|---|---|---|
| 细胞膜主要由磷脂双分子层构成，其中还镶嵌着各种蛋白质，负责物质运输、信息传递等功能 | 一条塞了三个命题 | ① 骨架是磷脂双分子层<br>② 镶嵌的蛋白质承担物质运输<br>③ 同一批蛋白质还参与信号传递 |

要点数上限 6 条（`max_bullets`），单条上限 30 字（`max_bullet_chars`），
一页正文合计上限 120 字（`max_body_chars`）。**触线就往讲稿里搬，不要缩字号。**

### 第 5 步：把讲解移进讲稿

幻灯片给**观众**看，讲稿给**讲授者**用，两者职责分离是本技能的核心机制。

**表 3 · 内容该放哪儿**

| 内容类型 | 幻灯片正文 | 讲稿备注 |
|---|---|---|
| 核心命题 | 写（断言式标题 + 要点） | 不重复，只写"为什么这样讲" |
| 举例、类比、故事 | 不写 | 写（口述独有的价值） |
| 推导过程、计算步骤 | 不写 | 写 |
| 过渡句、提问 | 不写 | 写 |
| 数据与图表 | 写结论句 + 标来源 | 写口径、读图顺序、常见误读 |
| 易错点与边界条件 | 不写 | 写 |

讲稿长度控制在 10–800 字（`min_notes_chars` / `max_notes_chars`）：
少于 10 字说明撑不住这一页；多于 800 字说明该拆页。

**讲稿只有一份**：它写在每页的 `notes` 字段里，讲义从课件**导出**，
不另写一遍 —— 两份讲稿必然漂移。

### 第 6 步：标来源

凡出现外部事实、数据、统计量、引文的页面，来源字段必须有内容。
自绘示意图写"示意图为作者自绘"；引用他人数据写"来源：作者，年份，出处名称或链接"；
改绘他人图表写"来源：改绘自作者，年份，图表出处"；教材内容写"来源：教材第 X 章"，
不确定就只写教材名。

**事实性内容不得编造**：作者、年份、页码不确定就留空待补，
或换成不依赖具体出处的表述。绝不生成看起来很真的假引用。

### 第 7 步：把脚本交给生成器

本技能到此为止。**逐页脚本 → PPTX 文件**这一步交给 `teaching-slide-builder`：

```powershell
python scripts/build_pptx.py spec.json -o slides.pptx --check
python scripts/slide_spec_lint.py spec.json
```

生成命令、规格 JSON 的完整示例、版式几何与字号色板、溢出判据、
以及**PowerPoint 实开 + 逐页导出拼版**的验收流程，都在那个技能里。

> 交接时**必须一起交付**：PPTX 本体 + spec JSON（可编辑源）+ 逐页脚本表。
> 只有 PPTX，后续改一个字就得重排 30 页。

### 第 8 步：人眼过一遍

自动检查查不出版面问题。生成后必须打开放映一遍：文字有没有溢出或压住分隔线；
有没有字小到后排看不清；图有没有压住文字、图例有没有被裁掉；
实际讲完是否落在课时预算内；有没有哪一页不看幻灯片讲不下去
（讲稿没写够），或离开你就讲不下去（内容全写在幻灯片上）。

## 中国高校语境要点

- **学时与页数配比**：经验值是每 45 分钟授课约 10–15 页（含封面与分节页），
  "新内容页"不超过一半，其余留给提问、演示与练习。以各校校历与班型为准。
- **大班 vs 小班**：合班百人以上的大班，每 45 分钟新内容页控制在 6–8 页，
  多留提问与演示；研讨课可一页一个论点，但要更频繁停下来做口头检查。
- **投影 vs 智慧黑板**：智慧黑板可延展，适合现场手写推导，此时关键步骤应**留白**
  而非预先写满；投影条件下正文少字、字号偏大。
- **机房与实验课**：机房课页面以"操作步骤 + 预期现象 + 出错排查"三段为主；
  实验课的数据与误差分析至少占一页，否则学生复盘没有锚点。
- **混编班差异**：专业跨度大的班级，同页术语必须中英并列；跨专业例子不能默认共享背景，
  讲稿里补一句"为什么这个例子对你们也成立"。
- **课件要发到学习平台**：交付物**必须**含可编辑源（规格 JSON 或 PPTX 本体）与可编辑文本，
  不要只交 PDF；上传版本要保留页内标题结构，便于课后检索。需存档的再留一份 spec JSON
  并记下生成命令与阈值设置。
- **讲稿与课程思政**：讲稿是课程思政案例的天然落点——案例写在讲稿里、正文只留结论句，
  既不挤占版面，又能在提问环节自然引出。**不要**把思政语录做成单独一页大字海报
  占掉黄金时间。

## 易错点

- ❌ 把教案抄成幻灯片 → ✅ 一页只承担一个认知任务；举例、推导、过渡全部进讲稿。
- ❌ 要点当句子写（词组拼贴） → ✅ 每条要点是主谓宾齐全、可独立成立的命题。
- ❌ 页标题写成"其他""总结""背景" → ✅ 标题写成可判真假的断言句；加了限定语的分类词要靠自己改。
- ❌ 讲稿写进正文 → ✅ 正文只留结论与要点；讲稿进备注字段，放映时在备注视图可见。
- ❌ 出现"如上图""如前所述" → ✅ 幻灯片是并置版面，线性指代在观众眼里不成立；
  改成"这张图里""上一页的结论是"。
- ❌ 有数据有引文却没标来源 → ✅ 事实性页面一律补来源字段；出处不确定宁可留空待补，
  也不编一个像真的引用。
- ❌ 把 PPTX 当唯一交付物 → ✅ 同时交付 spec JSON 与可编辑源；平台上传、后续重生成、换图都靠它。
- ❌ 用图片承载必须口述的信息 → ✅ 图上只放必须被"看"的信息；必须被"听"的写进讲稿，
  不要截文字冒充讲解。
- ❌ 每页都塞满 6 条以上 → ✅ 六条是上限不是目标；超过 4 条就该怀疑这页承担了两个任务。
- ❌ 封面做成多页 → ✅ title 版式全文只出现一次且在第 1 页，章节过渡一律用 section 版式。
- ❌ 触线了就缩字号 → ✅ **缩字号是错解**：字号是版面预算的一部分，
  缩了就等于把内容密度藏起来。触线就往讲稿里搬。
- ❌ 阈值凭印象定 → ✅ 阈值写在上面那段机器可读块里，守卫会比对代码与文档；
  改了要两边一起改。

## 自检清单

- [ ] 每一页都写清了要解决的认知任务，一页只做一个
- [ ] 正文页标题都是可判真假的断言句，没有纯分类词
- [ ] 每页标题不超过 20 字
- [ ] 每页要点不超过 6 条，单条不超过 30 字
- [ ] 每条要点都是完整命题，不是词组拼贴
- [ ] 每页正文合计不超过 120 字
- [ ] 幻灯片正文里没有线性指代（"如上图""如前所述"）
- [ ] 每处外部事实或数据都能追溯到来源
- [ ] 没有编造的数据、引文或出处
- [ ] 每个正文页都有讲稿，长度在 10–800 字之间
- [ ] 讲稿写了举例、推导、过渡与易错点，不是把正文重抄一遍
- [ ] **讲稿只有一份**（在 `notes` 里），讲义从它导出
- [ ] 版式选择逐页判过，七种版式没有混用
- [ ] 有图的页面都写了图注，图 + 要点不超过 4 条
- [ ] 封面唯一且在第 1 页，章节页用的是 section 版式
- [ ] 占位符（待补/待定/TBD/XXX 等）已清零
- [ ] 每页有稳定 id（`P1`…）
- [ ] 触线的阈值都写进了处置记录表，理由是"这一页教学上成立"
- [ ] 已交接给 `teaching-slide-builder`：逐页脚本 + spec JSON

## 方法论依据

- **认知负荷理论（Sweller 的认知负荷理论）**：工作记忆容量有限，
  一页同时呈现的要素越多，外在负荷越高。据此设定要点数、单条字数与正文总字数上限
  ——这些阈值是教学经验值，不是普适定律。
- **Mayer 的多媒体学习原则**：信号词原则、冗余原则、空间邻近原则。据此规定
  "标题即结论"、并置版面不用线性指代、图表与结论句同页相邻。
- **并置媒介的指代失效**：幻灯片属于并置媒介，观众看到的是整页而不是一条线性序列；
  "如上图所示"在纸面上成立、在并置版面里失效，因此改为显式指认本页元素。
- **幻灯片与讲稿的职责分离**：幻灯片是观众的视觉通道，讲稿是讲授者的言语通道。
  据此把举例、推导、过渡、易错点移入讲稿，正文只保留可被视觉快速扫描的结论与要点。
- **阈值的可判定性**：教学经验值只有变成**可判定的数字**才能进入自动审查，
  才能让评审从"我觉得这页太满"变成"这一页 7 条要点，超上限 1 条"。
  同时阈值必须**只有一个出处**，否则文档与工具会各说各话。
