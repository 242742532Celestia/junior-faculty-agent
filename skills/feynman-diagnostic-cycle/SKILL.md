# 费曼式诊断循环

## 这个技能解决什么

教师用提问检查理解，得到的是"懂了 / 没懂"。这类回答既不能定位问题，也不能设计下一步干预。

本技能把诊断对象从**教材**换成**学习者当前的解释**：没有初始解释，就没有诊断。

核心机制很简单：让学习者**讲给外行听**。讲不下去的地方——跳步、术语替代、错误因果、遗漏——就是理解缺口的候选位置；把它们逐个找出来，用最少的问题补上，最后换情境验证机制是否真的被掌握。

这 8 步是诊断工具链，不是课堂表演。

## 什么时候用

用：

- 学生"都会"但题目总做错，怀疑是概念理解断层而非计算失误时；
- 单元开始或关键转折点，需要定位前概念缺口时；
- 需要为分层任务、补救教学定位具体断点时；
- 学习者用术语堆砌、只会复述定义却无法举例解释时；
- 需要为自学者设计一条可执行的"自查—纠错—迁移"路径时。

**不用**：

- 只需要一次随堂测或单元测验的成绩分析时（改用测验与错因分析工具）；
- 只需要给出标准答案或讲清一遍概念时；
- 学习者尚无任何初始解释（零基础）时——先做显性讲解，再进入本循环；
- 需要逐句实时判分的自动化测评时（本技能的产出是诊断设计与记录工具，不是判分器）。

## 输入

**必填**（缺任一项时先按默认起草，并在需人工核验清单中标为假设）：

- 目标概念；
- 学习者已有解释的载体（口头 / 书面 / 问卷）；
- 课时；
- 听众设定（讲给谁听）。

**选填**（**没给就留空，不编**）：

- 教师是否允许直接给答案；
- 可用的诊断数据（既往作业、测验错因）；
- 历史误解清单。

## 执行步骤

**开始前先定三个约束**

不写清就开始，是本技能最常见的失败。

| 约束 | 要写清什么 |
|---|---|
| 概念边界 | 本轮只解释哪个核心概念；明确**不覆盖**什么 |
| 听众 | 讲给谁听（例如没学过该概念的本科生、跨专业同学、"完全外行"） |
| 教师约束 | 学习深度要求；追问失败后是否允许直接给答案或给支架 |

**5 条核心原则**

1. **学习者先讲，教师后介入**：先收集解释，再给权威定义；定义先出，学习者就不再暴露自己的理解。
2. **一次只修最小缺口**：从解释里找当前最关键的 1–2 个断点，不一次砸整本教材。
3. **追问优先于代答**：先用最少的问题帮学习者自己补全因果链；只有多次追问仍卡住、且教师约束允许时，才给必要事实或支架。
4. **理解必须经得住改写和迁移**：能背术语 ≠ 理解。
5. **材料只提供事实，不抢占初始解释**：让学习者先有话说，材料后给。

**8 步循环**

| 步骤 | 这一步在诊断什么 | 产出什么证据 |
|---|---|---|
| 1 先讲给外行听（不许查资料，用自己的话） | 是否存在可独立启动的解释；是否只会复述定义与术语 | v1 原始解释（录音或书面） |
| 2 找到最小卡点 | 当前最关键的 1–2 个断点：跳步、术语替代、错误因果、遗漏 | 最小缺口清单（学习者自陈卡点 + 旁观者判断） |
| 3 用问题把因果链补出来 | 缺口处的因果推理是否成立、环节是否齐 | 追问序列表 + 每问之后的回答证据 |
| 4 再讲一遍（给结构提示） | 结构是否补上、表述是否变得更可检验 | v2 解释（保留与 v1 可比较的差异） |
| 5 去掉刚才用过的术语 | 理解是否依赖术语而非机制 | 术语剥离清单 + 去术语版解释 |
| 6 拆穿自己的类比 | 类比的结构映射在哪里断裂 | 类比失效点表（至少 1 个失效点） |
| 7 换一个陌生情境 | 机制能否迁移到表面不同的任务 | 迁移任务作答记录（含反例或边界条件） |
| 8 合成费曼学习记录 | 本轮诊断结论与下一轮起点 | 费曼学习记录（7 字段） |

补充要求：

- 第 2 步要**让学习者自己判断卡在哪**，不要只给一个 AI 评分代替自陈。
- 第 3 步每个问题只针对**一个已定位缺口**，并写明该问题针对什么、出现什么理解证据后停止。
- 第 4 步给少量**结构提示**指向因果结构，不复述标准答案。
- 第 5 步只剥离**学习者自己用过**的词，不预先给一张与学习者表达无关的术语黑名单。
- 第 6 步由学习者自己提类比，再问"哪里像 / 哪里不像"，**至少逼出一个失效点**。
- 第 7 步离开原始案例；可限制使用概念名称，迫使依靠机制解释；最好加一个反例、边界条件或假设改变。

**费曼学习记录（7 字段）**

1. 我现在能解释什么
2. 我一开始怎样理解
3. 我发现自己卡在哪里
4. 我的新版解释
5. 我的类比及其失效点
6. 我能解决的新问题
7. 我仍然不能解释什么，以及下一轮学习目标

它**不是庆祝页**，是下一轮循环的起点。

**表达红线**

下列词是**规划语言**，只能出现在教师侧 brief 与对话里，**不得出现在学生可见标题或栏目**：

| 只能出现在教师侧 brief 与对话里的词 | 学生可见标题写法 |
|---|---|
| Teach-back | 先把它讲给一个没学过的人听 |
| Jargon Challenge | 换掉这几个词，再讲一遍 |
| 费曼循环 | 本轮自检三步 |
| 概念定界 | 本轮只解决这一个概念 |
| 缺口诊断 | 你讲到哪一步卡住了？ |
| 类比破坏测试 | 这个类比会在哪里失效 |
| v1 / v2 / v3 | 第一次讲 / 改完再讲 / 换情境再讲 |

**能力边界（如实告知，不得越界承诺）**

生成式或静态页面**无法**对学习者实时输入的每一句做动态诊断。可用三条路径如实说明：

1. 用开放式任务收集解释，并用检查点支持自检；
2. 用同伴 / 教师角色模拟苏格拉底式追问；
3. 需要逐句诊断与持续保存解释版本时，在工作台对话中运行循环。

**不得把静态或预生成页面描述成能实时判分。**

## 中国高校语境要点

- **课时换算**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。8 步循环建议拆成 **2–3 次课**推进，不留成"一节课讲完费曼法"。
- **形成性证据的处理**：若计入平时成绩，须在**第一周**公布评分规则与**申诉方式**；否则只记不评。
- **学术诚信**：AI 不能代写解释稿；学生要能口头讲清自己卡在哪，解释稿须学生本人完成。
- **数据合规**：含姓名学号的作答记录不进外部 AI 工具，统一用临时编号后再导入或分享。
- **班级规模**：小组互评与同伴追问按学院分组上限安排；未给标「待补充」。

## 易错点

- ❌ 先给标准答案再让学生讲 → ✅ 先收集 v1 原始解释，权威定义最后才出现。
- ❌ 一次修所有缺口 → ✅ 每轮只修 1–2 个最小缺口，其余留到下一轮。
- ❌ 追问变成代答 → ✅ 每个问题只针对一个已定位缺口；多次追问仍卡住、且教师约束允许时才给必要事实或支架。
- ❌ 术语黑名单与学习者表达无关 → ✅ 只剥离学习者自己用过的词。
- ❌ 类比不逼失效点 → ✅ 至少逼出一个"哪里不像"，否则第 6 步不算完成。
- ❌ 迁移还在原案例 → ✅ 换表面不同的情境，最好加反例、边界条件或假设改变。
- ❌ 把静态页面说成能实时判分 → ✅ 按能力边界三条路径如实说明。
- ❌ 单次解释就下"已掌握"结论 → ✅ 至少要过改写（去术语）与迁移两关。
- ❌ 教师急着纠正 → ✅ 教师后介入，先收集再纠正；解释先于定义。
- ❌ 概念边界不清，一次想覆盖整章 → ✅ 一轮只解决一个核心概念，其余明确列为不覆盖。

## 自检清单

- [ ] 已写明概念边界、听众设定、教师约束三个约束
- [ ] v1 解释在学习者查阅资料之前取得
- [ ] 最小缺口限定在 1–2 个，且注明了类型
- [ ] 第 2 步有学习者自陈卡点，不只有外部评分
- [ ] 每个追问只针对一个缺口，并写明停止条件
- [ ] v2 解释保留下来，可与 v1 逐点比较
- [ ] 术语剥离只涉及学习者自己用过的词
- [ ] 类比由学习者自己提出，并至少记录 1 个失效点
- [ ] 迁移情境与原案例表面不同，含反例或边界条件
- [ ] 费曼学习记录 7 字段齐全，且写成下一轮起点
- [ ] 学生可见标题中不含规划语言（Teach-back、费曼循环、v1/v2 等）
- [ ] 交付说明未把静态或预生成页面描述为能实时判分
- [ ] 评分规则与申诉方式已在第一周公布，或明确只记不评
- [ ] 含学生身份的作答记录已按临时编号脱敏
