# 学科教学法内容知识发展器

## 这个技能解决什么

- 新教师"知识讲对了，课讲不成"：同一段讲稿对三个班用同一套讲法，学生在哪一步断掉说不清。
- 老教师常说"这章难"，但说不清难在哪一步、学生的错误理解长什么样。
- 教研安排全是讲座，课后没人知道下一节课该改哪一句。
- 评课时只说"他讲得比我好"，指不出好在一个可复制的动作上。
- 想用点技术，第一反应是加工具，而不是先想这个内容到底怎么讲才讲得进去。

本技能只处理一层能力：**把学科内容转成学生能进入的教学化表征**。
诊断要基于证据，练习要当堂产出材料，复测要有判据。

## 什么时候用 / 什么时候不用

**用：**

- 新教师入职后第一个学期的主题讲法培养
- "讲了三遍学生还错"的某个顽固知识点
- 公开课前打磨某个具体概念的讲法
- 教研组共建某一主题的讲法，避免各讲各的
- 骨干教师培养方案里的能力诊断环节

**不用：**

- 内容本身的正确性核查（那是同行审阅内容的活）
- 课堂组织、纪律与时间管理（走课堂观察与课例研究）
- 学生学习困难的心理与学业支持
- 课程整体重构（走课程层面的工具）

## 输入

**必填**

| 项 | 说明 | 缺省处理 |
|---|---|---|
| 待发展的内容主题 | 一个可教知识点，1 学时内能覆盖 | 无：先把章节标题压缩成一个判断或一个模型 |
| 教师现有教法素材 | 教案、课件或录课片段 | 无：用一次 45 分钟课的现场速记代替 |
| 目标学生层次 | 年级、已修课程、班级规模 | 无：按本科大二、班级 40–60 人假设，并标注 |
| 可用学时与练习环境 | 能拿出多少备课时间 | 无：按 4 周、每周 2 小时设计 |

**可选**

- 学生错误作答样本（作业、随堂测、答疑记录）
- 教材与参考书
- 往轮成绩分布与阅卷中的高频错误
- 同行或督导的听课记录

**无错误样本时的规定**：先布置一次 5 分钟诊断小测（3 道题 + 1 道"让学生解释为什么"的题），
用它生成样本，再开始诊断。不得凭经验断言学生的误区。

## 执行步骤

1. **确定最小单位**：把主题压缩成"一节课能教会的一个说法 / 一个模型 / 一个判断"，
   而不是章节标题。压缩不成功说明主题太大，先切小。
2. **收三类证据**：教师怎么讲（观察或录像）、学生怎么答（作业样本）、学生怎么想（学生解释原话）。
3. **逐成分诊断**：对表征、学生先备、关键障碍、类比、例题变式、提问话语、教学常规 7 个成分
   逐一判等级并附依据原话。
4. **选缺口**：按"学生出错频次 × 改动成本"排序，单周期只取前 3 个，其余标次优先。
5. **设计练习**：每个缺口配一个当堂产出物（讲稿片段、一个类比、两道变式题、一组追问），
   备课 ≤ 40 分钟、产出 ≤ 10 分钟。
6. **排反馈**：同行 1 人 + 学生 1 组 + 自评三路来源；反馈在提交后 48 小时内，
   每条反馈必须指向"下一次课的一个具体动作"。
7. **定复测**：下一次课在同一内容点复测同一维度，用同一套等级锚点比对。
8. **归档**：形成一张"内容 × 表征 × 障碍 × 讲法"卡片，进个人教学档案。

**时间盒**：诊断一次 90 分钟；练习任务每次 ≤ 40 分钟备课；反馈 48 小时内；复测随下一节课。

## 中国高校语境要点

1. **学时现实**：45 分钟 1 学时，真正留给学生练习的时间通常 10–15 分钟，表 C 的练习按这个时长设计。
2. **大班可规模化**：练习产出物优先选"答题卡 / 随机点名 / 一句话纸条"，一次收齐 60–150 份。
3. **过程性考核**：练习任务可计入平时成绩；平时与期末的百分比必须写死且合计 100%（常见区间 30–50% 平时，以课程大纲为准）。
4. **教材**：教材是内容表征的重要载体。给参考书时附真实 ISBN；查不到写"待补充"，不得编造 ISBN。
5. **毕业要求支撑**：每个发展主题说明支撑的毕业要求指标点；属工程教育认证课程时，写明对应的能力项名称。
6. **课程思政**：把价值引领写进表 C 的"核心表述"或"问题导入"，用本专业真实问题引出，不贴标签。
7. **教案规范**：产出物要能直接贴进学院统一教案模板（教学目标、重难点、教法学法、课时安排）。
8. **工作量**：诊断会与互评按学校教研规定登记学时或折算工作量，各校口径不同，未查到写"按校规定另行申报"。

## 易错点

- ❌ 诊断写成"教学基本功不足" → ✅ 判到具体 PCK 成分，并附课堂原话证据
- ❌ 一轮改 5 个点 → ✅ 单周期缺口 ≤ 3，其余标次优先，留到下一轮
- ❌ 练习任务是"多讲几遍" → ✅ 练习必须产出材料：讲稿片段、类比、变式题或追问串
- ❌ 误区由教师凭经验断言 → ✅ 每条误区必须有学生错误作答或原话支撑
- ❌ 类比不写失效边界 → ✅ 必须写"在哪一点不成立"，否则迁移时反噬
- ❌ 只诊断不复测 → ✅ 每个缺口指定复测维度、目标等级与判定阈值
- ❌ 反馈只说"讲得不错" → ✅ 反馈句式固定为"证据 + 下一次课的一个动作"
- ❌ 抄教材写讲稿 → ✅ "学生先备"与"关键障碍"两项教材不提供，必须自己填
- ❌ 发展计划脱离学期进度 → ✅ 主题必须是下一节真实课能用的

## 自检清单

- [ ] 主题已压缩为一节课能教会的最小单位
- [ ] 教师怎么讲 / 学生怎么答 / 学生怎么想 三类证据齐全
- [ ] 8 个 PCK 成分逐项有等级，且依据引自课堂原话
- [ ] 缺口 ≤ 3 并已排序，其余标次优先
- [ ] 每个缺口具备练习任务 + 反馈来源 + 复测点三件套
- [ ] 表 C 含至少 1 种非文字表征，且类比写了失效边界
- [ ] 每条误区都有学生错误证据，不是教师断言
- [ ] 观察记录表按 5 分钟粒度填满，含原话与学生响应
- [ ] 推断链 7 步完成，等级判定引用了具体原话
- [ ] 材料能直接贴进学院教案模板
- [ ] 参考书附真实 ISBN 或写"待补充"，无编造
