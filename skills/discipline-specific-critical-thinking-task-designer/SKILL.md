# 学科批判性思维任务设计器

## 这个技能解决什么

教师布置的"批判性思维训练"最后变成读一篇文章写 500 字感想，结论雷同、格式统一，评分只能看字数与通顺度。

说"评价这篇论文的方法是否可靠"，学生背模板作答：先夸优点、再列三条局限、最后提一条建议——同一套框架贴在任何题目上都成立。

任务要求"设计方案"，学生交来的是例题换了数字，教师无法判断他们是在做设计还是在回忆例题。

评分标准写"论述深刻"，两位教师给出的分数能差 20 分；任务里塞了查文献、做实验、写报告、答辩四件事，三周做不完。

批判性思维任务的关键不在"讨论观点"，而在**强制学生完成该学科特有的思维操作**——检查前提与边界、分解误差来源、构造反例、在约束下取舍、跨尺度比较。这个技能把"批判性思维"翻译成本学科的思维操作清单，再据此设计任务、量规与权重，并内置**防蒙混检查**与**权重合计校验**。

## 什么时候用

**用**：

- 课程要体现批判性思维或高阶能力，现有考核却全是记忆与套公式的题目。
- 要设计大作业、课程论文、期末综合题或实验探究任务。
- 已有量规写得不可判（"论述深刻""理解到位"），需要改成可观察描述。
- 考核方式要改革（提高过程性评价与探究性任务占比），需要一份权重校验。

**不用**：

- 只需要一份普通评分量规（低阶记忆性任务），不必上高阶任务框架。
- 只是调整教学顺序或布置作业题（属教学准备，不是考核任务设计）。
- 课程目标是纯粹的操作熟练度（实验技能、编程语法），高阶思维任务不适用。

## 输入

**必填**：

1. 课程目标与本任务对应的目标条目（毕业要求指标点原文表述，若有）。缺省按"本课程第 __ 条教学目标"处理并标注待填。
2. 学科与专业方向（用于选择思维操作类型）。缺省按"理工类"处理并标注为假设。
3. 任务周期与学生人数。缺省按"3 周、小组 3–4 人"处理。
4. 可用材料与数据（课程自带实验数据、公开数据集、教材案例、企业问题）。缺省按"课程自带材料"处理。

**可选**：

5. 本任务在课程总评中的权重。缺省按 20% 处理（单项一般不宜超过 25%）。
6. 是否分组。缺省按"个人完成"处理。
7. 是否允许 AI 与计算工具。缺省按"允许检索与计算，不允许代写论证"处理。
8. 课程思政要求。缺省按"在工程伦理与社会责任维度自然融入"处理。

## 执行步骤

1. **先对齐目标。** 写清本任务评的是哪一条目标、对应哪个毕业要求指标点（照抄本校原文，不自编编号）。目标里没有的思维操作，不能靠任务硬加。
2. **确定本学科要练的思维操作。** 从模板 A 挑 2–3 项本学科用得上的操作，并改写成该学科的说法（例：通用"检查边界"→ 力学课"检查适用范围：线性假设、几何尺寸、阻尼项"）。
3. **选任务类型。** 从模板 C 六类菜单选 1 类主任务（可选 1 类辅）。一个任务只承载 1–2 项思维操作；操作越多越容易被通用套话蒙混。
4. **填任务五要素。** 情境、角色、待决问题、可用材料、交付物写死；"待决问题"要真有待决点（信息不足、条件冲突、需要权衡），不能是"谈谈你的看法"。
5. **加防蒙混机制。** 跑模板 D：能否靠背模板拿大部分分？能，就加一项不可预设的要素（必须现场处理的数据、约束或反例），并写进量规。
6. **写量规。** 用模板 E 写 4 档可观察标准，每条都能从学生交付物里"看出来"。禁止"深刻""到位""较好地"。
7. **跑可观察性判据。** 模板 G 三条硬判据：每档是否有行为描述、相邻档是否可区分、是否对应思维操作。任一条不过就重写量规。
8. **做权重合计校验。** 用模板 F 把本任务权重与各项评价相加，确认合计 100%。本任务超 25% 时先调整；改动须与课程大纲同步。
9. **配定验收环节。** 用模板 B 的交付物字段定下答辩形式（口头 3 分钟 + 1 页图），让论证必须被说出来，避免文本上的事后美化。

## 输出模板

### 模板 A｜学科思维操作清单（先通用，后学科化）

| # | 通用思维操作 | 本学科的具体说法（必填改写） | 可观察产出 | 典型错误 |
|---|---|---|---|---|
| 1 | 检查前提与边界 | 例：判断模型适用区间与失效条件 | 成立条件 + 一个越界实例 | 只写"在一定条件下" |
| 2 | 误差传递与来源分解 | 例：把总误差拆到各环节并找主导项 | 误差来源表 + 主导项 | 只报总误差 |
| 3 | 构造反例 | 例：找出使结论失效的具体实例 | 可算或可构造的反例 | 反例只是改数字 |
| 4 | 证据权衡 | 例：证据冲突时说明采信哪个及代价 | 采信决策 + 理由 | 罗列证据不表态 |
| 5 | 约束下的取舍 | 例：在成本/精度/工期冲突中排序 | 排序 + 每个取舍的代价 | 声称"两者兼顾" |

规则：本任务只选 2–3 项；每项都要在本学科里说得出来（例："误差传递"在中文专业应换成"考据互证与版本流传"）。

### 模板 B｜任务五要素卡（每个任务一张）

| 要素 | 内容（写死，不许"酌情"） |
|---|---|
| 任务名称 / 关联目标 | 课程目标第 __ 条 + 毕业要求指标点原文 |
| 情境 | 具体情境，含约束条件与利益相关方 |
| 角色 | 学生扮演的角色及其关注点（设计方 / 评审方 / 用户方） |
| 待决问题 | 真有争议、需在信息不足下判断的问题 |
| 可用材料 | 全部可得材料（数据表、图纸、标准、文献），注明哪些须自行获取 |
| 交付物 | 数量与形式写死（例：1500 字说明 + 1 张流程图 + 3 分钟答辩） |
| 时间盒 | 例：3 周，第 2 周交一次中间稿（第一次反馈点） |
| 个人/分组 | 个人；分组则须交个人贡献说明 |
| 本任务权重 | 20%（课程总评内） |
| 防蒙混要素 | 例：两组数据互相矛盾，须自选口径并说明代价 |

### 模板 C｜任务类型菜单（五类）

| 类型 | 适用思维操作 | 学科化任务骨架（按本学科改写） | 交付物形态 |
|---|---|---|---|
| 证据评估型 | 证据权衡、检查前提 | 给互相冲突的证据，判断哪些支持结论、哪些只是相关，说明采信代价 | 判断表 + 采信说明 |
| 参数敏感性型 | 量级估计、误差传递 | 给参数与实测值，判断对哪个参数最敏感，给出使结论翻转的临界值 | 敏感性排序表 + 临界值 |
| 反例构造型 | 构造反例、检查边界 | 给一个被广泛引用的结论，构造使其失效的具体实例并说明机制 | 反例 + 机制说明 |
| 方案取舍型 | 约束下取舍 | 给两项以上方案与冲突约束（成本/精度/工期/风险），排序并说明取舍代价 | 排序表 + 代价分析 |
| 跨尺度比较型 | 跨尺度比较与转换 | 把单元/机理尺度的结论推到另一尺度，检查转换中失效的前提 | 转换说明 + 失效点清单 |

### 模板 D｜防蒙混检查表（任一项不过就改任务）

| # | 检查项 | 判定 | 不通过时的改法 |
|---|---|---|---|
| 1 | 能否靠通用套话（优点/局限/建议）拿到大部分分 | 能 / 不能 | 把套话无法处理的具体数据写进任务 |
| 2 | 是否给定必须现场处理的信息（数值、约束、反常数据） | 是 / 否 | 加入一组需现场核对的数据 |
| 3 | 是否存在"信息不足但必须做判断"的待决点 | 是 / 否 | 删去多余信息或再删一半信息 |
| 4 | 是否有可核查的错误答案（错误推理会被算出来） | 有 / 无 | 设一条"常见错误路径"，量规为它单设低档 |
| 5 | 是否有明确的完成标准（不是"有深度"） | 有 / 无 | 用模板 E 改写为行为描述 |
| 6 | 是否需要用本课程核心方法，而非通用写作 | 是 / 否 | 交付物绑定学科方法（计算、实验、查证、制图） |
| 7 | 评分是否可能被"写得漂亮"替代 | 否 / 是 | 降低文字比重，提高中间稿与口头答辩比重 |

### 模板 E｜评分量规草案（4 档，全部行为化描述）

| 维度 | 优秀 | 良好 | 合格 | 不合格 |
|---|---|---|---|---|
| 思维操作 1：（填入操作名） | 主动完成该操作，并指出至少一处自己结论的失效条件 | 完成该操作，失效条件识别不完整 | 尝试该操作但结果有误，经提示可自行修正 | 未进行该操作，或结论与操作无关 |
| 思维操作 2：（填入） | （写成可观察行为） | （写成可观察行为） | （写成可观察行为） | （写成可观察行为） |
| 证据与表达 | 结论与证据一一对应，缺口自陈 | 结论与证据大体对应，个别缺口未自陈 | 有结论有证据但存在错配 | 无结论或结论无依据 |

写法规则：每格必须含可观察行为；相邻两档必须差一个可区分动作；评分点必须能在学生交付物上直接圈出位置。

### 模板 F｜权重合计校验表（课程评价体系内）

| 评价构成 | 权重（%） | 载体 | 是否含本任务 |
|---|---|---|---|
| 平时作业 / 随堂小测 | 20 | 4 次作业 | 否 |
| 过程性环节（中间稿、讨论参与） | 10 | 中期反馈 1 次 | 部分（中间稿） |
| 本批判性思维任务 | 20 | 1 个综合任务 | 是 |
| 期末终结性考核 | 50 | 期末试卷 | 否 |
| **合计** | **100** | | |

校验规则：①各项相加精确等于 100%，否则不通过；②本任务及含本任务的单项均 ≤25%；③终结性考核通常 50%–70%，本校大纲另有规定以大纲为准并注明依据；④过程性评价合计 ≥20%，本任务的过程性成分不得整体移入终结性考核；⑤调权重必须同步改课程大纲。

### 模板 G｜评分等级可观察性三条硬判据

| 判据 | 检验方法 | 通过标准 | 不通过时 |
|---|---|---|---|
| 1 可指出 | 抽 3 份交付物，各找 2 个评分点 | 每份都能在交付物上圈出对应位置 | 抽象表述改写为"能看到的动作" |
| 2 可区分 | 拿两份不同档样本，遮住分数让两位教师独立判档 | 判到同一档的比例 ≥80% | 重写相邻两档差异点，增加一个可数动作 |
| 3 对应操作 | 检查量规每一行 | 每行都能对应到模板 A 中的一项思维操作 | 删除与思维操作无关的维度（排版、字数） |

## 中国高校语境要点

- **学时制**：高阶任务建议配套课程 2–4 学时（课内 2 学时用于任务发布、中间稿点评与答辩，课外 8–12 小时完成）。
- **评价制度**：用模板 F 做权重合计校验。本任务权重建议 15%–25%，过程性评价合计 ≥20%，终结性考核 50%–70%，全部合计精确 100%。本校大纲另有规定的以大纲为准并注明依据，不得为放得下本任务而擅自压低其他项权重。
- **毕业要求支撑**：任务五要素卡的"关联目标"栏必须同时写课程教学目标条目与毕业要求指标点的**原文表述**，编号照抄本校文件，不自编、不简写。
- **课程思政**：把价值引领放进任务情境本身（材料中含涉及安全、伦理或公共利益的取舍点），让学生在技术判断中承担价值判断，不额外附加思政心得，权重不单列。
- **分组与个人**：小组作业必须附个人贡献说明（谁做了什么、用什么证据）并安排每人发言，否则个人成绩无法评。
- **AI 与计算工具**：允许与禁止范围写进任务书（例：可用 AI 检索与解释，论证链与数据处理须本人完成并留过程记录）；学生使用 AI 须在交付物中标注使用环节。

## 易错点

- ❌ 把"讨论观点"当成批判性思维任务 → ✅ 绑定模板 A 中至少 2 项本学科思维操作，否则无法评。
- ❌ 通用模板套话就能拿高分 → ✅ 跑模板 D，不过就加入必须现场处理的数据或约束。
- ❌ 量规写"论述深刻""理解到位" → ✅ 每格改写为可观察行为，并跑模板 G 判据 1。
- ❌ 相邻档只有程度副词差别 → ✅ 相邻档必须差一个可数动作（多一处自陈、多算对一个量）。
- ❌ 权重加起来不是 100% 就发布 → ✅ 模板 F 校验，不过不发布；改动须同步改大纲。
- ❌ 一个任务塞 5 种思维操作 → ✅ 只留 2–3 项，操作越多越容易被套话蒙混。
- ❌ 只收终稿 → ✅ 设中间反馈点 + 口头答辩，让过程可见。

## 自检清单

- [ ] 写清了对应的课程目标与毕业要求指标点原文
- [ ] 确定 2–3 项本学科思维操作并已改写成学科语言
- [ ] 选了任务类型并填满任务五要素卡
- [ ] 存在真实的待决点（信息不足但必须判断）
- [ ] 交付物数量形式、时间盒、分工方式已写死
- [ ] 模板 D 防蒙混检查 7 项全部通过（或已记录修改）
- [ ] 量规各档全部为行为化描述，无"深刻/到位"
- [ ] 相邻档有可区分差异点
- [ ] 模板 G 三条可观察性判据通过（含 3 份样本抽检）
- [ ] 权重合计精确 100%，本任务 ≤25%，终结性考核 50%–70%
- [ ] 有中间反馈点与至少 1 次口头答辩

## 交叉技能

→ `competency-unpacker`（把课程目标拆成可评的思维操作条目）
→ `criterion-referenced-rubric-generator`（把量规扩展成完整评分标准）
→ `assessment-validity-checker`（审查任务是否真的测到了目标）
→ `backwards-design-unit-planner`（从目标反推任务与证据链）
→ `project-brief-designer`（把任务五要素写成学生可执行的任务书）
