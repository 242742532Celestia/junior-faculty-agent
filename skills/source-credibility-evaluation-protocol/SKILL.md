# 来源可信度评估协议

## 这个技能解决什么

学生在综述里引用了一条根本查不到出处的"研究表明"，教师追问时学生说"网上看到的"，检索后发现是某营销号转述的三手内容。

一条引用看起来来自权威期刊，但真实链接指向一个仿冒站点；或者引用本身没问题，学生却把它当成了综述里唯一支撑一个关键主张的依据。

AI 生成的回答读起来比许多期刊文章还顺，引用的文献编号却查无此文；学生无法判断这是模型的幻觉还是真实文献。

同一个数据在新闻稿、预印本、期刊正式版、官方统计年鉴里数字不一样，学生随手引了其中一个，还说不清差别。

教师想布置"信息素养训练"，但没有可执行的判定标准，学生交上来的可信度报告只有"高/中/低"三个词，没有依据。

这个协议把"信不信"拆成四道关口：来源身份、证据内核、外部印证、使用边界，每道关口产出可填写的记录，最后落到一个 12 分制的分级判据和一份必须执行的处置动作。

## 什么时候用

**用**：

- 学生要评估一条网络来源、一份报告、一篇预印本或一条 AI 生成的材料是否可引用。
- 教师布置文献综述作业前，需要一套统一的可信度判定口径，避免学生各写各的。
- 学生引用了来源，但来源本身可疑（作者查不到、期刊不在目录内、只有二手转述）。
- 同一事实出现多个互相矛盾的版本，需要确定"以谁为准"。
- 指导学生使用 AI 检索文献时，需要一条"不得直接采信、必须人工回溯"的硬规则。

**不用**：

- 只是要检索文献并凑齐数量——先做检索，检索结果再进入本协议评估。
- 判断内容是否符合本专业伦理或是否值得读——那是阅读价值判断，不是可信度判断。
- 对具体实验数据做统计复核——交给统计与检验方法那一类技能。
- 已确认无法获取全文、需要判断"值不值得托人代查"——这是检索策略问题。

## 输入

**必填**：

1. 待评估来源清单：每条至少给出标题或可辨识的线索（作者/机构/年份/链接片段）。缺省按"单条来源"处理。
2. 来源类型：期刊论文 / 会议论文 / 预印本 / 学位论文 / 政府或机构报告 / 教材 / 科普文章 / 商业网页 / 社交媒体帖 / AI 生成输出。缺省由协议自动判定并标注不确定。
3. 拟支撑的结论（这条来源将被用来支持什么）。缺省填"待填写"，并把该来源的处置降一级，先做外部核验。

**可选**：

4. 是否有第二条独立来源（用于交叉核验）。没有时协议会生成一张"核验任务单"，而不是直接放行。
5. 本课程的引用格式与允许的来源类型（缺省按 GB/T 7714—2015，允许公开可追溯的学术与官方来源）。
6. 是否涉及 AI 生成内容（涉及时启用模板 D 六项人工核验）。
7. 学生已掌握的核验能力水平（缺省按本科低年级处理：核验动作写全，不省略步骤）。

## 执行步骤

1. **先定用途再评可信度。** 写清"这条来源要支撑的结论是什么"。用途不同，判据不同：作为背景介绍与作为关键证据的门槛不一样；作为数据来源与作为观点来源也不同。
2. **过第一关口：身份。** 作者/机构是谁、是否可追溯、有无编辑或评审机制、发表日期与版本、资金来源与利益关系。这一关不通过，后面不用做。
3. **过第二关口：证据内核。** 打开原文（或至少摘要、方法、数据表）。判断方法与数据能不能被读者检验：样本从哪来、怎么取的、结论能被复现吗。
4. **过第三关口：外部印证。** 至少找一条**来源独立**的第二材料：另一项研究、官方统计、权威机构的引用、独立报道。核对三件事：数字是否一致、结论方向是否一致、争议是否被提及。
5. **过第四关口：使用边界。** 写出"这条来源能支撑到多强的结论"（可作为主依据 / 可作支撑 / 仅作线索 / 不得引用），并写明限制条件。
6. **打分与分级。** 按模板 B 六个维度各打 0/1/2 分，总分 12 分，落到 A/B/C/D 四级；每一级绑定**必须执行**的处置动作，不允许只写等级。
7. **产出登记卡与核验任务单。** 每条来源一张登记卡；凡有"待检索""待核验"项的，单独成单，不允许混进正文。

## 输出模板

### 模板 A｜来源登记卡（每条来源一张）

| 字段 | 填写内容 |
|---|---|
| 编号 | S-01 |
| 标题（原文） | |
| 作者 / 机构 | |
| 发布日期 / 版本 | |
| 来源类型 | 期刊论文 / 预印本 / 报告 / 网页 / 社交媒体 / AI 输出 |
| 可定位出处（DOI、馆藏号、URL、访问日期） | |
| 拟支撑的结论 | |
| 证据类型 | 原始数据 / 综述 / 观点 / 二手转述 |
| 是否经同行评审 | 是 / 否 / 预印本未评审 / 不适用 |
| 资助来源与利益关系 | |
| 证据内核可核查程度 | 全文可查 / 仅摘要 / 仅转述 |
| 外部印证来源（≥1 条） | |
| 三源一致性 | 一致 / 部分一致 / 矛盾 / 无法核验 |
| 总分与等级 | （12 分制） |
| 处置动作 | 主依据 / 支撑证据（注明限定） / 仅作线索 / 不得引用 |
| 局限与使用边界 | |

### 模板 B｜十二分制可信度分级判据（六个维度各 0/1/2 分）

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 1 作者与机构可追溯 | 无署名、机构虚构、查不到人 | 有署名但信息不全，或无法判断是否同行 | 作者身份可核，有机构与联系方式，履历可查 |
| 2 评审与编辑机制 | 无任何审稿痕迹 | 只有形式评审或已被撤稿争议 | 有明确同行评审与编辑流程，可查评审或编辑政策 |
| 3 证据可核查 | 无数据、无方法、只有结论 | 有方法描述但数据不公开 | 数据/材料/代码可获取，方法可复现 |
| 4 动机与利益披露 | 不披露来源与商业目的 | 有披露但不完整或存在次级渠道 | 资助方、利益冲突、数据来源都写清楚 |
| 5 时效与版本 | 无日期、版本混乱 | 只有初版或数据已过时 | 版本清晰，数据截止时间明确且与结论相关 |
| 6 外部印证 | 只有孤证，无人引用或引用皆转引同一处 | 有引用但都源自同一原始出处 | 有独立来源复现或质证，争议点被公开讨论 |

分级与处置动作（写死，不许"酌情"）：

| 总分 | 等级 | 处置动作 |
|---|---|---|
| 10–12 | A | 可作为关键主张的主依据；正文直接引用，记录在册 |
| 7–9 | B | 可作为支撑证据，正文须写明限定条件；不得单独支撑关键主张 |
| 4–6 | C | 仅作线索与研究背景，不得作为论据；须补一条独立来源后才能升级 |
| 0–3 | D | 不得引用；转教学案例（讲清楚它错在哪） |

**硬规则**：任何进入正文的关键主张，其 A 级来源数必须 ≥1，且该来源的"证据可核查"维度不得为 0 分。

### 模板 C｜外部印证记录（每条关键来源至少一行）

| 印证来源 | 是否独立于原来源 | 数字是否一致 | 结论方向是否一致 | 是否提及争议 | 一致性判定 | 若矛盾：本方采用哪一个及理由 |
|---|---|---|---|---|---|---|
| | 是 / 否（若是"否"，不算印证） | | | | 一致 / 部分一致 / 矛盾 / 无法核验 | |

说明：两条引用如果都转引自同一篇原始研究，它们**不构成**交叉印证，只能算一条。

### 模板 D｜AI 生成输出的六项人工核验（涉及 AI 时必做）

| # | 核验项 | 操作 | 判定 |
|---|---|---|---|
| 1 | 文献是否真实存在 | 逐条在学术数据库或图书馆目录按题名+作者+年份检索 | 命中 / 部分命中 / 未命中 |
| 2 | 引文细节是否对得上 | 打开原文核对卷期、页码、年份、期刊名 | 一致 / 不一致 |
| 3 | 结论是否被原文支持 | 找到原文对应段落 | 支持 / 不支持 / 需改写 |
| 4 | 数据是否有出处 | 追问数字的统计口径、样本、时间范围 | 有出处 / 无出处 |
| 5 | 是否存在语气夸大 | 检查"研究证明""必然""最先进"等表述与证据强度是否匹配 | 匹配 / 夸大 |
| 6 | 是否混入生成内容 | 把 AI 输出中无法回溯的句子标红，整句删除或重写 | 处理完毕 |

规则：AI 输出只能作为检索线索。任何进入正文的内容，必须经过第 1、2、3 项人工回溯；未命中一律剔除。

### 模板 E｜课堂 15 分钟小协议（时间盒）

| 时间 | 动作 | 产出 |
|---|---|---|
| 0–2 分钟 | 定用途：这条要支撑什么结论 | 一句话用途陈述 |
| 2–5 分钟 | 查身份：作者、机构、日期、评审机制 | 模板 A 前半 |
| 5–9 分钟 | 验内核：打开原文看方法与数据 | 模板 A 中段 |
| 9–12 分钟 | 找印证：一条独立来源 | 模板 C 一行 |
| 12–15 分钟 | 打分定级 + 写处置动作 | 等级 + 一句动作 |

### 模板 F｜来源处置结论行（可直接粘进论文笔记）

```
S-0X｜等级：B（9/12）｜用法：仅作背景介绍，不支撑关键主张｜依据：3 号维度为 1 分，仅摘要可读｜限制：样本为 2019 年单中心数据｜待办：补一条独立复现研究后再评估
```

## 中国高校语境要点

- **学时制**：信息素养训练建议 1 学时（45 分钟）走完模板 E 的 15 分钟协议 × 3 条来源；完整的来源登记卡训练放在 2 学时（45×2）的模块里做。
- **评价制度**：可信度评估报告适合做过程性评价。建议权重：课堂即时协议 10% + 来源登记卡（含模板 A、B）20% + 期末考核 50%–60%，其余为出勤与随堂小测等，合计 100%；具体权重以课程大纲为准。
- **毕业要求支撑**：把"能核查并说明信息可靠性"归入毕业要求中"工程与社会""终身学习""沟通表达"类指标点的支撑活动，引用本校指标点原文表述，不自编编号。
- **课程思政**：在"利益披露""研究者的责任"处自然融入——例如讨论"如果一篇论文的结论对决策者有利，作者隐瞒了资助方意味着什么"，价值判断写在案例讨论里，不另立说教段落。
- **学术诚信与 AI**：明确告知学生：AI 生成的综述段落、文献清单、DOI 一律不得直接采用；必须按模板 D 人工回溯；须在作业末尾声明 AI 使用环节（辅助检索 / 语言润色 / 未使用）。学校或学院有更严格规定时以校规为准。
- **检索入口与规范**：文献核验优先用学校图书馆数据库与馆藏目录、官方统计年鉴、国家标准文本公开系统；引用著录按 GB/T 7714—2015 执行，格式细则服从本课程现行规定。
- **教材与参考书**：若引用信息素养教材章节，需给出可核验书目信息（有 ISBN 写 ISBN，无则写"待补充"并注明核验渠道），不得编造 ISBN。

## 易错点

- ❌ 先看结论顺不顺眼再评可信度 → ✅ 先定用途、再按四道关口走，顺序颠倒会把"读着舒服"当成"可信"。
- ❌ 把两条转引同一原文的文献当作交叉印证 → ✅ 模板 C 必须先确认"是否独立于原来源"，否则不算印证。
- ❌ 只查文献是否"存在"，不查结论是否被原文支持 → ✅ 六项核验里第 3 项不可省，AI 生成的错误常是"文献真实但结论错配"。
- ❌ 打分后只写"可信度较高" → ✅ 每一级绑定动作：C 级必须降为线索，D 级必须剔除，不能停在标签上。
- ❌ 用总分高掩盖单项致命缺陷 → ✅ 硬规则规定"证据可核查"得 0 分时，即使总分高也不得作主依据。
- ❌ 把发布方的权威身份当成内容可信 → ✅ 官方机构发布的初步数据也可能未评审，要看具体这份材料有没有评审与数据。
- ❌ 把"查不到"等同于"不可信" → ✅ 区分"未核验"与"已证伪"：查不到写"待检索"，找到反证才写不可信。
- ❌ 把 AI 的参考文献清单整段搬到学生作业里 → ✅ 六项核验逐条回溯，未命中条目直接剔除，并写入 AI 使用声明。

## 自检清单

- [ ] 每条待评来源都先写了"拟支撑的结论"
- [ ] 登记卡字段无空缺，查不到的项写明"待检索"而非留白
- [ ] 六个维度都打了分，总分与等级一致（10–12 A / 7–9 B / 4–6 C / 0–3 D）
- [ ] 每个等级都写明了处置动作
- [ ] 关键主张至少有 1 条 A 级来源支撑，且其"证据可核查"不为 0 分
- [ ] 每条关键来源至少有一条**独立**的外部印证材料
- [ ] 矛盾项已记录"采用哪一个、为什么"
- [ ] 涉及 AI 内容的，六项人工核验全部完成
- [ ] AI 使用情况已在作业末尾声明
- [ ] 引用格式符合 GB/T 7714—2015 与本课程规定
- [ ] 已生成独立的"核验任务单"，与正文分开存放

## 交叉技能

→ `citation-audit`（著录格式、逐条引用核验与来源台账）
→ `citation-audit` 的逐条引用核验判据（按题名+作者+年份做存在性核验）
→ `scholar-evaluation`（对已确认真实存在的文献做学术质量评价）
→ `discipline-specific-critical-thinking-task-designer`（把来源评估设计成该学科的思维操作任务）
→ `argument-structure-scaffold-generator`（把评估结果转成主张—依据的骨架）
→ `feedback-quality-analyser`（把"此来源不可用"的判断写成可执行的修改意见）
