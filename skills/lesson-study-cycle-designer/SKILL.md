# 课例研究循环设计器

## 这个技能解决什么

教研室里最常见的五种空转：

- 教研会开成经验分享会："我这节课讲得挺好"，大家点头，散会没有一张纸留下来。
- 评课变成打分：打完分结束，没有第二次课，改进既没设计也没验证。
- 同一个问题反复被提（典型如"提问后不给等待时间"），每学期都提，每学期都还是老样子。
- 新教师被安排去听课，笔记记的是"这节课内容好多"，与自己的教学没有连接。
- 想写教学改革论文，却说不清"改了什么、对照数据从哪来"。

本技能把"看别人的课"改造成**一轮可复制的改课循环**：每轮固定留下三样东西——
一个聚焦议题、一份改后教学设计、一次复观对照数据。

## 什么时候用 / 什么时候不用

**用：**

- 教研室要解决一个共性教学难题（提问组织、概念讲解、实验分组、作业批改与反馈）
- 公开课、精品课、教学名师培育前的打磨
- 新教师"带教—观课—复观"的培养安排
- 教学改革项目需要过程性证据与前后对照
- 想把教研成果写成教学论文，需要可复用的数据

**不用：**

- 目标是选拔评比而不是改进——评比另有量规，不需要完整循环
- 只能观一次课、没有复观条件的场合——改用单次诊断性观察
- 学期中段的突发补救（学生退课、机房故障等）——走即时改进，不走循环
- 需要学生心理测评或敏感个人信息的观察

## 输入

**必填**

| 项 | 说明 | 缺省处理 |
|---|---|---|
| 聚焦的共性问题 | 1–2 个，写成教学语言 | 无：先做一次课前预习 + 一次观察，产出 3 条候选，投票取前 2 条 |
| 参与人员与角色 | 4–6 人，含课例教师 | 无：默认 1 名课例教师 + 1 名主持 + 1 名记录 + 2 名观察 |
| 时间与录像条件 | 可用于循环的周次、能否录像 | 无：默认每 2 周 1 轮，共 3 轮，录像可选 |
| 本轮内容范围 | 哪一章、哪些班 | 无：默认同一课程内 2 个平行班 |

**可选**

- 往轮结论与遗留问题（决定本轮起点）
- 课程目标与毕业要求支撑矩阵（决定议题是否落在课程目标上）
- 班级规模与学情差异（决定复观的可比性）
- 学校教研活动与工作量的折算规定

## 执行步骤

1. **立项**：写清聚焦问题、成功标准、轮次上限。没有成功标准的循环无法收尾。
2. **配角色**：主持者控时、记录者只记不评、观察者只按协议记、课例教师本轮不做主讲以外的评判。
3. **课前设计会**：课例教师讲设计意图（15 分钟），小组把意图翻译成观察点，填观察协议。
4. **观课**：按协议记录；课例教师可只做观察者，不在课后即时自评（避免辩护性说明）。
5. **课例分析会**：先静默读记录 5 分钟再发言，产出 1–2 个议题，走推断链 7 步。
6. **改课**：只改聚焦议题涉及的教学环节，写出改动前后对照。
7. **再实施与复观**：用同一套观察维度复观，产出前后对照数据。
8. **归档收尾**：更新循环日志，生成一份可分享的课例报告，残留议题带入下一轮。

**表 B 小组角色与职责**

| 角色 | 人数 | 职责 | 明确不做 |
|---|---|---|---|
| 课例教师 | 1 | 提供设计意图，实施原课与改课 | 不评自己的课 |
| 主持者 | 1 | 控时、推动议题收敛、记录决议 | 不讨论教学内容细节 |
| 记录员 | 1 | 记事实、时间点、决议与未决问题 | 不写评价性意见 |
| 观察者 | 2 | 按协议独立记录 | 观察中不交流 |

**表 C 课前设计会（30 分钟）**

| 时段 | 环节 | 产出 |
|---|---|---|
| 0–15 | 课例教师讲设计意图与本节目标 | 意图陈述 3 条 |
| 15–25 | 小组把意图转成观察点 | 观察维度 ≤ 8 项 |
| 25–30 | 定稿协议与分工 | 协议定稿稿 |

**表 D 课例分析会（90 分钟）**

| 时段 | 环节 | 规则 |
|---|---|---|
| 0–5 | 静默读记录 | 不许发言，不许看录像以外的材料 |
| 5–15 | 事实朗读 | 只读带时间点的原始记录 |
| 15–40 | 走推断链，形成议题 | 议题 ≤ 2 条 |
| 40–60 | 改课设计 | 指出改在哪个环节、怎么改 |
| 60–75 | 指定复观指标 | 维度 + 目标水平 |
| 75–90 | 决议与未决问题 | 未决问题进入循环日志 |

**表 E 证据→议题推断链**（分析会现场填，记录员执笔）

| 步骤 | 写什么 | 判定规则 |
|---|---|---|
| 1 事实摘录 | 从记录表抄 2–3 条带时间点的原始记录 | 只抄不改写 |
| 2 模式判定 | 出现在几个窗口、涉及几名学生 | <2 窗或 <2 生 → 记"待观察"，不进议题 |
| 3 意图核对 | 课例教师的设计意图里是否包含该行为 | 意图中没有 → 归为"非问题"，写明理由 |
| 4 议题命名 | 一句教学语言 | 必须是可改的动作，不写"互动差""讲得不好" |
| 5 改动设计 | 下一版具体改哪一步 | 必须能在教学流程里指出位置 |
| 6 验证指标 | 复观看哪个维度、达到什么水平 | 指定维度 + 目标分数（如 3 档升到 5 档） |
| 7 残留问题 | 本轮没解决的 | 必填，空也写"无" |

| | | | | |

| 观察维度 | 前次水平 | 本次水平 | 目标水平 | 达成 |
|---|---|---|---|---|
| | | | | |

| 轮次 | 日期 | 议题 | 改了什么 | 复观结果 | 结论（保留/放弃/再试） | 残留问题 |
|---|---|---|---|---|---|---|
| | | | | | | |

**时间盒**：课前会 30 分钟、分析会 90 分钟、记录整理 24 小时内完成、课例报告 ≤ 3 页。

## 中国高校语境要点

1. **课时与周期**：45 分钟 1 学时，两学时连堂 90 分钟；课例优先选连堂课，能容纳"讲—练—评"完整环节。
2. **平行班对照**：同一课程 2–3 个平行班是最经济的复观对照；跨年级或跨专业对照要写明不可比因素。
3. **大班约束**：60 人以上课堂的观察维度不超过 8 项，改课优先改"可控的组织动作"（如提问等待时间、分组检查），不依赖逐组辅导。
4. **工作量登记**：课前会与分析会应按学校教研活动规定登记学时或折算工作量，各校口径不同，未查到写"按校规定另行申报"。
5. **毕业要求支撑**：每轮聚焦问题须挂在课程目标上；若该课程支撑某毕业要求指标点，议题也要能支撑它。
6. **课程思政**：改课方案中涉及价值引领的环节（如案例讨论）要写明融入方式，避免变成口号；融入点随改后设计同步更新。
7. **学生知情同意**：涉及录像与课堂影像传播的，须取得同意；成果对外分享只保留教师与去标识化的教学片段。
8. **成果出口**：每学期至少沉淀 1 份课例报告（3 页内），格式与"教学论文"出口对齐，便于直接改写为教研论文。

## 易错点

- ❌ 教研会变成轮流讲感想 → ✅ 分析会前 5 分钟静默读记录，发言只引用记录里的带时间点事实
- ❌ 一轮讨论 5 个议题 → ✅ 单轮议题 ≤ 2 条，多了必然改不动
- ❌ 只观不改，改完不复观 → ✅ 没有复观数据的轮次记为"未闭环"，不算完成一轮
- ❌ 课例教师当场自评并辩护 → ✅ 观课后教师暂不发言，先由观察者读记录
- ❌ 改课顺手换教材、换章节 → ✅ 只改聚焦议题涉及的环节，其余保持一致，否则复观无法归因
- ❌ 跨班复观直接比较 → ✅ 不同班必须写明差异来源，或改用同一班跨轮对照
- ❌ 把"待观察"当议题 → ✅ 只出现 1 次的现象进"待观察"清单，不进议题
- ❌ 结论写成"教师态度认真" → ✅ 结论写成"提问后等待 3 秒，观察到的应答比例从 2/9 升到 6/9"

## 自检清单

- [ ] 已写聚焦问题与本轮成功标准
- [ ] 每轮只有 1–2 个议题，且议题是可改的动作而非评价
- [ ] 小组角色齐备，职责与"不做的事"已写明
- [ ] 课前会与分析会均有时长与产出定义
- [ ] 每条结论都能回溯到带时间点的原始记录
- [ ] 推断链 7 步填完，"待观察"项已单独列出
- [ ] 改课对照表写明改在哪一环节、改后怎么做
- [ ] 复观使用同一观察维度与粒度，可比性已说明
- [ ] 循环日志含残留问题，下一轮起点明确
- [ ] 录像与成果分享的知情同意已确认
- [ ] 课例报告 ≤ 3 页，已存入教研档案

## 交叉技能

→ `lesson-observation-protocol-designer`（提供每轮观课的观察协议与记录表）
→ `peer-review`（课例分析会的证据讨论借用同行评议的证据分级习惯）
→ `hypothesis-generation`（把课例议题转成可检验的改进假设）
→ `backwards-design-unit-planner`（改课方案对齐教学目标与证据链）
→ `teaching-file-builder`（课例报告归档进教学文件与教研档案）
