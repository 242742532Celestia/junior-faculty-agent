# 反思实践提问脚本生成器

## 这个技能解决什么

观完课、写完评语，教研会却总是卡在这里：

- 评语停在"教态自然、互动较好"，没人说得出下一步改哪一句话。
- 反思写成感想日记："今天讲得不够耐心"，既没有证据也没有动作。
- 一上来就问"这节课哪里没讲好"，教师立刻进入自我辩护，讨论再也不往下走。
- 提问一上来就是"是不是因为讲太快了？"，封闭问句把思考定死在提问者的预设里。
- 反思结论五条十条，学期末一条都没落地。

本技能把反思拆成一条**有顺序的提问串**：先描述事实，再归类行为，再逼出至少两个备选解释，
最后收敛成一个下次可执行、可复现的动作。

## 什么时候用 / 什么时候不用

**用：**

- 教研会上基于课堂录像片段做同行反思
- 教师个人课后复盘（尤其是新教师第一学期）
- 对一批学生作业做错因复盘
- 教学比赛或公开课前的"试讲—录像—复盘"环节
- 教研组要收集可共享的实践知识

**不用：**

- 做量化打分或等级评定（那是观察协议与评分量规的事）
- 学生个人辅导的谈话脚本（对象是学生，不是教师）
- 需要匿名化的学生访谈（另找访谈规范）
- 录像或作业样本缺失时硬编问题

## 输入

**必填**

| 项 | 说明 | 缺省处理 |
|---|---|---|
| 反思对象 | 一节课的录像 / 一批作业 / 一次课堂录音 | 无：追问用户，不生成 |
| 证据片段 | 具体时间码或具体学生作业 | 无：先做片段抽取说明，不出脚本 |
| 反思场景 | 个人自评 / 同行评议 / 教研会集体 | 无：默认同行评议 |
| 可用时长 | 反思会或自省能占多少分钟 | 无：默认 25 分钟 |

**可选**

- 本节课的教学目标与预期学生反应
- 往轮同类反思的结论与行动项（避免重复反思同一件事）
- 学生匿名编号方案
- 是否需要在反思中涉及情绪与压力话题

## 执行步骤

1. **先切片段**：录像只取 3 个 5 分钟片段（起点 1 个、转折 1 个、收尾 1 个）；作业只取 3 份（典型正确、典型错误、反常 1 份）。
2. **写事实卡**：每片段只摘录看得见、听得到的内容，不做解释；先写"我的第一反应"并标注这是反应不是结论。
3. **定提问串**：按"描述 → 归类 → 备选解释 → 决策"四层排 5–7 问，前两问必须是描述性。
4. **给每问配预期回答与转圜**：写清"如果沉默 10 秒怎么问"，避免冷场后由反思者自己答。
5. **设计追问分支**：对最可能分歧的第 3–4 问各写一条分支追问，形成一棵浅树。
6. **走推断链**：从片段到反思结论必须留 7 步痕迹，缺步骤的结论不进行动表。
7. **收敛成一个动作**：整场反思只承诺 1 个下次可执行的动作，并写清触发条件与复现日期。

## 输出模板

**表 A 反思任务卡**

| 项 | 内容 |
|---|---|
| 反思对象 | 课程 / 章节 / 班级 / 日期 |
| 证据源 | 录像编号或作业批次号（学生用匿名编号） |
| 反思者 | |
| 场景 | 个人 / 同行 / 集体 |
| 时长 | 25 分钟（片段 3 × 5 分钟 + 提问 10 分钟） |
| 本场唯一目标 | 一句话写清要改什么 |

**表 B 证据片段摘录表**

| 片段 | 时间码 / 作业编号 | 原样摘录（听到的、看到的、写的） | 我的第一反应 | 我没说出口的判断 |
|---|---|---|---|---|
| S1 | | | | |

规则：摘录栏只写原话与可见行为；"第一反应"是情绪与直觉，允许主观但不得进入结论。

**表 C 提问脚本**（核心产出，5–7 问）

| 序 | 提问 | 层级 | 预期听到的回答 | 沉默 10 秒的转圜 | 用时 |
|---|---|---|---|---|---|
| 1 | | 描述 | | | 60 秒 |
| 2 | | 描述 | | | 60 秒 |
| 3 | | 归类 | | | 90 秒 |
| 4 | | 备选解释 | | | 120 秒 |
| 5 | | 备选解释 | | | 120 秒 |
| 6 | | 决策 | | | 120 秒 |
| 7 | | 承诺 | | | 60 秒 |

提问规则（逐条可查）：

- 一问一意，禁止"你为什么这样讲、又为什么那样问"这种双问。
- 前两问只用"发生了什么／你看到什么"，不用"好不好"。
- 第 4、5 问必须逼出两个以上互斥解释，句式建议"还有可能是……"或"如果换成另一种解释，会是什么"。
- 最后一问必须落到可观察动作，句式建议"下一次上课，你打算改哪一句、放在哪个环节"。
- 禁止使用"应该""为什么不能""难道不是吗"这类带评判或封闭的问法。

**表 D 追问分支**

| 母问题 | 触发条件 | 追问 | 时长上限 |
|---|---|---|---|
| | 学生回答停在感受层 | 那个瞬间你具体想达到什么效果？ | 30 秒 |
| | 回答指向学生能力而非教学决策 | 你当时可以换哪种做法？ | 30 秒 |
| | 出现归因外部化（"他们都不…"） | 有哪一次是这个班特别不一样？ | 45 秒 |

**表 E 证据→结论推断链**

| 步骤 | 写什么 | 判定规则 |
|---|---|---|
| 1 摘录 | 从片段抄 1–3 条原话或可见行为 | 只抄不改写 |
| 2 描述 | 把摘录还原成中性事实句 | 不含"因为/所以/说明" |
| 3 归类 | 归到教学行为类别（讲解、提问、等待、组织、反馈、过渡） | 一次只归一类 |
| 4 备选解释 | 至少写 2 个互斥解释 | 两个解释都需与第 2 步的事实相容 |
| 5 检验 | 下次用什么现象可以否定其中一个解释 | 必须可观察、可计数 |
| 6 决策 | 选一个下次可执行动作 | 一个动作，含触发条件 |
| 7 复盘日期 | 何时回看这个动作有没有发生 | 写具体日期 |

**表 F 反思记录表**（反思后 24 小时内填）

| 项 | 填写 | 上限 |
|---|---|---|
| 最强的一个证据 | 引片段编号 + 原话 | 50 字 |
| 我原来的解释 | | 50 字 |
| 现在更倾向的解释 | | 50 字 |
| 还不能确定的 | | 50 字 |
| 下次课的具体改动 | 动作 + 触发条件 | 50 字 |
| 检验方式 | 看什么、多久看一次 | 50 字 |

**表 G 行动承诺表**

| 动作 | 触发条件（课前/课中某信号） | 首次实施日期 | 复现次数 | 检验方式 | 判定阈值 |
|---|---|---|---|---|---|
| | | | | | |

约束：一轮反思只承诺 1 个动作；连续 3 次课出现同一触发条件而动作未执行，视为承诺失败，需重新设计。

## 中国高校语境要点

1. **反思时间的现实**：教研会通常 1–1.5 小时，扣除汇报只剩 25–30 分钟；脚本必须能压进这段时间。
2. **片段抽取习惯**：45 分钟录像不整段看，只看 3 个 5 分钟片段；作业批改后当天选 3 份代表性样本，避免隔周失忆。
3. **作业样本选择**：批改量大时按"典型正确 / 典型错误 / 反常"各取 1 份，保证反思覆盖不同类型而不是只看差生。
4. **录像伦理**：含学生的录像仅用于本人与教研组，成果对外分享须去除可识别信息；反思记录不进人事材料。
5. **反思的出口**：行动承诺表按学期归档，可直接改写为教研论文的"实践—反思—改进"部分。
6. **课程思政与价值讨论**：涉及价值引领的课堂片段，反思时同时追问"学生是否产生了自己的判断"，避免反思只停在形式。
7. **工作量登记**：反思会与互评按学校教研活动规定登记学时或折算工作量，各校口径不同，未查到写"按校规定另行申报"。
8. **心理安全**：反思是改进工具不是问责工具；脚本中不设"追责式"提问，同行评议先说证据再说判断。

## 易错点

- ❌ 开场就问"这节课哪里没讲好" → ✅ 前两问只做描述，"好不好"留到归类层
- ❌ 一问里塞两件事 → ✅ 一问一意，拆成两次追问
- ❌ 用封闭问句预设结论 → ✅ 改开放问，并强制写出两个互斥解释
- ❌ 学生沉默就自己答 → ✅ 等待 10 秒 → 换一种说法再问 → 仍沉默则换角度问反思者自己
- ❌ 反思写成感想日记 → ✅ 每条感受必须挂一个片段时间码
- ❌ 整段录像看一遍 → ✅ 只看 3 个片段，把时间留给提问
- ❌ 承诺 5 条改进 → ✅ 一轮只承诺 1 个动作，写清触发条件
- ❌ 反思结论变成教师能力评价 → ✅ 结论必须写成"下一节课可观察到的动作"
- ❌ 把反思当问责谈 → ✅ 先摆证据，个人判断放到第 3 问之后
- ❌ 学生姓名出现在脚本里 → ✅ 一律用匿名编号，脚本不承载身份信息

## 自检清单

- [ ] 已确定反思对象、场景与时长
- [ ] 证据片段按规则抽取（录像 3 段 / 作业 3 份）
- [ ] 片段摘录只有原话与可见行为，解释被单独隔离
- [ ] 提问串 5–7 问，前两问为描述性
- [ ] 至少两问逼出互斥解释，最后一问落到可观察动作
- [ ] 每问都配了沉默 10 秒的转圜方案
- [ ] 追问分支已写，且有 45 秒时间上限
- [ ] 推断链 7 步完成，每步可回溯到片段
- [ ] 行动承诺表只有 1 个动作，含触发条件、日期与判定阈值
- [ ] 学生信息已匿名，录像用途与保留期限已写明
- [ ] 反思记录 24 小时内完成
