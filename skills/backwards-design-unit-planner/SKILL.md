# 逆向设计单元计划

## 这个技能解决什么

大多数教学材料是按"这章讲什么"倒着写出来的：先定内容，再配活动，最后补一个考试。
三段之间各说各话，于是期末一考就露馅——

> 目标写的是"理解傅里叶变换的基本原理"，课堂活动是"看 PPT 讲历史脉络"，
> 期末考的是"计算 DFT 系数"。学生复习的是计算，理解的只有定义。

逆向设计把顺序倒过来：**先确定"学完能做出什么"，再倒推"用什么证据证明"，最后才排"做什么活动"**。
三段共用同一组动词，于是"写了目标但不考""考了但没教"这类错位在设计阶段就被挡住，
而不是在期末补救。

## 什么时候用 / 什么时候不用

**用**：
- 备一门新课或一个新的教学单元（4 学时以内为一个单元最稳）
- 现有教案出现"目标—考核—活动"三者对不上，需要整改
- 要编课程目标与毕业要求支撑矩阵，需要先钉死可考核的目标
- 要做教学诊断后的改进方案

**不用**：
- 只是把已有教案换个排版、调字号、改标题
- 一次性的通知、讲座、班会（没有"单元"结构）
- 纯粹的知识问答（不需要产出教学计划）

## 输入

**必填**（缺任何一项就停下来问，或先出草稿并把假设标出来）：
1. 单元主题（如"图像增强：滤波与边缘检测"）
2. 本单元学时与课时划分（如 2 学时 = 2×45 分钟连堂）
3. 学生层次（大一/大三/研究生）与专业背景
4. 本单元在大纲中的位置（前修单元、后续单元）

**选填**（用户没给就留空并列入"需人工核验清单"，**不许编**）：
5. 已有教学大纲 / 教材对应章节
6. 本单元在总评中的权重
7. 毕业要求指标点编号（**没有就留空**，不要自己编指标体系）
8. 课程思政要求（学校或学院是否有明确指定）
9. 教学条件（机房/实验设备/是否分组）

## 执行步骤

1. **先写产出，不写内容。**
   列出 3–5 条"学完这个单元，学生能做出的东西"。
   每条必须以可观察动词开头：能设计 / 能推导 / 能比较 / 能评价 / 能解释 / 能诊断 / 能实施 / 能批判。
   **禁用**"理解、掌握、熟悉、了解、认识"——这些词无法证伪，写进目标等于没写。
   若某个目标写不出可观察动词，说明它其实是"内容"不是"目标"，移到内容清单里。

2. **给每条目标配一份"证据"。**
   证据 = 学生要交出的东西，它能证明目标达成。
   一条目标可以有多份证据，但**每条目标至少一份**。
   证据的载体形式：书面作业、计算结果、设计图纸、实验报告、课堂演示、口头答辩、
   编程实现、案例分析报告。**"考试"只是证据的一种形式，不是唯一形式。**

3. **选考核形式（产出最终要评分的那一份）。**
   判据只有一条：**这个形式能不能生成第 2 步的证据？**
   生成不了就得换形式，而不是让学生额外做一份与考核无关的作业。

4. **排教学活动。**
   活动必须让学生在课堂里做出"同源证据的低风险版本"——
   期末要交一份设计说明书，课堂活动就该让学生做一份设计草图并互评；
   期末要考计算，课堂活动就该有当堂计算与小测。
   活动描述里要写明"这一步产出什么、用来对哪条证据做铺垫"。

5. **双向对齐检查**（这一步不能省，见易错点）：
   - **正向**：每条目标 → 对应哪份证据 → 由哪个活动铺垫
   - **反向**：每份考核 → 测到了哪条目标；每个活动 → 服务于哪条目标
   - 两向都对得上，才算对齐。反向检查能抓出"多教了没考的"和"考了没教的"。

6. **分配课时。**
   一个 45 分钟课时能承载的高阶目标（设计/评价/创造类）通常不超过 1–2 个。
   超载时先砍目标，不要把课时摊薄成"每条目标讲 10 分钟"。

7. **标出不确定项。**
   凡属你的推断（学生先备水平、课时够不够、难度预判）标「假设」；
   凡属用户未提供但你必须知道的信息（教材版本、指标点编号、权重）标「待补充」，
   汇总到"需人工核验清单"。

## UbD 三阶段：预期结果 → 评估证据 → 学习计划

现有技能做的是"目标—证据—活动"三段对齐：先写学生能做出什么，再定用什么证据证明，最后排活动。
三段是一条**单向链**，但链的两端各缺一块——前端缺"这门课要留下什么理解"，
后端缺"证据分哪几类、每类各证明什么"。UbD（Understanding by Design）把这两块补齐，
形成完整三阶段：**预期结果 → 评估证据 → 学习计划**。

### ① 阶段一 · 预期结果

阶段一有两个必答项。缺任何一个，阶段二与阶段三就只能靠猜。

**持久理解（transferable understanding）**

学生离开这门课后还能带走、还能迁移的**大概念/理解**，不是章节标题，不是知识点清单。

写法要求：写成"学生能理解 ___，并在 ___ 情境中用它"，不写成"理解 XX 原理"。
- ❌ "理解傅里叶变换的基本原理"（这是知识点，且无法迁移）
- ✅ "学生能理解任何信号都可以分解为若干频率成分叠加，并在滤波与降噪这类真实任务中用它选择处理方式"

一个单元通常写 1–3 条持久理解；多了就退化成章节标题的改写。

**基本问题（essential questions）**

3–5 个贯穿整个单元、指向持久理解的开放问题。

判据（两条都要过）：
- **无法靠背定义回答**——答案不来自教材某一行的抄写；
- **学生在单元结束时仍能回答**——不是一次性导论话题。

写法示例：
- ✅ "信号在传递过程中发生了什么，哪些是信息、哪些只是噪声？"
- ❌ "什么是频域？"（能靠背定义回答，且不指向持久理解）

**持久理解与现有"目标"清单是两层，要互相校验**

| | 持久理解（UbD 阶段一） | 可观察目标（现有表 1） |
|---|---|---|
| 回答的问题 | **为什么学**：这门课要留下什么理解 | **怎么算达成**：学完能做出什么 |
| 粒度 | 少数几条，跨单元、跨学期仍成立 | 多条，一条对应一份证据 |
| 判定方式 | 看学生能不能在新情境里用出来 | 看证据是否达标 |
| 方向 | 往上：目标都要挂在持久理解下 | 往下：每条目标都要指向一个持久理解 |

校验规则：目标里出现而持久理解没有支撑的，多半是"内容"混进了目标；
持久理解写了却没有任何目标或证据支撑的，多半是写成了口号。

### ② 阶段二 · 评估证据

阶段二不是"设计一套考试"，而是**为持久理解配三类各司其职的证据**。三类定位不同，不能互相顶替。

**表现性任务（performance task）**

真实情境下的真实产出，是 UbD 的核心证据——它直接检验持久理解能否被用出来。

硬判据：**能靠背定义得满分的题，不算表现性任务。**
构造方式见第 ④ 节的 GRASPS 卡。

**概念诊断辨析（conceptual diagnostic）**

二选一/对错题，用来探测学生的**概念**而非记忆。

判据：干扰项必须来自**真实的迷思概念**，不是编的。
编出来的干扰项测的是"你记不记得我编的错法"，测不出理解。

**迁移应用（transfer application）**

把概念用到**没教过的新情境**，是检验"持久"的那一环——
持久理解按定义就是可迁移的；不设迁移证据，"持久"两个字就无从验证。

三类证据的分工：概念诊断负责**早期定位**，表现性任务负责**终点取证**，
迁移应用负责**验证可迁移性**。顺序不能颠倒。

### ③ 阶段三 · 学习计划

有了阶段一与阶段二，学习计划才有取舍依据：要让学生有足够多的机会**产生阶段二要的那些证据**。

学习计划不按"讲完第几章"排，而按"每个阶段二的证据在什么时候被产出"排。
每个学习活动都要能回答："这个活动产出的是哪一类证据的哪一份？"
用 **WHERETO** 逐项检查活动覆盖了学习循环的哪些环节（见第 ⑤ 节覆盖表）。

### ④ GRASPS：表现性任务的六要素

| 要素 | 含义 | 填写要求 |
|---|---|---|
| G · Goal 目标 | 学生要达成的真实目标 | 写成委托方的要求，不是知识点 |
| R · Roles 角色 | 学生扮演的角色 | 角色决定了可用信息与决策权限 |
| A · Audience 受众 | 产出给谁看 | 受众决定了质量标准与表达要求 |
| S · Situation 情境 | 故事发生的处境 | 情境里必须有真实约束与利害 |
| P · Product 产物 | 学生交出的东西 | 可检验的成品，不是"参与讨论" |
| S · Standards 标准 | 质量标准 | 必须能判定达标与否（含量规/阈值） |

> 使用规则：**六要素写全了，这个任务才有"真实性"；缺一两项不致命，但 P 与 S 必须实。**

### ⑤ WHERETO：学习活动的覆盖检查

| 代号 | 要素 | 含义 | 本单元覆盖位置 |
|---|---|---|---|
| W | Where & Why | 在什么情境下学、为什么重要 | |
| H | Hook | 钩子（怎么把人拉进来） | |
| E | Equip | 装备（需要什么工具/知识/资源） | |
| E | Experience | 体验（学生实际经历什么） | |
| R | Rethink & Revise | 反思与修订（改了以后怎么办） | |
| T | Tailor | 因材施教（给不同的人什么不同支持） | |
| O | Organize | 组织（怎么排序、怎么分组、怎么衔接） | |

> 使用规则：**七个要素不是七个都要单独占一节课，但每一项都要有"落在哪"的答案**；
> 答不出来的项就是设计漏洞（尤以 E·Experience 与 R·Rethink 最常漏）。

### ⑥ 三阶段与现有"目标—证据—活动"三段如何对齐

| UbD 阶段 | 对应本技能现有内容 | 说明 |
|---|---|---|
| 阶段一 · 预期结果 | 目标清单之前的**顶层依据** | 持久理解 + 基本问题，为每条目标提供挂靠点 |
| 阶段二 · 评估证据 | 表 1「单元目标与证据」+ 表 2「双向对齐检查」+ 第 3 步「选考核形式」 | 三类证据在表 1 的"证据形式"列里分别标注 |
| 阶段三 · 学习计划 | 表 3「课时分配」+ 第 4 步「排教学活动」 | 活动按"产出哪份证据"排序，用 WHERETO 查覆盖 |

对齐硬规则：**UbD 阶段一没写清楚就不要往下走**——后面两步的取舍全靠它。
阶段二与阶段三可以迭代修改，但每次修改都要回头问一句："这次改动动了持久理解吗？"
动了就说明阶段一要重写；没动才是局部调整。

## 中国高校语境要点

- **学时制**：1 学时 = 45 分钟；连堂 2 学时 = 90 分钟，中间不宜超过 15 分钟连续讲授。
  课表上每 45 分钟要有一个可观察的学习动作。
- **权重**：本单元若计入总评，其权重必须写清；课程整体的平时/期末各项加总**恰好 100%**。
- **评价制度**：课内多为形成性评价（提问、小测、同伴互评），期末为终结性考核。
  逆向设计里至少安排 1–2 次形成性证据，用来在期末前发现没对齐的地方。
- **毕业要求支撑**：指标点编号由院系给定。**用户没给就留空**，
  在表 1 旁注明"待补充"，不要自己编"毕业要求 3.2"这类编号。
- **课程思政**：融入点挂在**本学科内容自身的论证里**（如"去噪算法里的偏差-方差权衡
  与工程中的公平性取舍同构"），不要在知识点后面贴一句"提升家国情怀"。
- **教材**：ISBN 需真实并与本单元章节对应，查不到就写「待补充」。
- **表现性任务与终结性考核的衔接**：同一份产出被表现性任务与期末考核计两次分时，
  **必须在任务书里明说**（哪一份产出、计几次、各按什么规则计分），不明说就变成"临时加考"；
  表现性任务若计入平时成绩，须在**第一周**向学生公布计分规则、权重与申诉方式。
  权重合计以学院教学大纲为准；尚未确定时写「待考核方案确定」，合计写"待定"，不填占位数字。
- **基本问题与毕业要求的呼应**：基本问题要与毕业要求指标点形成呼应关系，
  但**指标点编号由院系给定，没给就留空**，在对应位置注明「待补充」，
  不自编"毕业要求 2.3"这类编号。
- **真实数据与合规边界**：表现性任务若涉及真实数据（企业案例、公开数据集、用户数据），
  任务书要写清数据来源与合规边界；没有合规数据源时，
  明确写"使用合成数据并在报告中声明"，并写清合成数据的生成规则。
- **学术诚信声明**：在任务书中单列学术诚信条款，写明允许的合作形式（个人/小组内分工）、
  必须独立完成的部分、引用与数据标注要求，以及违规的认定与处理流程（按学院学术规范处理，不自拟处分）。

## 易错点

- ❌ 目标写"理解/掌握/熟悉" → ✅ 换成可观察动词（能解释、能计算、能比较、能设计）
- ❌ 证据与活动不同源（考计算、课堂讲历史） → ✅ 三段共用同一组动词
- ❌ 只做正向检查不做反向 → ✅ 反向检查是抓"多教了没考"的唯一手段
- ❌ 把内容目录当成目标清单 → ✅ 内容进"输入/内容清单"，目标只写学生能做出的东西
- ❌ 一单元塞 8 条目标 → ✅ 按"一个课时最多 1–2 个高阶目标"反推条数
- ❌ 权重凑整（写"平时 40% 期末 70%"） → ✅ 加总恰好 100%
- ❌ 编造毕业要求编号 / 教材 ISBN / 章节页码 → ✅ 留空并进核验清单
- ❌ 活动只写"讲授、讨论、练习" → ✅ 每条活动都要写"产出什么、铺垫哪条证据"
- ❌ 只做了 UbD 的阶段二与阶段三，阶段一空着 → ✅ 阶段一（持久理解 + 基本问题）没写清楚就不要往下走
- ❌ 持久理解写成章节标题（"理解第 3 章：信号分解"） → ✅ 写成"学生能理解 ___，并在 ___ 情境中用它"
- ❌ 基本问题写成能背的题（"什么是频域？"） → ✅ 基本问题必须无法靠背定义回答，且单元结束时仍能回答
- ❌ 表现性任务被做成选择题或计算题 → ✅ 能靠背定义得满分的题不算表现性任务
- ❌ 概念诊断的干扰项是自己编的 → ✅ 干扰项必须来自真实的迷思概念
- ❌ WHERETO 只填了表、没落实 → ✅ 每一项都要有"落在哪"的答案，答不出来的就是设计漏洞
- ❌ 表现性任务与期末考核对同一份产出重复计分且未公布规则 → ✅ 明说计分方式与次数；计入平时成绩须第一周公布规则与申诉方式

## 自检清单

- [ ] 每条目标都以可观察动词开头，没有"理解/掌握"类词
- [ ] 每条目标至少有一条对应证据
- [ ] 考核形式能生成那些证据
- [ ] 每个活动都写明了产出与对应目标
- [ ] 正向、反向两向对齐检查都做了，且没有"多教没考""考没教"残留
- [ ] 课时分配合计与学时不符
- [ ] 权重合计 = 100%
- [ ] 毕业要求编号 / ISBN 等事实项：真实或已列入待补充，无编造
- [ ] 假设与待确认项已单列
- [ ] UbD 三阶段（预期结果 / 评估证据 / 学习计划）都产出了，不是只做了一步
- [ ] 持久理解写成可迁移的形式（"理解 ___，并在 ___ 情境中用它"），不是章节标题
- [ ] 基本问题 3–5 个，每一个都无法靠背定义回答，且单元结束时仍能回答
- [ ] 每条可观察目标都挂到了某条持久理解上，持久理解也都有目标或证据支撑
- [ ] 表现性任务有 GRASPS 六要素，P 与 S 落到了实处
- [ ] 概念诊断的干扰项来自真实迷思概念，不是现编的
- [ ] 三类证据齐全，且含至少一个迁移应用（用到没教过的新情境）
- [ ] WHERETO 每一项都有"落在哪"的答案，E·Experience 与 R·Rethink 不为空
- [ ] 表现性任务与终结性考核没有对同一份产出重复计分；计入平时成绩的规则已第一周公布
