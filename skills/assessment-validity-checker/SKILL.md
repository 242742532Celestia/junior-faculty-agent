# 考核效度审查

## 这个技能解决什么

一份试卷出完了，没人问过它到底在测什么。目标写"能设计并评价一个实验方案"，
卷子上最后一道大题是"简述实验设计的基本原则"，另外半张卷考术语定义。
学生分数很整齐，"设计"这项能力却没有任何证据支撑——高分学生同样可能做不出方案。

同一门课每学期都这样：教师凭经验命题，学生凭经验复习，双方都以为测到了目标。
问题不在命题技巧，而在**从"要测什么"到"这题在测什么"之间没有任何中间步骤**，
于是构念被悄悄替换（用"记得住"代替"想得清"），覆盖缺口（教了整章、只考一节），
而这些都发生在课程结束、学生已经考完之后。

效度审查就是补上这个中间步骤：先把目标还原成构念，再把每道题挂到构念上，
用矩阵看见空洞，用推断链追问"这份分数凭什么能支撑那个结论"。

## 什么时候用 / 什么时候不用

**用**：
- 期末卷、实验考核、大作业提交前，判断"这份考核能不能证明目标达成了"
- 课程目标写的是高阶能力（设计、评价、迁移），而考核全是记忆题
- 学院要求提交课程考核的效度说明或目标达成度分析材料
- 学生反馈"考的不是我们学的"，需要定位是教的问题还是考的问题

**不用**：
- 只想提高本次考试的区分度或命题技巧（那是命题技巧问题，不是效度问题）
- 已经在改教学设计、还没定考核形式（先做 `backwards-design-unit-planner`）
- 单次课堂随堂小测的即时调整（走 `formative-assessment-technique-selector` 更合适）
- 纯粹核对分值算术、漏题漏页（那属于质量检查，不是效度）

## 输入

**必填**（缺任一项先出草稿并把假设标出来，不要停下来空等）：
1. 考核材料本身：试卷题目全文 / 作业任务说明 / 考核形式与时长
2. 该考核对应的课程目标或单元目标清单（每条含教学动词）
3. 考核在总评中的权重（用于判断"这块失真影响多大"）
4. 授课对象：年级、专业、班级规模

**选填**（没有就留空，写进"需人工核验清单"，**不许编**）：
5. 本课程各考核项的权重构成（用于合计 100% 校验）
6. 毕业要求指标点编号（**用户没给就留空**，不要自造指标体系）
7. 命题人是谁（是否一人命题、是否已做阅卷校准）
8. 教材与参考书版本、对应章节（ISBN 需真实，查不到写"待补充"）

## 执行步骤

1. **先把目标翻译成构念。**
   对每条目标问三件事：学生**做什么可观察的动作**、**在什么情境下做**、**做到什么程度算达成**。
   写不出这三要素，说明这条目标本身还不能被考核——它不是效度问题，是目标问题，
   记到"目标层面的待办"，别硬套进矩阵。
   例："理解测量误差" → 行为=从一组重复测量中估计不确定度并解释其来源；
   情境=在实验报告中处理一组带重复的数据；程度=能说明估计策略对不确定度的影响。

2. **给每条题目标注它实际在测的构念，而不是它声称在测的构念。**
   把题目挂到构念上，允许一条题挂多个构念，也允许标"与任何构念无关"（纯格式题、区分度填充题）。
   标注时以**题目要求学生实际做的事**为准，不以题干字面为准：
   题干写"评价一个方案"但设问全是"指出该方案中的两个术语"，
   它测的是术语识别，不是评价。

3. **做覆盖度诊断。**
   用构念×题目矩阵找三类问题：
   - **空行**（构念没有任何题目）→ 教了没考，学生复习不到，权重虚高；
   - **空洞**（某构念只有一题、或只有低阶题）→ 名义覆盖，实质没测；
   - **空列/越界题**（题目不对应任何目标构念）→ 考了近义词或无关能力，
     挤占课时又制造"复习了却不会"。

4. **做权重诊断。**
   把每个构念的**分值占比**与该构念在目标体系中的**应然占比**并列。
   两者差得远，就是"时间花在哪、考的是哪、最后计的是哪"三者打架。
   这一步同时做权重合计校验：课程各项考核权重加总必须**恰好 100%**。

5. **走效度论证链（Kane 的四步推断）。**
   对每一条主要结论（例如"通过本课程的学生具备方案设计能力"）逐问：
   - **评分推断**：阅卷标准能不能把不同水平的作答分到不同等级？同一份卷两个评分者差多少？
   - **泛化推断**：这几十道题是不是这个构念的"代表样本"？还是只测了一个熟悉情境？
   - **外推推断**：从这次的表现，能外推到"具备该能力"吗？一道题能外推多远？
   - **后果推断**：拿这个分数做什么决策？据此分流、授学位、判及格，后果是什么？
   四步里任何一步站不住，这条结论就不能写进达成度报告。

6. **检查三类经典失真（Messick / 2014 版测试标准的表述）。**
   - **构念代表不足**：目标里的关键成分没有任何题覆盖；
   - **构念无关变异**：与目标无关的因素（背书风、答题速度、是否熟悉题型）左右了分数；
   - **教学效应污染**：考法太贴近课堂例题，测出的是"跟课跟得紧"而不是"能力够"。

7. **分诊并排序。**
   每个问题标为**致命**（构念错位或核心能力零覆盖）/ **严重**（覆盖不足、权重失衡）/
   **提示**（表述与判分措辞不一致）。排序依据：影响面（涉及多少目标）× 严重度 × 改造成本。
   致命项先改，因为它们会让整门课的达成度结论失效。

8. **写可执行的整改动作。**
   每个问题必须给到"改什么、怎么改、改完怎么验证"。
   只写"建议加强某能力考察"不算整改。

9. **收口：列出不确定项。**
   凡是推断而非事实的（"大概率是构念错位"）标「假设」，
   用户没给但必须知道的信息（阅卷校准记录、指标点编号、ISBN）标「待补充」。

## 中国高校语境要点

- **学时与命题量**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。
  终结性考核的题量与分值要能装进实际考试时长（如 120 分钟卷、闭卷），
  评审时先做"题量—时长"换算，再谈覆盖度。
- **评价制度**：形成性评价（课堂提问、随堂小测、discussion、阶段作业）承担"提前发现错位"的功能，
  终结性考核（期末笔试/开卷/机考）承担"留证"的功能。
  审查要分别做一次：形成性证据够不够早暴露构念错位，终结性证据够不够支撑达成结论。
- **权重构成**：平时成绩与期末成绩各项百分比必须**加总恰好 100%**；
  审查中发现缺项或合计不等于 100% 要直接标为严重问题。
- **等级体系**：用「优秀 / 良好 / 合格 / 不合格」映射分数段，
  不把 K-12 的 band 体系当成中国高校及格线；
  及格线与等级切分点是否站得住，属于"后果推断"必须回答的问题。
- **毕业要求支撑**：课程目标对应的毕业要求指标点编号由院系给定。
  **用户没给就留空**，在表 1 旁注明"待补充"，不要自己编"毕业要求 3.2"。
- **课程思政**：审查的是"考核是否测到目标"，思政融入点若作为教学目标存在，
  同样需要在矩阵里找到对应构念；找不到就是空行，按实报，不要用思政目标凑覆盖。
- **教材与参考书**：ISBN 需真实并与课程章节对应，查不到就写「待补充」，不许编造。
- **实践/实验环节**：实验考核单列时（如实验报告占 20%），在表 2 标注其分值，
  并在表 5 校验实验分值与"设计/评价类"构念的对应关系，避免实验环节只考操作。

## 易错点

- ❌ 按题干字面判定题目在测什么 → ✅ 以"题目要求学生实际做的动作"为判定依据
- ❌ 目标是"理解/掌握"就直接当构念用 → ✅ 先转成可观察行为+情境+达成程度，转不出来就归入"目标不可评"
- ❌ 只查"教了没考"，不查"考了没教" → ✅ 空行与越界题同时查，矩阵必须双向扫
- ❌ 把"每章都出一道题"当成覆盖充分 → ✅ 覆盖看构念与行为层次的组合，单点题堆数量无效
- ❌ 用难度或区分度代替效度 → ✅ 难度高说明题难，效度说的是"测的是不是它要测的东西"
- ❌ 效度结论只写"本次考核效度良好" → ✅ 必须给出四步推断各自站不站得住及缺口
- ❌ 权重合计随手写"平时 40% 期末 60%" → ✅ 逐项加总校验到 100%，差 0.1% 也要报
- ❌ 整改只写"加强某能力考察" → ✅ 每条问题给出改什么、怎么改、改完如何验证
- ❌ 编造毕业要求编号、教材 ISBN、等级切分点 → ✅ 查不到写「待补充」，并列入核验清单

## 自检清单

- [ ] 每条目标都已转成"行为+情境+达成程度"，转不出的已单列
- [ ] 每道题都标注了实际测到的构念，允许标"与目标无关"
- [ ] 覆盖度诊断同时检查了空行、空洞、越界题三类
- [ ] 构念分值占比与应然占比已并列，差异已排序
- [ ] 考核权重合计已核到 100%
- [ ] 四步推断每一步都给了"站得住/站不住 + 缺口"
- [ ] 致命级问题数量与整改动作一一对应
- [ ] 每个整改动作都带验证方式
- [ ] 等级体系用「优秀/良好/合格/不合格」，未套用 K-12 band
- [ ] 毕业要求编号、ISBN 等事实项：真实或已列入待补充，无编造
- [ ] 假设与待确认项已单列

## 交叉技能

- 目标太大、构念划得太粗 → `competency-unpacker`
- 考核方案整体设计与权重分配 → `assessment-design-orchestrator`
- 评分量规与等级切分点 → `criterion-referenced-rubric-generator`、`single-point-rubric-designer`
- 构念落到题目上的具体设计 → `exam-question-bank`、`hinge-question-designer`
- 课堂层面的即时证据采集 → `checking-for-understanding-protocol-designer`
- 学生作业的错误类型诊断 → `gap-analysis-from-student-work`、`error-analysis-protocol`
- 成绩数据的使用与解释边界 → `learning-analytics-interpretation-guide`
- 学段与课时制度换算 → `he-context-adapter`
