# 例题—渐隐—变式练习序列

## 这个技能解决什么

例题讲完，练习题发下去，学生还是不会做。常见的三种病因：

- **例题只有结果没有思路**：例题写得像答案册，学生看懂的是结论，看不到"为什么先做这一步"；
- **练习与例题长得一样**：三道题换数字不换结构，学生做对的是记忆不是理解，一换情境就崩；
- **梯度是断的**：例题讲完直接上综合题，中间没有从"跟着做"到"自己做"的过渡台阶。

练习序列要解决的是**梯度**问题：先把"专家的完整过程"展示出来，
再逐步抽掉支架（给出前一步、给出一半、只给目标、只换情境），
最后撤到完全独立；并且在不同位置插入**变式题**，
让同一结构在不同表面特征下反复被调用，结构本身才变成可迁移的东西。

## 什么时候用 / 什么时候不用

**用**：
- 教授新的解题程序、新的算法、新的案例分析框架
- 学生"例题听懂了但题目不会做"
- 练习题重复率高，学生靠背答案过关
- 期末复习阶段，需要把散点题目串成一条难度与结构都递进的链

**不用**：
- 纯知识的记忆与再认（用提取练习类技能更合适）
- 开放式研究项目（没有可分解的程序结构）
- 学生已熟练的内容（应换题换情境，而不是重排梯度）

## 输入

**必填**：
1. 本环节要练的**具体程序或概念**（写清学生最终要独立完成的任务）
2. 可用时长（45 分钟单次课 / 2 学时连堂 90 分钟）
3. 学生先备水平与已做过的题量
4. 学生历史高频错误（决定变式方向与干预点）

**选填**：
5. 可用题目来源（自编 / 教材习题 / 题库）
6. 课程思政要求
7. 毕业要求指标点编号（**没给就留空**）
8. 教材与参考书版本（ISBN 须真实，查不到写「待补充」）
9. 是否可分组或使用计算工具

## 执行步骤

1. **把目标还原成"可操作的程序"。**
   写出这项任务包含哪几个关键步骤，以及**哪些步骤最容易错**。
   如果写不出关键步骤，说明这个目标还不适合用练习序列教（它可能是理解类目标，
   应转成别的活动）。

2. **选 2–3 个完整例题，按"专家表征"标准检查。**
   一个合格的完整例题要同时满足：步骤全部可见；每个关键步骤后面写明"为什么选这一步"；
   情境真实或接近真实；覆盖关键步骤且不引入无关复杂度；难度略高于学生当前水平。
   例题太少则没有对照，太少则学生没有迁移的参照系；3 个以上通常超出单课时承载。
   **教师平时用的解法要写出来**：学生会用你的解法，不要用你事后觉得"更漂亮"的解法。

3. **搭五级渐隐阶梯。**
   阶梯固定为：完整例题 → 完成式（给出前几步，学生续写）→ 仿写（结构相同、数值不同，
   仍可对照例题）→ 变式（情境或表征改变，结构保留）→ 独立（无任何支架）。
   每下一级都要写明"这一次撤掉了哪一层"；如果两级的支架没区别，这一级就不成立。

4. **安排变式，并给出变式维度表。**
   常见变式轴：数值变、情境变、表征变（文字↔图↔符号↔代码）、条件反向（问"怎样才不成立"）、
   表征层变（同一事实在不同学科里出现）。规律是：**先同型后异型**——
   结构不变只换表面，练"识别结构"；结构变表面也变，练"迁移"。

5. **控制间隔，避免顺序效应。**
   同型题不要连排超过 3 题，否则学生靠滑动的节奏答题。插入异型题或换个表征，
   迫使学生每次都重新识别结构。交错排布的收益在延迟测验上更明显，
   课上就要把"换题要重新判断"变成明确要求。

6. **预算时间与题量。**
   45 分钟课的实际上限：完整例题 1–2 个、完成式 2 道、变式 2–3 道、独立 1 道。
   超过这个量，学生会跳过例题直接做变式，序列就白排了。
   每道题写预计用时，累加后必须留出讲解与检查时间。

7. **预设典型错误与干预动作。**
   对每个关键步骤写一个学生最可能犯的错（不是泛泛的"概念不清"），
   以及发现该错时的具体动作：当场停 30 秒集体纠、让错误答案上黑板对比、
   换一道只针对该错的题。最后一步特别重要——序列必须回应一个真实的错误模式。

8. **输出核验清单。**
   凡属推断（难度是否合适、学生会在哪卡住）标「假设」；
   凡属未提供但必须知道的信息（题目出处、教材版本）标「待补充」。

## 中国高校语境要点

- **学时与题量**：1 学时 = 45 分钟，完整例题 + 完成式 + 变式 + 独立题建议上限为
  2 + 2 + 3 + 1；2 学时连堂 90 分钟可到 2 + 3 + 4 + 2，但必须留出至少 25 分钟做讲解与检查，
  否则序列变成"赶题"，渐隐的用意全失。
- **实践环节**：机房课把"独立题"换成编程题或实验步骤题，
  变式可设计成"同一算法处理不同数据类型"；实验课的分组方式与考核占比要在方案里写明。
- **大班**：变式题适合当堂用答题器做集体作答，能立刻看出哪一变式全体失守。
- **评价**：课内练习属形成性评价，若计入平时成绩需写明占比，平时/期末各项百分比**加总恰好 100%**；
  期末终结性考核的题型应与序列末级（L5）的独立性一致，
  若期末全是例题同型，学生在序列里练的能力就落不到考核上。
- **毕业要求**：序列对应的目标可向毕业要求指标点追溯，编号由院系给定，**没给就留空**。
- **课程思政**：变式轴里可以放一个真实工程情境（如不同行业场景下的同一技术路线），
  自然体现技术的社会责任与适用边界；不要在每道题后加一句价值评论。
- **教材**：例题若改编自教材习题，注明章节与 ISBN；改编幅度大时要写明"改编自某章节第 X 题"，
  查不到具体出处写「待补充」，不得编造页码。

## 易错点

- ❌ 例题只给答案不给判断依据 → ✅ 每个关键步骤后写"为什么先做这一步"
- ❌ 用"更漂亮的解法"做例题 → ✅ 用教师平时真实会用的解法，学生模仿的是你的思路
- ❌ 练习题只换数字不换情境 → ✅ 变式轴至少覆盖"情境"与"表征"两个方向
- ❌ 渐隐阶梯形同虚设（两级支架没区别） → ✅ 每级写明撤掉了哪一层，写不出就不设这一级
- ❌ 题量堆到 20 道、学生跳过例题 → ✅ 按表 6 的上限控制，宁可少而有序
- ❌ 变式题只换情境但难度同步上升 → ✅ 变式题难度与 L3 持平，考的是识别而非难度
- ❌ 序列排完不针对真实错误 → ✅ 每个关键步骤预设一个高频错误与干预动作
- ❌ 编造题目页码、指标点编号或 ISBN → ✅ 真实提供或留空进核验清单

## 自检清单

- [ ] 目标已还原为可操作的关键步骤清单，并标出易错步骤
- [ ] 例题 1–2 个，每个都满足"步骤可见 + 依据可见 + 情境真实"
- [ ] 五级渐隐阶梯齐全，每级写明撤掉了哪一层
- [ ] 变式维度表至少覆盖两个变式轴，且写明保持不变的成分
- [ ] 同型题连续不超过 3 题
- [ ] 每题有预计用时，累加后留出讲解与检查时间
- [ ] 每个关键步骤预设了典型错误与具体干预动作
- [ ] 期末考题型与序列末级的独立性一致
- [ ] 平时/期末各项百分比合计 = 100%
- [ ] 题目出处、ISBN、指标点编号等事实项：真实或已列入待补充，无编造
