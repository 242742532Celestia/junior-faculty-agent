# 实训任务型课程设计

## 这个技能解决什么

职教实训课最常见的失败是"**实训课讲成了理论课**"：讲了一堆概念，做了一个跟概念无关的演示，学生既没学会操作，也没建立安全的职业判断。

本技能的核心产出不是讲稿，而是**实训作业序列**：学习者要**按顺序真的把这项工作做一遍**，带着工具、设备状态和后果。

一句话检验：把讲义拿走，学生能不能按手上的工序卡把这件活干完，并且知道什么时候该停。

## 什么时候用

用：

- 实训 / 实践类课程设计（机电、护理、烹饪、汽修、电商运营、财务实务、软件测试、物流调度等）；
- 需要对接职业资格或技能等级证书的课程；
- 企业真实任务引入的课内项目、跟岗前的模拟训练；
- 把"演示课"改成"动手课"的整改；
- 需要一份可落地的工序卡与安全边界的教学文件。

**不用**：

- 纯理论讲授课；
- 没有任何操作流程与工具状态的任务（如数学推导、诗歌朗读）——按普通课程设计处理；
- 只需要一份实习计划或校企合作协议时。

## 输入

**必填**（缺任一项时先按默认起草，并在需人工核验清单中标为假设）：

- 职业任务与工种；
- 学时（**理论 / 实训分列**）；
- 场地与设备条件；
- 班级规模与分组上限。

**选填**（**没给就留空，不编**）：

- 具体设备型号与量程；
- 考核方式与权重；
- 职业资格标准与证书要求；
- 实习单位要求；
- 安全管理规定原文。

## 执行步骤

**适用边界（先判断再动手）**

如果这项任务**没有操作流程、没有工具或设备状态、没有安全或通过 / 不通过判断**（例如数学推导、诗歌朗读），就在回复里**用一句话说明**，并改按普通课程设计，**不要硬套工序卡**。

**结构硬约束**

| 约束 | 要求 |
|---|---|
| 开篇 | **恰好 1 个情境交底页**：工作任务、任务边界、训练目标、关键步骤、安全边界 / 风险提示、完成标准（GO/STOP 判据）。**不是**学科发展史，不是定义页 |
| 主体 | **同一项任务的操作工序段**，按技术员真实作业顺序：准备与设备检查 → 操作本身（逐步） → 验证 / 测量 / 记录 → 交接与完成检查 |
| 动手环节 | **至少 3 个** |
| 决策检查点 | **至少 1 个 GO/STOP 检查点**：给定一个异常读数或不安全状态，学习者判断"继续 / 重新检查 / 停线"。**不是词汇小测** |
| 收尾 | 落在**完成标准**，不是概念总结 |

**工序卡字段**

每个动手环节一张：

| 字段 | 要求 |
|---|---|
| 工序类型 | 检修 / 装配 / 检验 / 操作 / 自定义 |
| 本段任务 | |
| 所需工具与器材 | 含仪器、耗材、劳保用品 |
| 操作步骤 | 有序 |
| 成功判据 | **阈值、读数、状态**，不是"理解了概念" |
| 错误后果 | 跳步或蛮干到底会发生什么 |

**场景命名读作工作步骤**

- 好：「断电确认与验电」「绝缘电阻测量与判读」「异常读数：继续还是停线」。
- 坏：「什么是低压配电柜」「配电柜的发展历史」「本课总结」。

**禁止项**

- 纯理论段、概念讲授、公式推导；
- 泛泛的「课程总结」收尾；
- 所有动手环节都做成同一张勾选清单（要有变化：检查表、测量面板、步骤排序、故障分诊）；
- 无安全边界的动手环节；
- 用"理解了原理"充当成功判据。

**评价**

- 评分表各部分权重合计**恰好 100%**；未定则写「待考核方案确定」，合计栏写"待定"，不许填占位数字。
- GO/STOP 检查点**单列权重**，不并入其他项。
- 实操评分点须可观察（读数、动作、顺序、记录完整性），不写"态度好"这类无法判定的项。

## 中国高校语境要点

- **实训学时与理论学时分列**，写进大纲与进度表，不能合并成一个数字。
- **分组人数上限、场地与设备条件**按学院实际；**没给就标「待补充」**，不要按常见值猜。
- **安全教育与实习责任险**按学校现行规定执行，**不自创规定**、不编条款号。
- **评分表各部分权重合计恰好 100%**，GO/STOP 检查点**单列权重**。
- **职业资格 / 技能等级证书对接**：没给就留空，**不编证号与等级**。
- **课程思政自然融入**：把**职业规范、安全意识、对他人安全的责任**写在"错误后果"与"停线判断"里，不写口号。
- **AI 工具边界**：AI 工具**不得用于替代操作记录与判读**；可用于整理与检索，测量值与判读结论须由学习者本人完成并署名。
- **学时换算**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。工序段时间按此填写。

## 易错点

- ❌ 实训课讲成理论课（大量概念讲授 + 一个无关演示） → ✅ 主体是按真实作业顺序展开的工序段，每个环节都有动手与判据。
- ❌ 没有安全边界与 GO/STOP 检查点 → ✅ 交底页写明风险与禁止动作，至少 1 个 GO/STOP 决策点并单列权重。
- ❌ 动手环节凑不够 3 个 → ✅ 工序分解表逐段核对，"动手环节"至少 3 个。
- ❌ 成功判据写"理解了概念" → ✅ 写成阈值、读数或状态（例：绝缘电阻读数不低于规定值且无异常声响）。
- ❌ 收尾写概念总结 → ✅ 收尾落在完成标准与交接检查。
- ❌ 所有环节都做成同一张勾选清单 → ✅ 环节形态有变化：检查表、测量面板、步骤排序、故障分诊。
- ❌ 编造设备参数与证号等级 → ✅ 一律「待补充」并进需人工核验清单。
- ❌ 权重凑整或填占位数字 → ✅ 合计恰好 100%；未定就写「待考核方案确定」，合计写"待定"。
- ❌ 任务没有工序还硬套工序卡 → ✅ 用一句话说明该任务无操作流程，改按普通课程设计。
- ❌ 情境页写成学科发展史或定义页 → ✅ 开篇恰好 1 页，写工作任务、边界、目标、安全与完成标准。

- [ ] 开篇**恰好 1 个**情境交底页，含任务、边界、目标、关键步骤、安全边界、完成标准
- [ ] 情境交底页不是学科发展史或定义页
- [ ] 主体按准备与设备检查 → 操作 → 验证 / 测量 / 记录 → 交接与完成检查排序
- [ ] 动手环节**不少于 3 个**，且已在工序分解表中标出
- [ ] 至少 1 个 GO/STOP 检查点，给定的是异常读数或不安全状态，不是词汇题
- [ ] 每张工序卡 6 个字段齐全，步骤有序
- [ ] 成功判据全部是阈值 / 读数 / 状态，没有"理解了概念"式表述
- [ ] 错误后果写明跳步或蛮干到底的实际后果
- [ ] 环节形态有变化，不是同一张勾选清单重复
- [ ] 工具与器材清单含仪器、耗材、劳保用品；未给参数写「待补充」
