# 引用核验与一致性审计规则（citation-audit-rules）

本文件是 `citation-audit` 技能的可引用规则底稿。技能主文件 `SKILL.md` 给出工作流，
本文件给出**判定阈值、四档判定的充分必要条件、取径理由、失败模式**。

---

## 1. 判定阈值表

| 维度 | 阈值 | 判定含义 | 备注 |
|---|---|---|---|
| 标题相似度 | `ratio >= 0.85` | 标题匹配，视为同一条文献 | 由 `difflib.SequenceMatcher(None, a, b).ratio()` 计算，比较前先归一化（小写、去标点、压缩空白） |
| 标题相似度 | `0.70 <= ratio < 0.85` | 标题**存疑**：可能是同一文献但有副标题/译名差异，也可能是引用错文 | 不直接判错，需人工看标题全文 |
| 标题相似度 | `ratio < 0.70` | 标题**证伪**：数据源命中的文献与引用不是同一篇 | 仍需确认是否命中了"同主题不同文献" |
| 年份差 | `|ref_year - source_year| <= 2` | 年份可接受 | 允许 2 年偏差，容纳 online-first / 会议年与正式出版年不同 |
| 年份差 | `|ref_year - source_year| > 2` | 判**存疑**，标注"年份不符" | 不单独判错：预印本→正式版常差 1–3 年 |
| 第一作者姓氏 | 归一化后完全相同 | 作者一致 | 归一化：去空格、去标点、转小写 |
| 第一作者姓氏 | 归一化后不同 | 判**存疑**，标注"作者不符" | 机构作者无姓氏时，此项**跳过**，不判错 |

## 2. 四档判定的充分必要条件

### 2.1 证实（confirmed）

**充分必要条件**：至少命中一个权威数据源（Crossref / arXiv / Semantic Scholar），且
- 标题相似度 `ratio >= 0.85`，**并且**
- 年份差 `<= 2`（若两侧年份均可得），**并且**
- 第一作者姓氏归一化后相同（若两侧作者均可得）。

三条件的"并且"关系只作用于**可得的字段**：字段缺失时该条件视为满足，但必须在报告中写明该字段未核验。

### 2.2 存疑（suspicious）

满足下列**任一**条件即为存疑（不足以判错，但必须人工复核）：

1. 命中数据源，标题相似度落在 `[0.70, 0.85)`；
2. 年份差 `> 2`；
3. 第一作者姓氏不匹配；
4. 多个数据源给出**互相冲突**的结论（例如一个源证实、另一个源证伪）。

存疑的输出必须至少包含一条**具体可执行的说明**，例如"年份不符：引用 2019，数据源 2023（相差 4 年）"。

### 2.3 证伪（refuted）

命中数据源，但标题相似度 `< 0.70`。

**必要条件是"命中了数据源"**。若根本没有命中任何记录，就不是证伪，而是查不到（见 2.4）。
证伪是强结论，报告中必须展示：引用标题、命中标题、相似度数值，三者齐备。

### 2.4 查不到（unknown）

下列**任一**情形即为查不到：

1. 所有数据源检索均无匹配记录；
2. 数据源访问失败（超时、HTTP 429/5xx 重试后仍失败、返回体无法解析）；
3. 输入只有作者+年份、没有标题也没有 DOI/ID，检索条件不足以定位。

🔴 **查不到 ≠ 错**。报告必须写明：
> "数据库未收录，可能是预印本/会议论文/非英文文献"

并**禁止**在查不到的情况下输出"证伪"。把"查不到"写成"证伪"是本技能最严重的错误，
因为它会误导作者删掉真实存在的文献。

## 3. "只报矛盾、不报缺失"的取径理由

这一条同时约束两个脚本。

### 3.1 为什么只报矛盾

- **矛盾是可证伪的**：正文出现 `[12]`，而文献表里编号只到 8 —— 这是文档内部两个事实的直接冲突，
  证据在文档里，判定不依赖外部数据库。
- **缺失是不可证的**：文献表里没有某条，可能是作者确实遗漏，也可能是**脚本没解析出来**
  （表格跨行、条目写在图片里、文献表标题用了非标准写法如"主要参考文献"）。
  把"脚本没解析出来"报成"文献缺失"，制造的是假警报。

### 3.2 具体取径

| 情况 | 报不报 | 报法 |
|---|---|---|
| 正文有 `[12]`，文献表无编号 12 | 报 | **悬空引用**（高） |
| 文献表有条目，正文从未引 | 报 | **幽灵条目**（中） |
| 正文 `[2]` 实际对应文献表第 5 条 | 报 | **编号错位**（高） |
| 正文 `Zhang et al. (2021)` vs 文献表同年条目第一作者是 `Li` | 报 | **作者指代不一致**（中/高） |
| 文档根本没有可解析的文献表 | 报，但**降级为** | **文献表缺失**（低/中），不报悬空/幽灵 |
| 某条参考文献在数据库查不到 | **不报**为作者的问题 | 只输出"查不到"并说明可能原因 |
| 文献表少了一条，但正文也没有对应引用 | **不报** | 这是作者的编辑偏好，不是矛盾 |

### 3.3 降级与噪声控制

- "文献表缺失"同时提示两种可能：真的没写，或脚本没识别到文献表标题。
  提示语必须同时覆盖这两种可能，不能断言"你漏写了参考文献"。
- 严重度分三档：**高**（悬空引用 / 编号错位 / 幽灵条目 / 明确的作者年份冲突）、
  **中**（风格混用 / 幽灵条目 / 作者姓氏不符）、**低**（文献表整体缺失 / 作者无法定位）。
- 同一处重复出现的同一类问题合并成一条，避免刷屏。

## 4. 常见失败模式

### 4.1 预印本与正式版 DOI 不同
arXiv 预印本（如 `arXiv:2103.00012`）后续发表时通常获得**新的 DOI**，标题可能有副标题变化、
作者顺序调整、期刊名替换。后果：按预印本 DOI 查 Crossref 必然失败（查不到，不是证伪）；
按正式版 DOI 查则年份会差 1–3 年 → 触发"年份不符"存疑。
处理：查不到时先按标题跨源检索（Crossref 标题 + arXiv 标题），匹配到即改判为证实或存疑。

### 4.2 页码差异只比首页
同一个卷期内，页码范围可能因出版商排版（如封面页计入）差 1–2 页。
本技能**不把页码纳入判定**——只比标题、年份、第一作者姓氏。原因是页码差异的噪声
（±2 页）远大于真错率，而卷号/页码不一致的信号价值低。若需要页码级核验，
交由 `citation-management` 处理。

### 4.3 机构作者无姓氏
部分期刊用机构名署名（如"中国科学院"），第一条作者记录没有 family 字段，或 family 是机构全称。
此时"第一作者姓氏"这个判据**不适用**，必须跳过，不得判"作者不符"。
脚本里表现为 `authors` 为空或首项形如机构全称。

### 4.4 会议论文无卷号
会议论文通常没有卷号（volume）、页码也可能只有起始页；arXiv 上的会议版更常见。
后果：依赖卷号/页码的匹配会失败。本技能只做标题+年份+作者匹配，天然规避；
但需注意**同题会议版与期刊版**会触发"年份不符"存疑，此时应视为正常现象。

### 4.5 DOI 解析重定向
`https://doi.org/10.xxxx/yyy` 会 302 重定向到出版商页面。脚本只请求 `api.crossref.org`，
**不做**出版商页面抓取，因此不受重定向影响；但若有人手工把出版商 URL 塞进 `--reference`，
会因不含 DOI 形态而走标题检索路径 → 大概率查不到。处理：识别出版商域名时提示改用 DOI。

### 4.6 网络受限 / API 限流
Crossref 对匿名请求有速率限制，命中 429；Semantic Scholar 匿名接口同样有限流。
处理：指数退避重试（最多 3 次，基数 1.5 秒），仍失败则该数据源降级为"查不到"，
并在报告中写明"数据源访问异常"，**不得**把网络失败解释成文献有问题。

### 4.7 文档格式差异
- `.docx`：用 `zipfile` 读 `word/document.xml`，再用 `xml.etree` 抽 `<w:t>` 文本节点。
  **不要**引入 python-docx（本技能只用标准库）。注意 Word 里引用域（REF / CITATION 域代码）
  抽出来的是**域结果文本**，可能为空或为占位符（如"错误！未找到引用源"）——这属于"查不到"，
  不是"证伪"。
- `.md`：文献表标题可能是 `## 参考文献`、`## References`、`## 参考文献 References`。
  脚本按标题行切分；标题识别不到时，退化为"文献表缺失（低）"提示，而不是报一堆悬空引用。

### 4.8 编号风格混用被误判
正文里既有 `[1]` 又有 `(Smith, 2020)`，有时是**风格混用**，有时是**引号内的正文举例**。
脚本只报"混用"这一条中等严重度问题，由人工判断，不自动改写。

## 5. API 不可用时如何在报告中如实标注

**原则：如实标注状态，不外推结论。**

报告必须包含以下三要素：

1. **状态**：明确写"数据源访问异常"，而不是让读者以为查过了。
2. **原因**：写清是超时、429、5xx、还是 DNS/连接失败。
3. **结论边界**：写明"该条无法核验，既不构成证实，也不构成证伪"。

推荐表述模板：

```
[3] Zhang, W. (2021). Some Title Here.
    判定：查不到
    ! 数据源访问异常：Crossref 标题检索失败：<urlopen error timed out>
    - 数据库未收录，可能是预印本/会议论文/非英文文献；查不到不等于错
```

**禁止的表述**：
- ❌"该文献不存在" —— 网络失败无法支持这个结论。
- ❌"疑似虚假引用" —— 那是证伪档的结论，需要 `ratio < 0.70` 的证据支撑。
- ❌"共核验 12 条，均为真实文献" —— 查不到的条目必须单独计数。

**汇总行的要求**：四种状态**分别计数**，不得只报"通过率"。
"查不到"的条数要在汇总中显式出现，提醒作者这部分尚未核验。
