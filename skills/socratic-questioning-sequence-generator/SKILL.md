# 苏格拉底式追问序列生成器

## 这个技能解决什么

教师自认为在用苏格拉底式提问，学生听到的却是"你这都答对了还要问什么"——问题带着"正确答案"的方向，问句本身在暗示。

学生一开口就答结论（"因为它更好"），没有推理过程可追；教师不断追问"为什么"，问了三轮，学生只会越来越烦。

追到第三轮，问题已经跑到课程目标之外，学生开始编答案，教师无法判断是真懂还是被逼出来的。

学生说"不知道"，教师就没有下一步动作，课堂转入讲授，前面设计的追问全部作废。

一问一答变成了教师与单个学生的私聊，全班其他人在旁边刷手机。

追问是**有结构的动作序列**，不是随机的"再问为什么"。这个技能把一次苏格拉底式对话拆成五类可轮换的动作（澄清、举例、反例、后果、原理），一次只做一个，每轮有话术、有分支预案、有退出条件，并给出 8 分钟的固定时间盒。

## 什么时候用

**用**：

- 学生回答过于笼统，需要一步步把它带到可检验的理由上。
- 学生给出结论但说不出推导过程，教师要复原他的推理链。
- 课堂目标是让学生自己发现某个规律或判断，而不是听教师讲出来。
- 学生说"不知道"，需要一个不羞辱他又能推进的接续动作。
- 教师要设计"点名—追问—全班回应的"课堂环节脚本。

**不用**：

- 需要快速确认事实、核对数值或检查记忆——那是形成性评价技术。
- 学生完全没有相关经验，追问只会逼出编造；先用实例或演示补经验。
- 目的是让学生记住某个结论（例如公式、名词定义），讲授与重复练习更合适。
- 时间只剩 2–3 分钟，容不下一轮完整的追问。

## 输入

**必填**：

1. 追问的起点：学生（或预设的回答）说了什么。缺省按"学生给出一个结论但没有依据"处理，并在输出中标注该假设。
2. 要抵达的教学命题：追问结束时学生应该能说出的那句话。缺省按"该节课的核心概念"处理。
3. 单次追问的可用时间（分钟）。缺省按 8 分钟处理。
4. 班级规模与点名策略。缺省按 30–45 人、一次只点 1 人应答、全班可补充处理。

**可选**：

5. 学生先备水平。缺省按"掌握基本术语、能做简单比较"处理。
6. 课堂可见材料。缺省按"有板书与投影"处理。
7. 是否计入形成性评价。缺省按"计入，权重 ≤10%"处理。
8. 课程思政要求。缺省按"在后果类追问中自然融入责任与代价"处理。

## 执行步骤

1. **先把目标命题写成一个学生能说出口的句子。** 例："在给定约束下，先降载再调参比同时调整更省总时间。"目标写成句子，追问才有落点。
2. **给起点回答做一次编码。** 判断它是结论、定义、感受还是推理链。起点是结论就追问依据；起点是感受就追问实例；起点是背诵就追问适用条件。
3. **选起点动作。** 五类动作（澄清 / 举例 / 反例 / 后果 / 原理）里选一个作为第一轮，通常是澄清或举例。
4. **一次只写一轮，先写满三层再展开。** 用模板 E 生成 3–6 轮脚本，每轮一个动作，每轮配 1–2 条学生可能的回答分支和分支后的下一轮。
5. **给每轮写退出条件。** 退出条件必须可观察（学生说出含数量、比例、条件之一的句子）。没有退出条件，序列会无限延长。
6. **分配时间盒。** 起始问 1 分钟，追问 4–6 分钟（每轮 60–90 秒），收敛 2 分钟；总时长不超过给定上限，超时即进入收敛。
7. **预写卡壳处置。** 对每一轮写一句"学生答不出时的降级动作"，从模板 D 取用。
8. **写收束句。** 序列的最后必须由教师或学生把目标命题说出来，并留一句"你回到 X 的理由是……"（回收）。

## 输出模板

### 模板 A｜五类苏格拉底动作定义表

| 动作 | 目的 | 句式骨架 | 追问方向 | 风险 | 什么时候停 |
|---|---|---|---|---|---|
| 澄清 | 让学生把话说精确 | "你说的 X，具体是指……？" | 定义、边界、对象 | 变成抠字眼 | 学生的话已能被复述 |
| 举例 | 把抽象换成具体 | "能举一个你见过的 X 吗？" | 实例、场景、数据 | 举了名不副实的例子 | 学生给出可检验的实例 |
| 反例 | 检验结论的稳健性 | "如果出现 Y，这个结论还成立吗？" | 边界、失效条件 | 变成抬杠 | 学生给出反例或确认无反例 |
| 后果 | 把判断推到代价上 | "如果按 X 做，最坏会怎样？" | 风险、代价、代价承担者 | 滑向价值指责 | 学生说出具体后果 |
| 原理 | 抽出可迁移的规则 | "为什么这类问题都按 X 处理？" | 机理、迁移 | 变成术语背诵 | 学生用自己的话说出原理 |

规则：同一轮只能用一个动作；一轮只降一阶复杂度；"澄清"最多连续两轮，之后必须换动作。

### 模板 B｜逐轮脚本表（主表，照读即可）

| 轮次 | 本轮动作 | 教师话术（可直接照读） | 学生可能的回答（分支） | 分支后的下一轮 | 累计时间 | 退出条件 |
|---|---|---|---|---|---|---|
| 1 | 澄清 | "你说 X 能解决 Y——这里的 X，指的是……？" | A：具体指代明确 → 进第 2 轮"举例"；B：说不清 → 追问"那换一个例子看看它指什么" | | 1 分钟 | 学生的话能被教师准确复述一遍 |
| 2 | 举例 | "能举一个你自己见过的 X 吗？" | | | | 学生给出带具体数据的例子 |
| 3 | 反例 | "如果……，你的判断还成立吗？" | | | | 学生说出失效条件或确认成立 |
| 4 | 后果 | "如果按这个判断做，最坏的情况是什么？" | | | | 学生说出具体后果 |
| 5 | 原理 | "为什么这类问题要这样处理？" | | | | 学生用自己的话说出原理（非背书） |

### 模板 C｜追问层级与时间盒（8 分钟标准版）

| 层级 | 轮次 | 目的 | 时长 | 进入下一层的条件 |
|---|---|---|---|---|
| 第 1 层 起始问 | 第 1 轮 | 确立起点、把话摆到桌面上 | 60 秒 | 学生给出起点回答 |
| 第 2 层 追问 | 第 2–4 轮 | 把回答从"结论"推到"理由"再到"条件" | 每轮 60–90 秒，合计 4–6 分钟 | 每轮都出现可检验理由（数量、比例、条件之一） |
| 第 3 层 收敛 | 第 5 轮 | 抽出可迁移的原理，回到目标命题 | 90–120 秒 | 学生用自己的话说出原理 |

降级规则：若第 2 层连续两轮没有可检验理由，直接跳到第 3 层，用教师给出的半成品句式做支架（"你大概是想说……对吗？再加一句为什么"）。

### 模板 D｜卡壳处置表（现场照做）

| 情形 | 现场表现 | 处置动作 | 用时 |
|---|---|---|---|
| 沉默 | 学生低头不答 | 把问题降一级："先不用回答我，先问同桌"（20 秒） | 30 秒 |
| "不知道" | 直接说不会 | 给选项："是 A 还是 B？先选一个，我再问你为什么" | 60 秒 |
| 答非所问 | 答的是别的问题 | 复述目标命题，再问一次；不追加新问题 | 30 秒 |
| 背诵式回答 | 照教材念 | 追问例外："有没有一次不是这样？" | 60 秒 |
| 挑战教师 | "这有什么意义" | 认可质疑，把它变成追问对象："那我们问个更实在的：……" | 60 秒 |
| 说"都對" | 回避选择 | 给两个候选，要求二选一并说明差别 | 60 秒 |
| 学生已答到位 | 回答已含可检验理由与条件 | 立即收束，不加轮 | 0 |

### 模板 E｜话术对照表（伪苏格拉底 vs 真苏格拉底）

| ❌ 伪苏格拉底（教师想要答案） | ✅ 真苏格拉底（学生产出理由） |
|---|---|
| "这个方案显然更合理，对吧？" | "这两个方案你更倾向哪一个？你判断的依据是什么？" |
| "是不是应该先降载再调参？" | "从你刚才给的数据看，调参和降载哪个先做收益更大？" |
| "这样理解对吗？" | "你用自己的话把刚才那条规则说一遍。" |
| "这说明实验设计有问题，是不是？" | "如果这个结论成立，最可能的问题会出现在设计哪一环？" |
| "很好，还有吗？"（连续表扬） | "刚才你说 A 更好，B 同学说 A 在成本上更差——这两条能同时成立吗？" |
| "这个问题太难，换一个" | "那我们把它缩小：只看这一次实验，你观察到什么？" |

### 模板 F｜序列自检表（生成后逐项打钩）

| # | 检查项 | 通过 |
|---|---|---|
| 1 | 目标命题写成了学生能说出口的一句话 | ☐ |
| 2 | 起点回答已编码（结论/定义/感受/推理链） | ☐ |
| 3 | 每轮只用一个动作，澄清未连续超过两轮 | ☐ |
| 4 | 每轮都配了至少一条分支与分支后的走向 | ☐ |
| 5 | 每轮都有可观察的退出条件 | ☐ |
| 6 | 每轮都写了学生答不出的降级动作 | ☐ |
| 7 | 时间盒合计 ≤ 给定时长，收敛层始终保留 | ☐ |
| 8 | 最后有回收句（回到目标命题） | ☐ |
| 9 | 话术对照表已逐条核过，无"对吗""是不是"诱导 | ☐ |
| 10 | 至少有一处由学生主动说出的、可写进结论清单的表述 | ☐ |

## 中国高校语境要点

- **学时制**：一次苏格拉底追问序列建议 8 分钟（45 分钟课内），45×2 连续课时可安排两段共 15 分钟。序列不宜超过 5–6 轮，超出后教师与学生都会疲劳。
- **评价制度**：追问过程可计入形成性评价（课堂讨论 10% 以内）；"学生说出的可检验表述"可作为随堂小测的评分依据（5%）。终结性考核权重相应下调，合计必须 100%，以课程大纲为准。
- **班级规模**：40 人以上建议"点 1 人应答 + 全班补充 + 教师追问"，避免连续点名同一排；可让学生举手补充，教师优先邀请未发言者。
- **毕业要求支撑**：追问到"原理"层直接支撑"综合分析""终身学习""问题求解"类毕业要求指标点，引用本校指标点原文表述。
- **课程思政**：在"后果"类动作里自然融入责任与代价的追问（例如"这个方案出错时谁承担后果"），把价值讨论挂在具体决策后果上，而不是加一段表态。
- **学术诚信与 AI**：苏格拉底式追问的核心是让学生自己产出理由，因此课堂讨论与个人作业都不得以 AI 生成的回答替代；若课程允许使用 AI，须在作业中声明并说明"哪一部分推理是自己的"。
- **教材与参考书**：若引用启发式提问的案例集，须给出可核验书目信息（有 ISBN 写 ISBN，无则写"待补充"并注明核验渠道），不得编造 ISBN。

## 易错点

- ❌ 问题里带方向（"对吧""是不是"） → ✅ 一律改成二选一或开放问，答案必须由学生说出。
- ❌ 一轮里塞三个问题 → ✅ 一轮一问，等回答再问下一个；否则学生的回答永远接不上。
- ❌ 用"为什么"连环追问 → ✅ "为什么"要接在学生自己的话之后，且必须配"因为什么"的证据要求，否则变成质问。
- ❌ 学生答不出就自己给答案 → ✅ 用模板 D 降级：给选项、换台阶、让同桌先说，绝不代答。
- ❌ 追问到课程目标之外 → ✅ 第 2 层最多 3 轮，超出即收束；越界追问会让学生学会编造。
- ❌ 把苏格拉底提问当成"提问技巧表演" → ✅ 判据只有一个：学生是否说出了教师原本要说的那句话，且用了自己的话。
- ❌ 只追结论不追条件 → ✅ 第 3 层的收敛必须产出边界或反例，否则结论会被用到不该用的地方。
- ❌ 全班旁观、只有两人在对话 → ✅ 每 2 轮插入一次全班回应（举手/纸条/学习通），保证是全班序列。

## 自检清单

- [ ] 目标命题写成了一句学生能说出口的话
- [ ] 起点回答已分类编码，并据此选了第一轮动作
- [ ] 脚本 3–6 轮，每轮只做一个动作
- [ ] "澄清"没有连续出现超过两轮
- [ ] 每轮都配了分支预案与分支后的走向
- [ ] 每轮都有可观察的退出条件
- [ ] 每轮都写了学生答不出的降级动作
- [ ] 时间盒合计 ≤ 给定时长，且保留了收敛层
- [ ] 最后有回到目标命题的回收句
- [ ] 话术已逐条比对，无诱导性问句
- [ ] 有全班参与环节，不是单点问答
- [ ] 已安排课后记录"学生自己说出的可检验表述"

## 交叉技能

→ `hinge-question-designer`（为序列第 1 轮选准那个能改变走向的转折问题）
