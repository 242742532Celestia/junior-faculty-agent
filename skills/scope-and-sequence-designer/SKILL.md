# 教学大纲与进度编排（含学时分配）

## 这个技能解决什么

大纲写到"第 1–4 章：绪论与基本概念；第 5–8 章：理论方法；第 9–12 章：应用"就停下了，
这份大纲在教务审核时会遇到三个问题：

- **学时对不上**：48 学时的课，教学内容只排了 32 学时，剩下 16 学时去哪了？
- **考核没有位置**：期末考在第 16 周，但第 14 周才开始讲新内容，学生复习什么全凭自己；
  大作业的截止时间与哪一章的内容对不上，也没人说。
- **目标是悬空的**：课程目标写了 8 条，进度表里看不出哪一章在支撑哪一条，
  到考核周才发现"能评价"这条目标全学期没有落点。
大纲的本质不是内容目录，是**一份教学决策的公开账目**：在有限学时里哪些内容教、哪些不教；
每章花多少学时、为什么这么花；每条目标在哪几周被真正教会；评价在哪一周发生。
难点从来不是"讲什么"，而是**在给定学时内做取舍，并让取舍可被检验**。

## 什么时候用 / 什么时候不用

**用**：
- 新开课，需要一份能交学院备案的教学大纲 + 教学进度表
- 现有大纲学时与学分不匹配（超编或欠编），需要重排
- 调整教学进度：换教材版本、加删章节、假期或考试周压缩
- 学院要求更新大纲的"教学内容与学时分配""考核方式与权重"部分
- 课程被纳入毕业要求支撑，需要标出目标与章节的对应

**不用**：
- 一次课（45 分钟）内部的环节设计（用 `explicit-instruction-sequence-builder`）
- 单元级目标—证据—活动的倒推（用 `backwards-design-unit-planner`）
- 作业任务书本身（用 `project-brief-designer`）
- 教材出版社提供的章节目录誊抄，或纯行政文本（课程简介、师资安排）

## 输入

**必填**（缺任何一项就停下来问，或先出草稿并把假设标出来）：
1. 课程名称、代码、**学分**、**总学时**（含理论/实验/上机分列）
2. 学期周数与单周学时（**默认 16 周**，按学院实际；每学时 45 分钟）
3. 课程目标清单（编号，可观察动词）
4. 课程性质（必修 / 选修 / 专业核心 / 实践环节）与先修关系
5. 教材与参考书（版本、ISBN；**查不到写「待补充」，不许编**）

**选填**（用户没给就留空并列入"需人工核验清单"，**不许编**）：
6. 校历关键节点（假期占用周次、期末考试周位置）
7. 考核方式与权重（**若未定，本技能只预留位置并标「待考核方案确定」**）
8. 毕业要求指标点编号（**院系给定，没给就留空**）；课程思政的既定要求（学院是否指定融入点数量或章节）
9. 实验/实践条件（分组人数上限、场地与设备）与往届大纲（用于"改动说明"）

## 执行步骤

1. **先锁死硬约束，画出可用时间预算。**
   总学时来自学分（按学院换算比例，不自行假设）。减去期末复习周、考试占用、
   校庆与假期影响的周次，得出**可用于教学内容与练习的净学时**——
   所有取舍都发生在这个净学时之内，不是在名义总学时之内。
2. **做章节候选池，标注每个候选章服务哪条目标。**
   候选来自教材目录 + 课程目标反推（哪些内容是达成某条目标的必要条件）。
   每个候选章标注：服务哪条目标、预估学时、是否可与其他章合并。这一步先求全，不要急着砍。
3. **按优先级取舍，不要平均用力。** 排序依据是目标权重 × 该章的不可替代性。
   典型结果：主干章占学时一半以上，导论与历史沿革压到 2 学时以内，拓展内容降级为"课外阅读 / 自学"。
   **砍掉的是章，不是把每章摊薄。**
4. **排章节顺序。** 规则按优先级：**先修依赖**（不能先讲有限元再讲应力）→
   **概念—应用交替**（长讲授后安排一次应用或练习，避免连续 3 学时纯输入）→
   **高阶目标前置准备**（分析/评价类目标所需的工具先于它出现）→
   **收尾留白**（最后 2 周不排新内容，留给综合应用与项目展示）。
5. **分配学时类型与节次。**
   每个章节标注学时在**讲授 / 研讨 / 练习 / 实验 / 项目 / 考核**之间的配比。
   原则：高阶目标不能只靠讲授获得——凡目标动词为分析、评价、创造，
   对应章节的研讨与练习学时不得低于该章学时的 1/3。
   再落到节次：连堂 2 学时（90 分钟）用于讲授 + 连续推进，单学时（45 分钟）用于研讨、练习、答疑；
   连续讲授超过 90 分钟要安排 10–15 分钟活动切换。
6. **安排考核与反馈节点。**
   每次考核在进度表上写明施测周次、形式、对应目标、权重；
   反馈节点（作业讲评、小测反馈、方案评审）同样落进周次，
   并保证**反馈发生在被考核内容之后 1–2 周内**。
7. **做三重校验并把结果写进大纲。**
   **学时校验**：各章学时合计 = 净可用学时（差额显式写成"机动 / 答疑"章）；
   **目标覆盖校验**：每条课程目标至少落在一章上（目标—章节矩阵）；
   **权重校验**：各考核项权重合计 = 100%，未定的写「待考核方案确定」，**不得先写占位数字**。
8. **产出"本学期不讲什么"清单。**
   把被砍掉的候选章写进大纲说明部分，注明理由与后续课程衔接。
   这一条常被跳过，但它是教学取舍的公开记录，也是下一轮修订的起点。

## 概念脊柱与螺旋式重访

按章节线性排课是进度表的默认写法：第 1 章讲完，第 2 章讲完，期末统一复习一遍。
它的问题不是"漏讲了"，而是**核心观念始终停留在入门水平**——
学生见的是第 3 章的成熟形态，却没有机会经历"从案例到模型"的那段路。
螺旋式重访补的正是这一段：少数核心概念跨周反复回来，
每次回来都比上一次**结构上更高一层**。

### ① 第一原则：Revisit ≠ Review（重访不等于复习）

"第 1 课讲概念，第 3 课复习，第 6 课再复习"——这不是螺旋，这是同一份内容讲三遍。
判据只有一条：**这一次比上一次多了什么。**

每一次重访都要能回答：
- 这一次新增了哪个维度（复杂度 / 抽象度 / 关系密度 / 表征方式 / 迁移距离 / 边界与反例）？
- 新增的部分在结构上比上一次高在哪一层？

如果一次回来在任何维度上都没有更高，它就是重复，必须重写——
要么给它升阶，要么把它从"重访"降级为"复习"（并从概念脊柱里移除）。

### ② 概念脊柱（concept spine）

**不要先排课时清单。** 先回答一个问题："整个学期结束后，
学生真正应该建立哪几个能反复使用和迁移的核心观念？"

- 每个核心概念写成**一句可迁移的理解**，不是名词。
  - ❌ "能量守恒定律"（名词，只是章名）
  - ✅ "能量守恒意味着能量可以在形式之间转换而不消失"
- 一个学期通常选 **3–6 个**核心概念。多了，每课浅尝辄止，谁也升不上去。
- 每个概念同时声明**初始理解目标**与**最终理解目标**——这是该概念进阶的两个端点：
  前者是学期初要建立的结构，后者是学期末要达到的结构。

概念脊柱是**先于课表**的东西：先有脊柱，再把章节挂到脊柱上；
顺序反过来就会退化成"按章讲完再复习"。

### ③ 六个升阶维度

每一次重访，至少在其中一个维度上比上一次更高。

| 维度 | 初次接触 | 后续重访 |
|---|---|---|
| 复杂度 | 单一关系 | 多变量相互作用 |
| 抽象度 | 具体案例 | 一般模型 |
| 关系密度 | 孤立概念 | 与更多概念建立关系 |
| 表征方式 | 直观经验 | 图示、模型、符号 |
| 迁移距离 | 熟悉情境 | 陌生情境、跨领域 |
| 边界与反例 | 正例 | 反例、边界、局限 |

只写"再讲一遍"而没有落在这张表的某一格上，这次重访就不成立。

### ④ 七个升阶操作符（give a name + 何时用）

| 操作符 | 含义 | 何时用 |
|---|---|---|
| `ADD_COMPLEXITY` | 增加变量或相互作用 | 上一次的模型在多一个因素时就说不通 |
| `ADD_RELATION` | 与另一概念形成必要关系 | 概念要能解释另一个概念的现象 |
| `ABSTRACT` | 从案例上升到一般模型 | 学生已能处理多个同型案例 |
| `FORMALIZE` | 引入符号、模型或专业语言 | 学生已抓住结构，需要精确表达 |
| `CHANGE_REPRESENTATION` | 在操作、图像模型、符号表征之间重构 | 学生只会在一种表征下工作 |
| `INCREASE_TRANSFER_DISTANCE` | 进入更陌生或跨领域情境 | 学生一换情境就失灵 |
| `ADD_EXCEPTION` | 加入反例、边界、约束、局限 | 学生把规律当成无条件成立 |

规则：**一次重访通常选 1 个主操作符 + 少量辅助**；
一次叠满所有操作符只会堆难度，不产生结构性升阶。
每行课程行都要标出**本轮的主操作符**，其余记为辅助。

### ⑤ 规划一次重访的四件事

每一次重访都要写清四件事：

1. **保留什么**：哪些已有理解不必重教（直接带过去）。
2. **增加什么**：本轮新增的内容或条件（这是升阶的实体）。
3. **重组什么**：哪些孤立知识要组成机制或关系（没有重组就没有结构性变化）。
4. **迁移到哪里**：用哪个新情境检验概念结构（不检验，升阶只是宣称）。

### ⑥ 每课的螺旋契约（Spiral Contract）

每一行课程行都要带一份七字段的螺旋契约：

| 字段 | 含义 |
|---|---|
| `returning_concepts` | 哪些旧概念回来 |
| `new_concepts` | 哪些第一次出现 |
| `added_complexity` | 比之前复杂或抽象在哪 |
| `new_relation` | 新增了什么概念关系 |
| `representation_shift` | 是否更换表征 |
| `transfer_target` | 进入哪个新情境 |
| `future_hook` | 故意留下什么，供后续重访 |

`future_hook` 允许**有生产性的不完整**：早期先建一个可用但不完整的模型，后续再重组它。
**不要求每节课把概念讲完**——把概念讲完再回收是最常见的"讲死了"，
正确做法是留下一个明确的缺口，让学生后面带着它往前走。

### ⑦ 概念记忆

螺旋依赖跨周的共享记录：概念在第 3 周被重访时，
教师必须知道它第 1 周被教成什么样。因此每讲完一课，要记下该概念的：

- 初始理解目标
- 遭遇史（哪几周出现、每次加了什么）
- 表征史（用过哪些表征）
- 当前复杂度
- 已知关系（与哪些概念已建立关系）
- 已识别的迷思（学生带进来的错理解）
- 用过的例子
- 迁移距离（到过哪些情境）
- 掌握证据（凭什么认为这一层建立了）
- 下次重访目标

记录方式：一概念一卡，随进度表累积；它同时是下一轮重访设计与教学改进的输入。

### ⑧ 假螺旋检查（六项）

整套排完后，逐个概念逐项检查：

| 检查项 | 症状 |
|---|---|
| Repeated, not spiraled | 同一概念多次出现但复杂度没有提升 |
| Vocabulary inflation | 后面只增加术语，没有增加结构理解 |
| Linear curriculum | 每课都是新内容，旧概念不回来 |
| Review curriculum | 所谓回顾只发生在单元最后 |
| Context repetition | 概念回来时情境和表征完全相同 |
| Difficulty escalation without conceptual deepening | 后面只是题目更难，不是概念更深 |

命中任一项 → 回到对应课程行改写（补升阶维度、换情境或换表征），再重新验收。

## 中国高校语境要点

- **学时制**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。周学时按学院安排（常见 2–4 学时/周）。
  学时与学分的换算比例**按学院规定**，未提供时在时间预算表写"按 16 学时/学分暂估，待学院核定"。
- **周次**：默认 16 周/学期，扣除校历假期与考试周后得净教学周数（本例按 14 周），实际以学院校历为准。
- **考核与权重**：平时 / 大作业 / 期末各项权重合计**恰好 100%**；
  权重未定时**留空标「待考核方案确定」**，绝不填占位数字。
- **评价制度**：课内形成性评价（提问、随堂小测、discussion、同伴互评）在进度表中标注周次与是否计入总评；
  终结性考核标注施测周与对应目标。
- **毕业要求支撑**：指标点编号**由院系给定**；用户没给就在表 4 旁注明「待补充」，不自行编写编号。
  章节层面对毕业要求的支撑通过课程目标间接体现。
- **课程思政**：每章至少标注 1 个自然融入点（案例 / 问题导入 / 价值讨论），写明融入方式，不硬贴标签。
- **教材与实践环节**：ISBN 需真实且与章节对应，查不到写「待补充」；教材版本变更须同步修订进度表与"不讲清单"。
  实验/实践注明学时数、分组方式与考核占比，与表 2 的实验/上机列一致；
  若学院需要折算工作量，按学时 × 学院规定系数填写，不自行假设。
- **16 周学期的螺旋排布**：概念的首次出现之间要留出间隔，不要把同一概念的所有重访排在一起；
  重访要**跨周**（通常相隔数周），不要在同一天连讲；
  期末复习周与考试周**不安排新的重访**，只安排巩固与整合。
- **概念脊柱的重心选择**：一学期 3–6 个概念脊柱，**主干概念占学时一半以上**；
  其余章节作为"概念出现的情境与练习"存在，不单独占学时中心。
  若某一主干概念的累计学时明显低于另一主干概念，说明脊柱选择有问题，回查概念取舍。
- **课程思政在重访中逐次深化**：同一次重访不是重复贴标签，而是逐次推进层次——
  第一次重访在**事实层**（事实是什么、数据怎么说），
  第二次重访在**取舍层**（在冲突的诉求之间怎么权衡、代价由谁承担），
  第三次重访在**责任层**（应当做什么、谁为后果负责）。
  每一层配一个具体案例或问题，不写口号。
- **概念脊柱与毕业要求支撑**：脊柱的最终理解目标应与毕业要求指标点呼应，
  但**指标点编号由院系给定，没给就留空**（在概念脊柱表旁注明「待补充」），不自行编号。

## 易错点

- ❌ 只列章节不分配学时 → ✅ 每一章都有学时，合计行做校验并等于净可用学时
- ❌ 按名义总学时排课 → ✅ 先扣假期与考试周，在**净可用学时**内分配
- ❌ 每章学时均摊 → ✅ 按目标权重与不可替代性取舍，砍章而不是摊薄
- ❌ 连续 3 学时纯讲授 → ✅ 长讲授后安排活动切换；高阶目标章节的研讨 + 练习 ≥ 该章学时 1/3
- ❌ 考核没有周次位置 → ✅ 每项考核与每个反馈节点都落进进度表
- ❌ 反馈排在考核后一个月 → ✅ 反馈在考核后 1–2 周内
- ❌ 权重未定时先填占位数字 → ✅ 标「待考核方案确定」，合计行写"待定"
- ❌ 高阶目标没有任何章节承载 → ✅ 目标—章节矩阵发现缺口后，要么调目标要么调章节
- ❌ 不写不讲什么 → ✅ 产出取舍记录，说明理由与后续衔接
- ❌ 编造教材 ISBN、校历、毕业要求编号 → ✅ 全部留空并进待补充清单
- ❌ 按章节线性排课、期末统一复习一遍 → ✅ 先定概念脊柱，再把章节挂上去，重访跨周分布
- ❌ 把"复习"当"重访"（讲过的内容再讲一遍） → ✅ 每次重访必须在六个升阶维度之一上更高
- ❌ 核心概念写成名词清单（"能量守恒定律"） → ✅ 写成一句可迁移的理解
- ❌ 一个学期塞 7 个以上核心概念 → ✅ 3–6 个，多了每课浅尝辄止
- ❌ 一次重访把七个操作符全叠上 → ✅ 一次 1 个主操作符 + 少量辅助
- ❌ 螺旋契约只记符号（记了 `ABSTRACT`）不写新增结构 → ✅ 必须写出本次新增的结构与保留/增加/重组/迁移
- ❌ 不做假螺旋检查 → ✅ 排完后逐概念过六项检查，命中即回改对应课程行
- ❌ 在期末复习周与考试周堆新的重访 → ✅ 期末只安排巩固与整合，不引入新升阶

## 自检清单

- [ ] 总学时来源明确（学分 × 学院换算比例），未自行假定
- [ ] 时间预算表列出了假期与考试周占用，净可用学时已算出
- [ ] 每个章节都有学时，且合计 = 净可用学时
- [ ] 学时类型配比已分，高阶目标章节研讨 + 练习 ≥ 该章学时 1/3
- [ ] 章节顺序满足先修依赖，且有"概念—应用交替"；最后 2 周未排新内容
- [ ] 每条课程目标至少落在一章上，缺口已处理
- [ ] 每项考核有施测周次、形式、对应目标、权重，反馈有安排且在 1–2 周内
- [ ] 权重合计 = 100%，或未定时明确标「待考核方案确定」且未填占位数字
- [ ] 每章至少 1 个课程思政自然融入点，并写明融入方式
- [ ] 教材章节对应真实，ISBN 查不到已标「待补充」；实验学时、分组方式、占比与课程表一致
- [ ] 已产出"本学期不讲什么"及其理由；校历、指标点编号、权重等缺失项已进待补充清单，无编造
- [ ] 概念脊柱有 3–6 个核心概念，每个都写成一句可迁移的理解而不是名词
- [ ] 每个概念都声明了初始理解目标与最终理解目标
- [ ] 每次重访都标明了主升阶操作符
- [ ] 每次重访在六个升阶维度中至少有一项高于上一次
- [ ] 每个课程行都有螺旋契约七字段（含 `future_hook`）
- [ ] 概念记忆已记录（遭遇史、表征史、迷思、掌握证据、下次重访目标）
- [ ] 六项假螺旋检查已逐概念做过，命中项已回改对应课程行
- [ ] 期末复习周与考试周未安排新的重访
