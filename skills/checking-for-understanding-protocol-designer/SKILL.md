# 理解检测协议设计

## 这个技能解决什么

课堂上最贵的误会，是教师以为讲懂了、学生其实没懂：

- 讲完两页推导，问"这里为什么可以交换求和顺序"，全班沉默，教师只好自己接着讲；
- 学生点头的频率很高，但随堂小测错了一半；
- 一道题错了十几次，下一题换了数字又错——问题不在计算，在概念；
- 想重新讲，又怕节奏崩掉，于是含糊地说"这个大家注意一下"就翻页。

理解检测协议把"检查"从课堂的随机动作，变成**有预设的流程**：
在哪个环节、用哪种技术、题干长什么样、给多少思考时间、答对多少算过、答错时下一步做什么。
它的产出不是"提问清单"，而是一套带判据与处置分支的可执行协议。

## 什么时候用 / 什么时候不用

**用**：
- 备课时为每个教学环节预置检查点，尤其是重点段与易错段
- 大班课堂无法逐个纠错，需要低成本的全班状态探测
- 上一轮教学数据显示"某个概念大面积不会"，需要重设检测点
- 设计线上课程或翻转课堂的互动节点（课前自检、课中节点检查、课后回看检测）

**不用**：
- 专门的终结性考试命题与评分标准设计
- 学生个人学习策略与复习安排
- 需要长篇论文写作、完整实验报告的研究型教学环节

## 输入

**必填**：
1. 本单元/本节课的教学环节序列（含各环节时长）
2. 目标清单（每条目标对应的可观察行为）
3. 班级规模与座位形态（决定用手指、白板还是答题器）
4. 可用的检测时间预算（本课能拿出多少分钟做检查）

**选填**：
5. 学生先备水平与历史高频错误（决定错误选项怎么设计）
6. 课程思政要求
7. 毕业要求指标点编号（**没给就留空**，不要自拟）
8. 教材与参考书版本（ISBN 须真实，查不到写「待补充」）

## 执行步骤

1. **把每个目标改写成"证据句"。**
   证据句 = 一句"学生做出什么，就说明这个目标达成了"。
   例：目标"能解释相变潜热的物理来源" → 证据句"学生能用日常语言说明为什么水在沸腾时温度不再升高"。
   没有证据句的目标在课堂上无法检测，应退回目标设计环节改写。

2. **为每个环节选检测技术。**
   选型规则（按你想知道什么来定，而不是按什么方便）：
   - 想知道**全班状态**（几十人一起判断）→ 集体应答技术：手指表决、白板同时举、答题器、随机点名+全班比手势；
   - 想知道**某个人的具体误解** → 单点诊断技术：铰链题（3–4 个选项，含两个真实误解作干扰项）、口头追问；
   - 想知道**能不能自己走一遍** → 产出式技术：当堂写一步、口头复述、桌面演算；
   - 想知道**是否知道自己懂了** → 元认知技术：一句总结、离堂卡、信心评分。
   一次检测只问一个问题，问完立刻判，不要连珠炮。

3. **写题干：正确答案 + 两个真实误解作干扰项。**
   干扰项不能是随手编的荒谬答案，必须对应学生真会犯的错（如"方向搞反""忘记量纲""把必要条件当充分条件"）。
   铰链题的标准形式：题干一句话 + 3–4 个选项 + "选一个，并说出你排除另外两个的理由"。
   说出排除理由这一步是关键：它把"碰巧选中"和"真懂"区分开。

4. **定反应时间与通过阈值。**
   反应时间先给后问：给 3–5 秒沉默、留 8–10 秒等待回答、要求 1–2 句理由（过长会暴露答案提示）。
   通过阈值按班级状态定：答对比例 ≥ 80% 判定为全班通过，50%–80% 判定为部分通过并对少数派追问，
   < 50% 判定为未通过，必须停下来重教。阈值要写进协议，不靠临场感觉。

5. **写不通过时的处置动作（这一步最容易漏）。**
   处置不能只有"再讲一遍"。可选动作及其适用条件：
   - 换一个更小的问题重新问（概念错但整体框架对）；
   - 换例子重讲同一概念（方法对但例子的特殊性质误导了学生）；
   - 回到先备知识补一个前置环节（缺的是基础而不是本节内容）；
   - 改为全班动手做一次（讲不明白，讲了就做，做了才会暴露真正的卡点）。
   每条处置都要写"什么现象触发它"。

6. **预算检测点数量与时长。**
   45 分钟课次通常安排 4–6 个检测点，检测总时长控制在 8–12 分钟；
   90 分钟连堂可增加一次课中段检测点，但检测点之间要有间隔，
   连续两个检测点之间至少留一个完整的教学环节，否则学生进入"答题模式"而非"学习模式"。

7. **设计记录与跟进。**
   协议必须配一个能在讲台上用的记录表（表 5）：谁答了、答的是什么、属于哪类错误。
   没有记录，检测就只是走过场；有了记录，下一次讲评课才有依据。

## 中国高校语境要点

- **学时与节奏**：1 学时 = 45 分钟；2 学时连堂 90 分钟，中间休息不超过 15 分钟。
  检测点安排在休息前后的位置要当心，连堂后半段学生的应答质量明显下降，重的检测放在前半段。
- **大班**：100 人以上优先用集体应答（同步举手、白板、答题器），把"谁错了"推迟到课后，
  但**"全班对不对"必须在课内拿到**，否则协议退化成表演。
- **形成性 vs 终结性**：课中检测属形成性评价，通常不单独计分；若计入平时成绩，
  需写清该项占比，且平时/期末各项百分比**加总恰好 100%**。
- **毕业要求**：检测点对应的目标可再向毕业要求指标点追溯，但指标点编号由院系给定，
  **没给就留空**，不要自拟。
- **课程思政**：若检测题涉及价值判断（如技术方案的伦理后果），
  判据要写成"论据与本学科事实一致、推理可复核"，而不是"立场正确"——
  后者把思政变成政治打分，会在教学与评估上同时失效。
- **教材**：题干情境若直接取自教材，章节与 ISBN 须真实，查不到写「待补充」。

## 易错点

- ❌ 检测题只给正确项、干扰项随意编 → ✅ 干扰项对应学生真实犯过的错
- ❌ 问完不判、立刻接着讲 → ✅ 先报通过率，再按阈值决定往下走还是停下来重教
- ❌ 答错处理只有"我再讲一遍" → ✅ 准备 3–4 条处置动作，每条写触发条件
- ❌ 反应时间太短，学生还没看完题就举手 → ✅ 沉默 3–5 秒 + 等待 8–10 秒 + 要求说理由
- ❌ 把"答对"当"懂了" → ✅ 要求说出排除理由，或问一个反例
- ❌ 检测点密到每 5 分钟一次 → ✅ 相邻检测点之间留完整教学环节，学生要处于思考而非答题状态
- ❌ 检测只做不留痕 → ✅ 配记录表，答错情况要能进入下一次讲评
- ❌ 编造指标点编号或教材 ISBN → ✅ 真实提供或留空进核验清单

## 自检清单

- [ ] 每个目标都有对应的证据句与至少一个检测点
- [ ] 每个检测点写明了技术、题干、正确答案、阈值、反应时间、答错动作
- [ ] 干扰项对应真实误解，不是随手编的
- [ ] 每个检测点都有"答错怎么办"的具体动作和触发条件
- [ ] 检测点数量与总时长在课时预算内（45 分钟课 4–6 个、8–12 分钟）
- [ ] 相邻检测点之间留有完整教学环节
- [ ] 记录表能在讲台上直接使用
- [ ] 平时/期末各项百分比合计 = 100%（若检测计入平时成绩）
- [ ] 指标点编号、ISBN 等事实项：真实或已列入待补充，无编造
