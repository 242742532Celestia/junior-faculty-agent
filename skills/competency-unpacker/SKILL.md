# 能力目标解构

## 这个技能解决什么

大纲上写着"培养学生的复杂问题解决能力""掌握系统分析方法""具备工程实践素养"。
这几句话不能教，也不能考——没法安排课时，没法写题目，没法判分。
真到了期末，教师只能退回到考定义、考步骤、考计算，
于是"复杂问题解决"这一栏永远是空的，而"考点"永远很热闹。

更隐蔽的损失发生在拆分环节：把大目标拆成三五条"小目标"，看起来具体了，
其实只是把同一堆动词换了个说法，学生仍然不知道自己每一条要做到什么程度、拿什么证明。

解构要解决的不是"缩短目标"，而是**找到能力内部真正可以被单独教、单独练、单独判的成分**。
一个合格拆分的检验只有一条：把子目标单独发给一个学生，
他既知道要做什么，也知道做到什么程度算做到了。

## 什么时候用 / 什么时候不用

**用**：
- 课程目标里出现"综合、迁移、解决复杂问题、形成素养"等复合表述，需要落地
- 一个学期容量装不下，或一个课时里塞了太多子目标
- 要为量规确定维度、要在题库里挑能覆盖子目标的题
- 教学效果差，且怀疑是"目标太大导致教什么都浅"

**不用**：
- 目标已经是"能解释 X 的定义""能计算 Y"这种原子目标（直接用即可）
- 只是调整目标措辞或润色教学大纲文本
- 课程整体目标体系的重新论证（先做 `scope-and-sequence-designer`）
- 只想排教学顺序（依赖关系确定后用 `explicit-instruction-sequence-builder`）

## 输入

**必填**（缺任一项先出草稿并把假设标出来）：
1. 待解构的原始目标原文（1–5 条为宜，超过 5 条先分批）
2. 该目标所在课程/单元的教学条件：总学时、可用课次
3. 学生起点水平（大一新生 / 已修前导课 / 跨专业零基础）
4. 该目标最终用什么形式考核（期末笔试 / 课程大作业 / 实验 / 答辩）

**选填**（没有就留空，写进"需人工核验清单"，**不许编**）：
5. 已有教材章节顺序、跨课程先修关系（哪些成分在别的课里已经教过）
6. 课程各项考核权重构成（用于合计 100% 校验）
7. 毕业要求指标点编号（**用户没给就留空**）
8. 教材与参考书版本、对应章节（ISBN 需真实，查不到写"待补充"）

## 执行步骤

1. **定位复合动词。**
   目标里出现"分析、设计、评价、综合、解决、建构、迁移"这类动词时，
   它几乎一定盖着多个成分——因为这些动词本身就包含了一串子动作。
   "设计一个实验方案"里藏着：选定研究问题、确定变量、操作化、选方法、排除替代解释。
   这一步只做标记，不做拆分。

2. **把复合动词展开成成分，并给成分分类。**
   成分按 Anderson & Krathwohl 的知识维度分四类：
   **陈述性**（是什么）、**程序性**（怎么做）、**心智模型**（为何这样）、**判断性**（何时用哪个）。
   只列成分，暂不写子目标。

3. **对每个成分做"可教可评三问"。**
   能在一次 45 分钟课时内教完吗？能被一个学生作品或一次作答产出吗？能被一条评分判据判定吗？
   三问全"是"→ 升格为子目标；任一为"否"→ 继续往下拆，或标记为"移出本次目标"
   （属于更高阶或本课不承担的部分），**不要留在原地假装能教**。

4. **把子目标写成原子句。**
   公式：**可观察动词 + 对象 + 情境 + 判据**。
   例："能在给定的两种测量方案中，依据精度与成本约束说明选择理由，并指出被放弃方案的失效条件。"
   句中不出现"理解、掌握、熟悉、了解、认识"——这些词无法证伪，出现即说明拆分没做完。

5. **标出依赖与支点。**
   子目标之间不是并列的。画出"必须先掌握才能学"的关系，并标出**支点（hinge）**：
   不掌握它，后面一整片都会塌。支点决定了课时必须优先给谁。

6. **与课时做硬匹配。**
   一个 45 分钟课时能承载的高阶子目标（设计、评价、创造类）通常不超过 1–2 个；
   陈述性成分可以几个一起讲，但要有形成性检查点确认到了。
   容量不够时**先砍子目标**（并说明被砍的是哪条、依据什么），不要把课时摊薄成"每条讲 8 分钟"。

7. **给每条子目标配证据与判据。**
   证据形式：书面作业、计算结果、设计图纸、实验报告、编程实现、案例分析、课堂演示、口头答辩。
   判据要写成可以打勾的句子："能在不查资料的情况下说出两种方法各自的适用条件"。

8. **做拆分质量自检。**
   逐条查：原子性（一个动词一个对象）、可观察性、可评分性、不重复、
   覆盖原目标（有没有成分漏在原目标之外）、无空话动词。
   重复检测：把两条子目标并排读，若能同时被同一个作品满足且判据相同，就合并。

9. **收口：列出不确定项。**
   凡是推断（"学生大概没有前导知识"）标「假设」；缺失的事实信息（先修关系、指标点、ISBN、权重）标「待补充」。

## 中国高校语境要点

- **学时与容量**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟，中间不宜超过 15 分钟连续讲授。
  拆分子目标的硬上限来自这里：一个 45 分钟课时最多承载 1–2 个高阶子目标。
  学期按 16 周计算，可用课次先算清楚再拆。
- **评价制度**：每条高阶子目标至少配 1 个**形成性检查点**（随堂小测、discussion 中的追问、
  一次草稿提交），否则学期末才发现没学会。终结性考核（期末笔试/开卷/机考）只承担留证功能。
- **权重合计**：拆出的子目标若带分值或课时占比，加总必须**恰好 100%**；
  课程整体平时成绩与期末成绩各项百分比同样加总到 100%。
- **毕业要求支撑**：子目标应逐条对应毕业要求指标点，编号由院系给定。
  **用户没给就留空**，在表 2 旁注明"待补充"，不要自造"毕业要求 2.1"。
- **课程思政**：思政类目标同样要拆到可观察行为，否则它只会变成"写在目标里、
  考不到、也评不出"的空话。要么拆成可评行为，要么明确标注"非考核目标，仅作课堂融入点"，
  并在表中分开列，不要混进考核子目标。
- **教材与参考书**：子目标与教材章节要能对应（ISBN 需真实并与该章匹配），
  查不到写「待补充」，不许编造 ISBN 或页码。
- **实践/实验环节**：涉及操作的成分要注明实验学时数、分组方式与考核占比；
  把"会做实验"与"会分析实验数据"拆成两条子目标，不要合成一条。
- **教学工作量折算**：若院系需要，按子目标课时折算工作量（说明依据，不自行套系数）。

## 易错点

- ❌ 只把大目标"缩短"成短句 → ✅ 展开复合动词内部的成分，再逐个过三问
- ❌ 子目标里写"理解/掌握/熟悉"、成分拆出来却没判断能不能教 → ✅ 换成可观察动词 + 对象 + 情境 + 判据；三问不全过就继续拆或移出
- ❌ 子目标之间互相重复（都能被同一份作业满足） → ✅ 并排读，重复就合并
- ❌ 拆完不配判据 → ✅ 每条子目标配一条可打勾的判据
- ❌ 拆得很细但课时装不下 → ✅ 砍子目标并写明砍的是哪条、依据什么
- ❌ 依赖关系留到上课临时定 → ✅ 拆完立刻标支点，支点优先给课时
- ❌ 思政目标原样留着不算数 → ✅ 拆成可观察行为，或单列为非考核融入点
- ❌ 编造指标点编号、ISBN、学时折算系数 → ✅ 查不到写「待补充」并列入核验清单

## 自检清单

- [ ] 每条原始目标里的复合动词都已定位并展开
- [ ] 每个成分都做了可教可评三问，去向明确（拆分 / 保留 / 移出）
- [ ] 每条子目标都是"动词 + 对象 + 情境 + 判据"的可判定句
- [ ] 子目标中没有"理解、掌握、熟悉、了解、认识"，也没有两条子目标可被同一作品与同一判据同时满足
- [ ] 每条子目标至少配了一个证据形式
- [ ] 依赖关系与支点已标出，子目标数与可用课时匹配，砍掉的已写明依据
- [ ] 权重与课时占比加总 = 100%
- [ ] 原目标成分覆盖核对表无遗漏
- [ ] 思政目标已拆为可观察行为，或已明确单列为非考核融入点
- [ ] 指标点编号、ISBN 等事实项：真实或已列入待补充，无编造

## 交叉技能

- 目标拆好后排成进阶路径 → `learning-progression-builder`；目标—证据—活动三段对齐 → `backwards-design-unit-planner`
- 量规维度从子目标来 → `criterion-referenced-rubric-generator`、`single-point-rubric-designer`
- 考核是否真的测到子目标 → `assessment-validity-checker`
- 教学序列与课时安排 → `explicit-instruction-sequence-builder`
- 练习题与难度梯度 → `practice-problem-sequence-designer`
- 拆出的成分是否超出工作记忆负荷 → `cognitive-load-analyser`
- 目标措辞与表述规范 → `learning-target-authoring-guide`
- 课程整体目标体系 → `scope-and-sequence-designer`；学段与课时制度换算 → `he-context-adapter`
