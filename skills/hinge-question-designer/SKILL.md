# 关键转折问题设计器

## 这个技能解决什么

讨论进行到第十分钟，学生还在重复第一轮说过的话；教师抛出的"好问题"既没人反对，也没人补充，讨论像一条平线。

学生说了句"我觉得这样更好"，理由是"看起来更先进"；教师追问，得到的还是立场而不是依据。

两个小组的方案明明冲突（一个追求成本低，一个追求精度高），全班却一直用"各有优劣"把矛盾抹平，直到最后也没有结论。

教师的问题里其实藏着答案（"这个设计显然更合理，对吧？"），学生说是，讨论就结束了。

问题本身问得漂亮（"这背后反映了什么？"），但课堂上没有任何材料能支撑回答，学生只能空谈。

转折问题不是"好问题"，而是**会改变讨论走向的问题**：它的答案不同，后面的动作就不同。这个技能把"凭感觉想问题"换成一个可检查、可复用的设计流程——先采分歧，再按五要素检验，最后排进分钟级时间轴。

## 什么时候用

**用**：

- 讨论已经热闹但没有进展，教师需要一个能把话题推进到下一个层次的问题。
- 学生在表达立场却不给依据，需要一个把"我认为"逼成"因为"的问题。
- 两组方案或两种做法出现冲突，需要一个让冲突显形的问题。
- 备课时要在某个节点插入一个"检验全班理解到哪一步"的关键问题。
- 讨论时间有限，需要决定"只问这一个问题"时该问什么。

**不用**：

- 只是要唤醒沉默的学生——那是对谈式提问，不是转折问题。
- 需要事实数据或定义（"铰链点的应力是多少"）——那是信息查找。
- 学生尚不具备讨论该问题所需的前置知识，先补概念。
- 需要一次完整的、逐轮的追问序列——用逐轮脚本那类方法更合适，本技能只负责"那一个改变走向的问题"。

## 输入

**必填**：

1. 讨论主题或正在争论的那件事（一句话）。缺省从教学目标中的核心概念反推，并标注为假设。
2. 讨论已经进行到哪一步（开场 / 中段 / 尾声），以及已经出现的分歧点。缺省按"中段"处理。
3. 可用讨论时间（分钟）。缺省按 12 分钟处理。
4. 课堂上学生可见的材料（板书、投影、数据、实物、教材页）。缺省按"有板书"处理。

**可选**：

5. 学生先备水平。缺省按"已理解基本术语"处理。
6. 是否允许学生查资料。缺省按"当堂不可查"处理，因此问题必须在现有材料上可答。
7. 讨论是否进入评分。缺省按"进入形成性评价"处理。
8. 课程思政融入要求。缺省按"在价值取舍类转折问题里自然融入"处理。

## 执行步骤

1. **写下本节课的"待检验命题"。** 一句话，必须是可判断真假的教学命题（例如"在给定约束下，方案甲的整体代价更低"）。转折问题要检验的就是它。
2. **采集分歧句。** 从学生的原话里挑出 2–3 句"有判断、无依据"的句子（如"这个方案显然更先进"）。分歧句比教师想象的点子更可靠，因为学生真的在乎它。
3. **生成 4–6 个候选问题。** 从模板 C 的三类句式各取候选，每个候选都要能用黑板上的东西当场回答。
4. **跑五要素检验。** 每个候选按模板 B 逐项打 0/1 分，低于 4 分的淘汰。检验时特别问一句："如果学生的答案是 A，下一步我们会做什么？如果是 B 呢？"答不上来的问题不是转折问题。
5. **选定 1 个转折问题（最多 2 个）。** 转折问题越多，讨论越散。第一个用于中段推进，第二个用于尾声收束。
6. **写追问三层。** 用模板 E 给每个转折问题配起始问、追问、收敛，并写明每一层的分钟数与退出条件。
7. **排进时间轴。** 用模板 D 把转折问题插入具体分钟，写清插入前的现场信号（教师看到什么就该问）。
8. **预写失效预案。** 若学生答不出或答成口号，按模板 F 降级（换更小的台阶、给出一个可选答案、把问题改成让学生先举例）。

## 输出模板

### 模板 A｜分歧句采集卡

| 编号 | 学生原话（逐字） | 它隐含的判断 | 它缺什么 | 是否指向本节课的待检验命题 |
|---|---|---|---|---|
| S1 | "……" | | 依据 / 条件 / 比较对象 | 是 / 否 |

要求：至少 2 张卡，且至少 1 张是"与当前主流说法相反"的异议句（异议句是最好的转折入口）。

### 模板 B｜转折问题五要素检验表（每候选问题一行）

| 要素 | 判定标准 | 0 分 | 1 分 |
|---|---|---|---|
| 1 指向分歧 | 不同学生会给出不同答案 | 全班会答同一个 | 存在两种以上合理答案 |
| 2 当场可答 | 用课堂现有材料即可回答 | 需要课后查资料 | 板书/投影/数据里就有 |
| 3 改变走向 | 答案不同则后续动作不同 | 不管答什么都继续原计划 | 答案 A 走向甲，答案 B 走向乙 |
| 4 要求依据 | 必须给出理由而非表态 | 只要说选择即可 | 必须说"因为……" |
| 5 不含答案 | 问句本身不暗示倾向 | 问句里已有正确答案 | "显然""当然""是不是……" |

判定：总分 ≥4 才可作为转折问题；3 分以下降级为普通追问或删除。

### 模板 C｜三类转折问题句式库（句式骨架可直接套用）

| 类型 | 句式骨架 | 作用 | 示例（自拟，示意句式） |
|---|---|---|---|
| 证据追问型 | "你说 X 更合适——具体是哪个量上的差别带来的？如果把它换成 Y，这个结论还成立吗？" | 把立场换成依据 | "你说这个结构更轻——是重量指标还是成本指标上的差别？如果换成同样重量但更贵的材料，这个判断还成立吗？" |
| 边界反例型 | "有没有一种情况，这个结论会反过来？如果有，是什么情况？" | 逼出条件与适用范围 | "什么工况下这条路线的劣势会超过它的优势？那个临界点由什么决定？" |
| 冲突澄清型 | "甲组和乙组的结论正好相反——如果两边都没错，那它们各自默认了什么前提？" | 让被抹平的冲突显形 | "两个方案都说自己更优，那一个默认了成本不敏感，另一个默认了风险可忽略——如果两个假设都不成立，会怎样？" |

### 模板 D｜转折问题插入位置表（分钟级）

| 时段 | 现场信号（教师看到什么） | 教师动作 | 转折问题 | 预期走向 |
|---|---|---|---|---|
| 0–3 分钟 | 学生已各自说了看法，气氛松动 | 定锚：把讨论对象写成一句话 | | |
| 第 6 分钟 | 出现两句互相冲突的判断 | 插入转折问题 T1 | T1： | 答甲 → 转向证据比对；答乙 → 转向前提澄清 |
| 第 9 分钟 | 讨论仍在重复已有观点 | 插入追问（T1 的第 2 层） | | |
| 第 11–12 分钟 | 气氛松散、时间到 | 收束：产出结论 + 一条保留意见 | T2（可选） | |

### 模板 E｜追问三层与时间盒（每个转折问题填满）

| 层级 | 目的 | 句式 | 时长 | 退出条件（可观察） |
|---|---|---|---|---|
| 第 1 层 起始问 | 把分歧摆到台面上 | "关于 X，A 的理由是……，B 的理由是……，你们先判断哪个更站得住？" | 60 秒 | 已有学生选定一边并说理由 |
| 第 2 层 追问 | 逼出判据 | "你选 A 的理由里，最关键的一条是什么？换成 B 会带来什么后果？" | 90–120 秒 | 学生说出可检验的理由（含量、比例、条件之一） |
| 第 3 层 收敛 | 定条件与边界 | "那么这个结论成立的边界是什么？超出哪条线就得改判？" | 60–90 秒 | 学生给出一条边界或反例 |

规则：第 2 层未产出可检验理由，不得进入第 3 层；第 3 层结束后必须收束，不得开启第四层。

### 模板 F｜失效预案与降级动作

| 失效情形 | 现场表现 | 降级动作 | 用时 |
|---|---|---|---|
| 全班答不出 | 沉默、互相看 | 改为二选一："更接近 A 还是 B？先站队再说明理由" | 1 分钟 |
| 答成口号 | "就是感觉更好" | 换成量化要求："给一个数字——差多少？" | 1 分钟 |
| 问题太大 | 学生说"这得看情况" | 缩小到具体一个实例："就拿你手上这个例子说" | 1 分钟 |
| 无人反对 | 全班一边倒 | 追问条件："有没有一种情况会反过来？" | 1 分钟 |
| 时间不够 | 已到收束点 | 直接用模板 D 的收束动作，宣布结论与保留意见 | 0 |

### 模板 G｜转折是否生效（教师课后 2 分钟回填）

| 检查项 | 判定 | 记录 |
|---|---|---|
| 转折问题是否被当场回答 | 是 / 部分 / 否 | |
| 回答是否包含依据（而非立场） | 是 / 否 | |
| 回答是否改变了后续讨论内容 | 是 / 否 | |
| 是否产生至少一条可写入结论清单的表述 | 是 / 否 | |
| 下一轮改进 | | |

## 中国高校语境要点

- **学时制**：转折问题适合放在 45 分钟课的中段（对话段第 5–8 分钟）或 45×2 课的第二段开头。建议一节课最多 2 个转折问题，超过后课堂会失去节奏。
- **评价制度**：转折问题的回答质量可作为形成性评价素材（课堂讨论 10% + 随堂小测中一道迁移题 5%），终结性考核权重相应下调，合计必须 100%，以课程大纲为准。
- **班级规模**：60 人以上的大班，转折问题需先安排 30 秒的同桌互答，再请 2–3 位学生代表发言，最后由教师复述全班共识，避免只有前排发言。
- **毕业要求支撑**：转折问题支撑"综合分析""判断与决策""沟通表达"类毕业要求指标点的达成，引用本校指标点原文表述。
- **课程思政**：在"边界反例型"转折问题里自然融入工程伦理与社会责任（例如"当安全与成本冲突时，边界由谁定"），把价值判断放进具体决策情境，不做抽象说教。
- **课堂纪律与设备**：使用雨课堂、学习通等即时问答工具收集答案时，注意结果多为"跟随多数"，只用于统计倾向，不能替代口头理由。
- **教材与参考书**：若引用课堂提问案例集，须给出可核验书目信息（有 ISBN 写 ISBN，无则写"待补充"并注明核验渠道），不得编造 ISBN。

## 易错点

- ❌ 把"好问题"当成"转折问题" → ✅ 检验第 3 要素：答案不同，后续动作是否真的不同；不同就换问题。
- ❌ 问题里藏着答案 → ✅ 用模板 B 第 5 要素把关，出现"显然""当然"就重写。
- ❌ 问题太大、超出课堂材料 → ✅ 检验第 2 要素，当堂不能答的降级为普通追问。
- ❌ 问题一次问三层 → ✅ 一次一问、一次一阶，层与层之间必须等学生说出可检验的理由。
- ❌ 只挑最好听的一个候选 → ✅ 先写 4–6 个候选再打分，避免第一反应定胜负。
- ❌ 学生给出正确答案就收束 → ✅ 正确答案只能证明结论，要再问边界（第 3 层）。
- ❌ 全班一边倒就认定"讲清楚了" → ✅ 一致往往来自无人被追问，用反例试一次再收。
- ❌ 把转折问题用成辩论题 → ✅ 转折问题的落点是判据与边界，不是输赢；教师不裁定谁赢，只把判据逼出来。

## 自检清单

- [ ] 写出了本节课的待检验命题（可判断真假）
- [ ] 采集了 ≥2 张分歧句卡，其中 ≥1 张是异议句
- [ ] 生成并检验了 4–6 个候选问题
- [ ] 每个入选问题五要素得分 ≥4
- [ ] 入选问题不超过 2 个
- [ ] 每个入选问题都填满了起始问、追问、收敛三层与退出条件
- [ ] 第 2 层未达标时不会跳到第 3 层
- [ ] 已把转折问题排进分钟级时间轴，并写明插入前的现场信号
- [ ] 已预写至少三种失效情形的降级动作
- [ ] 问题不含答案倾向（无"显然""当然""是不是"）
- [ ] 大班已安排同桌互答环节
- [ ] 课堂讨论权重与期末权重合计 100%，与课程大纲一致
- [ ] 已安排课后填模板 G

## 交叉技能

→ `dialogic-teaching-move-generator`（把转折问题挂到施压与收束动作上）
→ `discussion-protocol-selector`（按目标与人数选协议，转折问题在协议内插入）
→ `socratic-questioning-sequence-generator`（把转折问题展开成逐轮追问脚本）
→ `checking-for-understanding-protocol-designer`（收束时用可判定问题替代开放问题）
→ `discipline-specific-critical-thinking-task-designer`（把转折问题落到该学科的思维操作上）
→ `cognitive-load-analyser`（检查转折问题是否超出学生可承载的信息量）
