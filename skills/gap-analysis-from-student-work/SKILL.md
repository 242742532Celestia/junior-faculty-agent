# 基于学生作品的学情差距分析

## 这个技能解决什么

期末成绩出来，一片不及格。教师开会讨论，原因通常是"学生不努力""基础太差""这届不行"，
三种说法都没有指向任何可以改的东西。补救方案也于是变成加讲一遍、加发一套题、
再放一遍视频——下一届重演。

问题出在**证据层级**上。分数告诉你"结果低"，没告诉你"在哪一步塌的"。
而"在哪一步塌的"恰恰是可干预的：一部分错误来自概念理解错误（要重讲），
一部分来自步骤不会（要示范），一部分来自策略缺失（要练习题梯度），
还有一部分其实来自题目表述有歧义（要改题，不是改学生）。

更麻烦的是归因习惯：看到错误就断定学生能力不行。同一份错误背后往往有两种以上解释
（概念没懂 / 表达没写清 / 时间不够），区分它们需要额外证据。
没有额外证据就下结论，就会把教学问题误诊成学生问题，然后加倍投入讲同样的内容。

差距分析要做的是三件事：**把差距定位到具体步骤**、**把错误分到性质**、
**把每个判断写成可被下一次数据推翻的假设**。

## 什么时候用 / 什么时候不用

**用**：
- 某次前测、单元作业或实验报告整体表现低于预期，需要定位原因
- 想知道"学生到底卡在哪个子目标上"，而不只是"平均分多少"
- 改了一轮教学但效果不明，需要判断是干预不对还是诊断不对
- 要为分层任务（`differentiation-adapter`）提供分组依据

**不用**：
- 数据只是分数分布、没有学生作品（无法定位步骤，先补证据）
- 目标是判分或排等级名次（那是阅卷与排名）
- 学生作品互相抄的（证据无效，先解决诚信问题）
- 需要的是设计教学活动（那是 `explicit-instruction-sequence-builder`）

## 输入

**必填**（缺任一项先出草稿并把假设标出来）：
1. 学生作品样本：题目/任务要求 + 学生作答（照片、扫描件、文本或平台导出）
2. 对应的课程目标或子目标清单
3. 样本描述：人数、班级、是否分层抽样、批改标准是否统一
4. 诊断时间点（用于对齐教学进度：这些错误是在哪一周的课之后产生的）

**选填**（没有就留空，写进"需人工核验清单"，**不许编**）：
5. 同期其他证据（随堂小测、课堂观察记录、答疑高频问题）
6. 教材版本与对应章节（ISBN 需真实，查不到写"待补充"）、课程各项考核权重构成
7. 毕业要求指标点编号（**用户没给就留空**）、学院学业预警与学习支持的规定

## 执行步骤

1. **先写"应然"。** 对每条子目标写一条可打勾的达成判据：
   "能识别混淆变量并说明控制方式"。写不出判据，说明该目标不可评，记入"目标层面的待办"，
   不要靠印象填。没有应然就没有 gap，只有"感觉差"。

2. **盘点"实然"证据并分级。** 三级：一级（学生作品原件）、二级（课堂观察、随堂记录）、
   三级（转述、论坛提问、同学反馈）。只有三级证据时可以提出假设，不能下诊断结论；
   报告里写明本次诊断用了几级证据。

3. **抽样，别全批就全断。** 按表现分三段（高/中/低）各取若干份，**低分段必须有人**。
   只看高分样本是最常见的自欺方式：它会让所有问题都显得不存在。
   样本量少于 10 份时，结论只写成"初步线索"。

4. **两层编码。** 第一层（子目标轴）：未触及 / 触及但错误 / 部分达成 / 达成。
   第二层（错误性质轴）：①概念性误解（用错原理，把 A 当 B）；②程序性失误（原理对，步骤错或漏步）；
   ③策略性缺失（会算但不知选哪种方法）；④迁移失败（换情境就不行）；
   ⑤表达性障碍（想法对但写不清、符号不规范、外语术语卡壳）；⑥条件性缺失（会但没时间/没条件）。
   先写编码字典（定义 + 样例），再多人独立编码同一批样本——两人不一致是字典有歧义的信号。

5. **做应然—实然对照，算 gap。** 每条子目标一行：应然判据 / 实然表现 /
   差距等级（未达 / 接近 / 达成 / 超越）/ 证据强度。注意"接近"这一档：
   很多学生不是不会，而是差一个条件（"知道要控制变量，但没说怎么控制"），干预成本最低，优先做。

6. **给 gap 分层。** 全班 gap（多数人同一处塌）→ 改教学；群体 gap（某一类背景集中出现）→ 改支持；
   个体 gap（个别学生独有）→ 个别辅导；伪 gap（作品已达判据但被误判为弱）→ 改判分或申诉。
   伪 gap 是"分数低不等于不会"的直接证据，必须查。

7. **写归因备择解释，别写结论。** 每个主要 gap 至少给两个可能解释，
   每个解释配一个**判别性证据**——"要判断是概念误解还是表达障碍，需要看他们的草稿过程与口头解释"，
   并说明判别数据从哪来、下次什么时候能拿到。

8. **排序。** 优先级 = 影响面（多少人）× 严重度（是否阻断后续）× 可干预性（有无已知有效动作）。
   排 P0 / P1 / P2，并写明排序理由。

9. **写改进假设并挂上复评。** 格式："如果对 <P0 gap> 采取 <动作>，
   那么 <指标> 应从 <现值> 变为 <目标>，在 <时点> 用 <数据来源> 复评。"没有复评的干预等于没做。

10. **交接到下游。** "全班 gap"和"群体 gap"交给 `differentiation-adapter` 设计支架与分层任务；
    "目标不可评"交给 `competency-unpacker` 重新拆解。收口时输出数据质量声明，
    推断标「假设」、缺失信息标「待补充」。

## 中国高校语境要点

- **课时与干预窗口**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。差距分析的产出必须在
  **下一次课之前**可用，否则只是事后总结；诊断结论直接对应下一次课的一个 45 分钟课时安排。
- **评价制度与权重**：诊断证据主要来自形成性评价（随堂小测、课堂任务、阶段作业、discussion）；
  终结性考核（期末笔试/开卷/机考）的分数能提示"某子目标大面积偏弱"，但不能替代作品级证据。
  补救作业若计入平时成绩，占比要写清，课程各项百分比加总**恰好 100%**。
- **毕业要求支撑与思政**：子目标与毕业要求指标点的对应由院系给定，**没给就留空**，
  指标点级别的 gap（多数学生都未达）要单列上报。若思政目标未在作品中出现，
  先判断是"没教"还是"教了没评"，不要在诊断报告里把"没有体现思政"写成学生问题。
- **教材与实验**：错因分析要与教材讲解口径对照，ISBN 需真实，查不到写「待补充」。
  实验报告的错误要区分"操作不规范"（E2 程序性）与"设计缺陷"（E1/E3 概念与策略），
  并注明实验环节学时数与考核占比。
- **跨专业与表达障碍**：外语术语不熟、符号规范不熟、表达不完整常被误读成"不会"。
  E5 必须单独统计，否则会得出"补基础概念"的错误结论，而真正需要的是表达训练与术语表。
- **数据使用边界**：诊断结果用于教学改进与学习支持；个体 gap 记录涉及学生个人信息，
  不进入评优与公示材料。学业预警是流程，本技能不替代预警流程。

## 易错点

- ❌ 只看分数分布、或只批高分样本就下诊断 → ✅ 分数提示位置、作品定位步骤；分段抽样，低分段必须有人看
- ❌ 用"不努力"作为错误类型 → ✅ 错误类型是性质（概念/程序/策略/迁移/表达/条件），不是态度
- ❌ 一个错误只给一个解释 → ✅ 至少两个备择解释 + 判别性证据
- ❌ 把"接近达成"当"未达" → ✅ 单独设"接近"档，它的干预成本最低
- ❌ 漏查伪 gap（已达标却被判弱）、编码字典不定义就开编 → ✅ 核对判分与判据；先写定义 + 样例，两人独立编码校准
- ❌ 结论没有复评安排 → ✅ 每条改进假设都写指标、现值、目标值、时点、数据来源
- ❌ 归因到学生态度后没有下文、直接给个体贴标签并公示 → ✅ 归因指向下一步可取的证据；个体信息不进入公示材料
- ❌ 编造指标点编号、ISBN、学院规定 → ✅ 查不到写「待补充」并列入核验清单

## 自检清单

- [ ] 每条子目标都有可打勾的应然判据
- [ ] 证据等级已分级，抽样覆盖高/中/低三段且低分段有样本
- [ ] 编码字典先定义后使用，含判定要点与样例
- [ ] 至少一部分样本经过两人独立编码，差异已处理
- [ ] 差距等级区分了"未达 / 接近 / 达成 / 超越"
- [ ] gap 已分为全班 / 群体 / 个体 / 伪 gap 四类
- [ ] 每个主要 gap 至少两个备择解释，各配判别性证据
- [ ] gap 排了 P0/P1/P2 并写了排序理由
- [ ] 每条改进假设含指标、现值、目标值、复评时点、数据来源
- [ ] 表达性障碍（E5）已单独统计
- [ ] 数据质量声明写明了样本、缺失、一致性、证据等级、结论强度
- [ ] 权重、指标点编号、ISBN 等事实项：真实或已列入待补充，无编造

## 交叉技能

- 诊断结果转成分层任务与支架 → `differentiation-adapter`
- 目标不可评需重新拆解 → `competency-unpacker`
- 错误类型的细化与讲评 → `error-analysis-protocol`
- 考核是否真测到目标 → `assessment-validity-checker`
- 改进后如何验证 → `formative-assessment-loop-designer`
- 反馈文本与成绩数据的使用边界 → `feedback-quality-analyser`、`learning-analytics-interpretation-guide`
- 进阶路径与水平判定 → `learning-progression-builder`、`checking-for-understanding-protocol-designer`
- 学段与课时制度换算 → `he-context-adapter`
