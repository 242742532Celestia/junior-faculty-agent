# 学习进阶构建

## 这个技能解决什么

大纲第一章讲定义，第二章讲定理，第三章讲应用。学生学完第三章，
有人能处理没见过的情境，有人只会复述第三章的例题。这两种人都"上过课"，
但显然不在同一个地方。

问题在于教学语言里只有两种状态："讲过"和"没讲过"。没有第三种状态来说明
"这个学生在这个构念上目前达到哪一层"。于是每节课都在默认所有人从上一层跳到下一层，
而实际发生的是：一部分人跳了，另一部分人卡在原地几周甚至退回上一层。

进阶地图要提供的就是这第三种状态。它把"教什么"改写成"学生在这个构念上
从哪一层走到哪一层"，每一层用**可观察的学生行为**来定义，
并指出从上一层到下一层之间需要搭什么桥、卡在哪里最常见。

它还有一个常被忽略的用途：把"差生"和"进度慢"区分开。
一个学生停在第 2 层，是因为第 2 层没学扎实，还是因为第 3 层需要的前概念缺失？
两种情况在进阶地图上一眼可辨，而考试卷子上的一个分数永远看不出来。

## 什么时候用 / 什么时候不用

**用**：
- 需要把按内容排列的大纲改造成按能力发展的教学路径
- 一个构念跨多节课甚至跨章节，学生水平差异大，需要标定当前位置
- 教学反馈只给分数，学生不知道"我现在在哪、下一站在哪"
- 设计阶段性检查点与进阶评价，或要写课程目标达成度分析

**不用**：
- 只需排教学进度顺序（那是 `scope-and-sequence-designer`）
- 目标本身过大无从测量（先做 `competency-unpacker`）
- 一次性知识点的讲解（不必建进阶）
- 想让学生做更多练习（那是 `practice-problem-sequence-designer`）

## 输入

**必填**（缺任一项先出草稿并把假设标出来）：
1. 目标构念：你想让学生最终能做什么（如"设计并评价一个实验方案"）
2. 课程总学时与周次（按 16 周/学期计）
3. 学生起点：年级、专业、先修课程、可能的跨专业来源
4. 现有教学单元顺序（进阶地图要挂靠到实际课次上）
5. 终结性考核的形式与权重

**选填**（没有就留空，写进"需人工核验清单"，**不许编**）：
6. 可用的诊断数据（前测、随堂小测、作业错误分布）
7. 教材版本与对应章节（ISBN 需真实，查不到写"待补充"）
8. 毕业要求指标点编号（**用户没给就留空**）、课程思政要求
9. 实验/实践环节的学时数、分组方式与考核占比

## 执行步骤

1. **选定构念，划清边界。** 进阶建在"构念"上，不是"章节"上：一个构念可以跨三章，
   也可以一章里含两个构念。必须写清这个构念**不包含什么**——边界不清时，
   学生做的相邻任务会不断混进"看起来会了其实没会"的状态。还要写清它为什么重要
   （它通向哪个更上位的目标或指标点）。

2. **采集前概念。** 学生带着什么进来，直接决定第一层设在哪里。前概念往往不是"没有"，
   而是"有一个错的版本"（把相关当因果、把总量当比例）。用 2–3 个诊断性问题或
   一个 10 分钟任务来获取，并写下每个前概念会**干扰哪一级**——前概念不是背景信息，是路障清单。

3. **划分水平（3–5 级）。** 划分依据是**认知结构的复杂度**，不是内容的多少或难度。
   一个可用的参照：单点结构（能复述/孤立使用）→ 多点结构（能列出若干要素）
   → 关联结构（要素之间建立关系、能解释取舍）→ 拓展抽象（能迁移到新情境、能质疑前提）。
   水平数一般 3–5；层级太密反而标不准。

4. **用学生行为写每一级。** 每级至少给四样东西：**典型行为**（一个可以观察的动作）、
   **作品样例**（真实或仿真的学生输出）、**常见错误**（这一级上最典型的错法）、
   **达成判据**（可打勾的判定条件）。不要直接抄结构水平术语，必须落到学生身上。

5. **设计过渡桥与支点。** 从第 n 级到第 n+1 级之间要搭什么桥：示例、反例、类比、变式练习、
   一次同伴解释或一次"把这个模型用到我的情境"的迁移任务。在每级之间标出**支点**：
   不跨过去就整片塌陷的那一步（通常是"从描述到解释"的跨越）。支点决定课时优先给谁。

6. **标出回退与再概念化。** 进阶不是单向楼梯。学生到了第 3 级，遇到与前概念冲突的证据，
   可能退回第 2 级甚至产生认知冲突——这不是倒退，是必要的一步。把这些"可能回退点"标出来，
   并写清用什么材料化解冲突；这一步直接决定了概念能否真正转变。

7. **挂证据与标级规则。** 每一级对应什么证据（哪份作业/哪次小测/哪个课堂产出），
   以及由谁、按什么规则把学生的作品标到哪一级。标级规则要写成可复核的判断，不是"教师感觉"。

8. **排课时与检查点。** 每一级分配多少课时、安排几次形成性检查、在哪个时点标级。
   检查点要落在**支点之后**（不在支点检查一次是浪费）。45 分钟一课时的排法：
   一个层级通常 1–3 次课，不宜压成一次。

9. **写"学生版进阶叙事"。** 一段面向学生的文字：你在哪一层、下一层什么样、
   你可以做什么来移动、移动的证据是什么。学生往往不是不想学，是不知道"下一层"长什么样。

10. **复核与收口。** 检查最顶层是否真的落在课程目标上；标出思政融入点；
    列出假设与待补充信息。

## 与概念脊柱、升阶操作符的衔接

本技能回答"学生在这个构念上到哪一层"，`scope-and-sequence-designer` 回答"课怎么排"。
两者若各写各的，会留下两份互不引用的文件：进阶说"第 5 周达 L3"，
进度表说"第 5 周讲第 4 章第 3 节"，谁也不知道谁。
本节负责把两者接上：**课表上的每一次概念重访，就是进阶地图上的一次水平推进**。

### ① 两个视角的分工

| | 概念脊柱与遭遇史 | 学习进阶地图 |
|---|---|---|
| 回答的问题 | 这个概念在**课表上**怎么反复回来 | 学生在**这个概念上**目前到哪一层 |
| 组织单位 | 周次 / 课程行 | 构念 / 水平 |
| 产出 | 排课顺序与每次新增的结构 | 水平定义、支点、标级规则 |
| 关系 | 水平高低的**证据来源** | 遭遇史的**设计依据** |

一句话：**遭遇史告诉我们"什么时候该再上一次"，进阶地图告诉我们"上次到哪、这次要到哪里"。**
两者互为输入——缺了遭遇史，进阶的水平是悬空的；缺了进阶，遭遇史的升阶只是宣称。

### ② 进阶建在概念脊柱的单个概念上，不是章节上

一个核心概念可以跨三章，一章里也可能含两个概念。
因此建阶之前必须先回答：**这份进阶对应概念脊柱上的哪一个概念？**

- 若一个构念横跨多个脊柱概念 → 构念划得太粗，拆成两个构念，各挂一个概念；
- 若一个脊柱概念下有多个构念 → 每个构念单独建阶，共享同一个"最终理解目标"作为上位约束。

### ③ 升阶操作符 ↔ 进阶水平的映射

| 升阶操作符 | 跨越的进阶水平 | 该次新增的结构 | 典型可观察证据 |
|---|---|---|---|
| `ADD_COMPLEXITY` | L2 → L3 | 从单变量到多变量相互作用 | 能说出取舍代价 |
| `ADD_RELATION` | L1 → L2 | 概念间形成必要关系 | 能指出关系缺失的后果 |
| `ABSTRACT` | L3 → L4 | 从案例上升到一般模型 | 能把模型用到未教过的实例 |
| `FORMALIZE` | L2 → L3 | 引入符号或专业语言 | 能用符号表达并解释 |
| `CHANGE_REPRESENTATION` | L1 → L2 | 表征方式切换 | 同一概念两种画法互译 |
| `INCREASE_TRANSFER_DISTANCE` | L3 → L4 | 进入陌生情境 | 迁移后仍能指出失效条件 |
| `ADD_EXCEPTION` | L2 → L3 | 加入反例与边界 | 能说出例外成立的界限 |

> 规则：**一个操作符通常只对应一次水平跨越**；
> 若某次重访跨了两级，要检查是不是把两个操作符叠在了一节课里——
> 叠了通常意味着学生还没准备好，而不是他们学得快。

### ④ 螺旋遭遇史 ↔ 进阶水平

**遭遇史的第几次 = 目标水平。** 把概念脊柱上的遭遇史逐次展开，与进阶地图对齐：

| 遭遇次序 | 目标水平 | 主操作符 | 这次新增的结构 |
|---|---|---|---|
| 第 1 次 | L1 | （首次接触） | 单一关系与直观表征 |
| 第 2 次 | L2 | `CHANGE_REPRESENTATION` | 表征切换，与相邻概念建立关系 |
| 第 3 次 | L3 | `ADD_COMPLEXITY` | 多变量相互作用与取舍 |
| 第 4 次 | L4 | `INCREASE_TRANSFER_DISTANCE` | 陌生情境迁移与失效条件 |

**假螺旋检查在本技能视角下的读法**：
若同一概念的多次遭遇对应**同一个水平**，说明那是重复不是升阶——
此时该改的是**教学安排**（补升阶维度、换情境、换表征），而不是改进阶定义。
改进阶定义最容易，也最坏：它把教学设计问题写进了测量工具。

### ⑤ 水平定义的升阶维度约束

现有 3–5 级划分（单点结构 → 多点结构 → 关联结构 → 拓展抽象）要**与六个升阶维度对齐**：
每一级至少在**哪一维度**比上一级高，必须写出来。

| 级别 | 至少要在哪一维度高于上一级 | 典型新增结构 |
|---|---|---|
| L1 → L2 | 表征方式 / 关系密度 | 从孤立陈述到要素罗列或表征切换 |
| L2 → L3 | 复杂度 / 抽象度 | 从罗列到建立关系、能解释取舍 |
| L3 → L4 | 迁移距离 / 边界与反例 | 从解释到迁移，并指出失效条件 |

若写不出"这一级在哪个维度更高"，说明这一级是**内容切分**而不是**水平切分**，应合并层级。

## 中国高校语境要点

- **学时与节奏**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟，中间不宜超过 15 分钟连续讲授。
  每一级通常需要 1–3 次课（45–135 分钟）才能稳定达成，压成一次课的层级不可信。
  学期按 16 周计算，排课时先扣掉复习与考试周。
- **评价制度与权重**：标级是**形成性**动作（课堂产出、单元作业、小测）；
  终结性考核（期末笔试/开卷/机考）给出的是「优秀 / 良好 / 合格 / 不合格」等级，
  需在表 5 写明等级与水平的映射（如良好 ≈ L2–L3 区间）。及格线与等级切分点不因水平差异而调整；
  课程各项百分比加总**恰好 100%**。
- **毕业要求支撑与思政**：最高层级对应毕业要求指标点，编号由院系给定，**没给就留空**，
  不要自造"毕业要求 4.1"。思政融入点放在进阶的推进过程中——例如从"会算"到"会质疑"这一层，
  价值判断随水平上升而深化（谁承担风险、谁受益），并写明融入方式，不要在知识点后贴标签。
- **教材与实验**：每一级要能指回教材对应章节，ISBN 需真实，查不到写「待补充」。
  程序性能力要单独建一条进阶（操作规范 → 稳定复现 → 自主排障），并注明实验学时数、
  分组方式与考核占比；实验分值与笔试分值在权重表中分开。
- **起点差异与工作量**：跨专业、专升本、境外学生起点不同，入口判定不能只靠一次摸底考，
  建议用诊断题 + 首次作业两种证据交叉判定入口层。若院系需要，按各水平课时折算教学工作量，
  说明依据，不自拟系数。
- **进阶水平与学期周次的挂靠**：每一级要落到具体周次与具体课次
  （如"L3 落在第 8–9 周的第 14–15 次课"），不能只写级数；
  挂靠后的课时与检查点顺序仍以 45 分钟/学时、90 分钟连堂为约束。
- **思政融入点随水平上升而深化**：融入点不是一次性的，而是随水平递进的——
  L1–L2 落在"会算/会复述"的事实层（是什么、怎么做的），
  L3 落在"会质疑"的取舍层（为什么这样选、代价由谁承担），
  L4 落在"会负责"的责任层（应当怎么做、后果由谁承担）。
  每一层写明融入方式与载体案例，不在知识点后贴标签。
- **水平与等级的映射**：等级（如"优秀 / 良好 / 合格"）对应一段**水平区间**而非单一水平，
  映射关系写进表 5（如"良好 ≈ L2–L3 区间"）；
  **及格线不因学生所处水平或水平区间不同而调整**——
  水平用于诊断与反馈，不用于抬高或降低通过标准。

## 易错点

- ❌ 把章节顺序当进阶、层级按"内容多少"划分 → ✅ 进阶建在构念上，按认知结构复杂度分层
- ❌ 水平用术语描述（"关联结构"） → ✅ 落到学生的可观察行为与作品样例
- ❌ 不写前概念 → ✅ 前概念是路障清单，必须采集并标注干扰哪一级
- ❌ 进阶画成单向楼梯、过渡桥只写"多练" → ✅ 标出回退/再概念化点并写化解材料；写明桥接动作与支架材料，标出支点
- ❌ 标级靠教师感觉、层级数越多越好 → ✅ 标级规则写成可复核判断；层级 3–5 级
- ❌ 进阶图做完就归档 → ✅ 每一级必须挂证据、检查点与课时
- ❌ 思政只写在末尾一课、编造指标点编号与 ISBN → ✅ 融入点挂在水平推进中；查不到写「待补充」并列入核验清单
- ❌ 进阶与课表各写各的（进阶说 L3，进度表说第 4 章第 3 节，互不引用） → ✅ 每份进阶都挂靠到概念脊柱的某个具体概念，每次重访标出目标水平与主操作符
- ❌ 同一概念的多次遭遇对应同一个水平，却当成"多次升阶" → ✅ 遭遇对应的水平相同即说明是重复，该改教学安排而不是改进阶定义
- ❌ 一次重访把两个以上升阶操作符叠在一起 → ✅ 一个操作符通常只对应一次水平跨越，跨两级要检查是否叠了操作符
- ❌ 水平之间说不出"这一级在哪个维度更高" → ✅ 每一级至少在六个升阶维度之一上高于上一级，说不出就合并层级

## 自检清单

- [ ] 构念已定义，边界（不包含什么）已写清
- [ ] 前概念已采集，并标注各自干扰哪一级
- [ ] 水平数为 3–5，每级都含行为描述、作品样例、常见错误、达成判据
- [ ] 每一级之间都有桥接动作与支架材料，支点已标出
- [ ] 已标出回退/再概念化点及化解材料
- [ ] 每级都挂了证据与可复核的标级规则
- [ ] 检查点落在支点之后，课时与 45 分钟/90 分钟连堂一致
- [ ] 课时合计与课程总学时的差额已说明，等级与水平的映射已写明
- [ ] 课程各项权重加总 = 100%，学生版进阶叙事已产出
- [ ] 指标点编号、ISBN 等事实项：真实或已列入待补充，无编造
- [ ] 每份进阶都挂靠到概念脊柱上的某个具体概念（不是章节）
- [ ] 每次重访都对应明确的目标水平与主升阶操作符
- [ ] 升阶操作符与水平跨越一一对应，没有一次重访叠多个主操作符
- [ ] 同一概念的多次遭遇对应的是不同水平（相同即说明是重复）
- [ ] 已产出"概念—水平—升阶操作符对照表"，且每级写明在哪个升阶维度上高于上一级
