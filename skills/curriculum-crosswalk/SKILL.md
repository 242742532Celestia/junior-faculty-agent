# 课程目标—毕业要求支撑对照

## 这个技能解决什么

专业认证材料里最常见的一句话是"本课程支撑毕业要求第 X 项"，但追问下去常常没有下文：

- 课程大纲里的目标是"了解数据结构的实现方式"，却被写在支撑"工程规范与社会责任"这类指标点上；
- 指标点原文写的是"能在复杂工程情境中综合运用专业知识"，课程只教了其中一个算法分支；
- 整门课被写成某指标点的唯一支撑来源，而这门课在大二、考核只有一次开卷小论文；
- 课程目标里有一整条（"具备团队协作与终身学习能力"）在任何指标点里都找不到落点。

本技能把"宣称支撑"变成**逐格可核对的证据**：哪条课程目标、以多大强度、靠什么证据、
在什么时点采集，支撑了哪一条指标点。缺口同样是交付物——不是每个指标点都必须被本课支撑，
但每个宣称都要经得起追问。

## 什么时候用 / 什么时候不用

**用**：
- 编制或更新"课程目标—毕业要求"支撑矩阵（认证材料、专业评估、院内自查）
- 评估某门课是否真的承担了它宣称的指标点支撑责任
- 调整课程目标权重或删改目标后，重新核对支撑结构是否断裂
- 审核新增/撤销课程对整体培养方案的影响

**不用**：
- 课程内部"目标—考核—活动"的三段对齐（那是单元教学设计的事）
- 学生个人毕业要求达成情况核算（那是数据采集与统计核算，不是对照设计）
- 尚无毕业要求指标点文本时凭空设计指标体系（没有原文就没有对照对象）

## 输入

**必填**：
1. 毕业要求指标点原文与编号（**由用户或院系提供**；照抄，不改写、不自拟编号）
2. 本课程目标清单（含目标权重，加总应为 100%）
3. 本课程的定位说明（专业哪一年级、哪类课、先修与后续关系）
4. 本课程可选的证据形式（作业、考试、实验报告、设计作品、课程报告等）

**选填**（用户没给就留空并列入核验清单）：
5. 培养方案中其他课程与指标点的对应关系（用于判断支撑是否重复或缺位）
6. 指标点达成度的目标值/达标线（院系给定才填）
7. 课程思政要求
8. 教材与参考书版本（ISBN 须真实，查不到写「待补充」）
9. 本课程的学时与实践环节占比

## 执行步骤

1. **逐字录入指标点原文并编号。**
   指标点文本必须来自院系或专业认证标准现行版本，**逐字抄录**；
   编号沿用院系给定的写法（如"3.2""毕业要求 5"），**没有就留空**，
   不要用"GR1/GR2"或"毕业要求第 X 项"这类自拟编号冒充官方编号。
   同时记录来源文件名称与版本年份；来源不明就写「来源待确认」。

2. **把每个指标点拆成能力成分。**
   一条指标点往往包含 2–4 个可观察成分（动词 + 对象 + 条件）。例如
   "能针对复杂工程问题综合运用专业知识"可拆成：识别问题情境、迁移多个学科方法、在约束下给出可验证方案。
   拆分目的是让"支撑"落到成分上，而不是落到整句口号上。

3. **写课程目标（动词 + 对象 + 条件）。**
   目标必须能被本课程真实教学与考核支撑。用统一动词体系（Anderson & Krathwohl 的分类层级）
   保持措辞一致，便于跨课程横向比较。权重加总应为 100%。

4. **逐格判定贡献等级并写判据。**
   对每个"指标点 × 课程目标"的格子判为三级：
   - **I 主责**：本课程是该成分的主要实现途径，且有终结性证据；
   - **II 协同**：只贡献部分成分或只提供前置准备，需其他课程补齐；
   - **III 支撑**：仅提供背景知识与条件，间接相关。
   每格写一句话判据（"承担了'识别问题情境'成分，本课第 3 章案例分析直接测量"）。
   判据写不出来时，说明这格不该打勾。

5. **汇总支撑强度与单课依赖风险。**
   对每条指标点统计：标 I 的课程数量、标 II 的课程数量、是否只有一门课标 I。
   只有一门课标 I 的指标点标为**单课依赖**，这类指标点一旦该课停开或考核形式改变即断链。
   反过来，某门课给所有指标点都标 I，说明该课目标失焦，需要回头砍目标。

6. **双向找缺口并定性。**
   - 从指标点看：哪些成分在本课程完全没人支撑（是本课该补，还是本来就属于别的课）；
   - 从课程目标看：哪些目标找不到任何指标点归属。**这里必须分两种**：
     通用能力类目标（如"具备沟通协作能力"）通常不对应专业指标点，可注明"通用能力，不计入指标点支撑"；
     学科核心能力类目标则多半是**真孤立**——培养方案里没人认领，毕业生这一能力将无证据支撑。
   两类不能用同一种说法含糊过去。

7. **写达成度证据链与采集计划。**
   对每条标 I 的指标点写出：指标点 → 课程目标 → 证据形式 → 数据来源（哪次作业/哪份报告/哪次考试）
   → 采集时点（学期中/期末/课程结束后）→ 责任人 → 目标达成度如何计算。
   链条上缺一环，这条支撑就只是宣称。

8. **输出核验清单。**
   凡属推断（本课对某成分的实际贡献程度、达成度目标值）标「假设」；
   凡属未提供但必须知道的信息（指标点原文、编号、目标值）标「待补充」。

## 中国高校语境要点

- **指标点来源**：毕业要求指标点由院系或专业认证标准给定。工程类专业认证标准通常给出若干条
 毕业要求条目并按 1–12 编号，但**必须以本校现行文本为准**，不得凭印象写"第 3.2 条"。
- **留空规则**：用户没给指标点原文时，输出表 1 只写表头与占位说明，
  并把"索取指标点原文"列为核验清单第一项——**宁可交半成品，不要编一套指标体系**。
- **权重校验**：课程目标权重加总 = 100%；各门课程在总评中的百分比也加总 = 100%。两处都要核。
- **学时与证据强度**：1 学时 = 45 分钟，2 学时连堂 90 分钟。学分高、实践占比大的课程
  才能承担"主责"级支撑；纯讲授的 1 学时课若被标为某指标点的唯一 I 级支撑，
  证据链天然偏弱（课程本身的学时量不足以支撑该成分的达成判定）。
- **评价制度**：课堂小测与课程报告属形成性评价，是达成度证据的常规来源；
  期末笔试、开卷、机考属终结性考核，是结论性证据。
  指标点的达成度测算以终结性证据为主、形成性证据为辅，
  只有终结性证据的指标点才算"可判定达成"。
- **课程思政**：思政目标通常不单独对应专业指标点，若本校指标点中有"社会责任""工程师伦理"
  类条目，需以**本校原文措辞**为准再归类，不得由本技能自行判定归入哪一条。
- **实践环节**：实验、实习、设计类课程要把学分与考核占比写进表 7 的证据链，
  实践环节的证据不能只靠期末笔试。
- **教材**：写证据来源或指定阅读材料时，ISBN 与版本须真实，查不到写「待补充」。

## 易错点

- ❌ 自拟指标点编号或改写指标点原文 → ✅ 逐字抄录官方文本，编号沿用院系写法，没有就留空
- ❌ 整句指标点整体打勾，不拆成分 → ✅ 拆成能力成分，支撑落在成分上
- ❌ 每格只有勾没有判据 → ✅ 每格写一句"为什么算 I"，写不出判据就不打勾
- ❌ 所有指标点都标 I → ✅ 标 I 的课程多了说明分工不清，要重新划界
- ❌ 课程目标找不到指标点归属就删掉目标 → ✅ 先分通用能力与学科核心能力，前者注明不计入支撑，后者必须上报
- ❌ 只做映射不写证据链 → ✅ 支撑宣称必须能落到具体数据来源与采集时点
- ❌ 把"单课依赖"当成没问题 → ✅ 标出来并给增补课程或强化证据的建议
- ❌ 编造达成度目标值 → ✅ 院系给定才填，否则列入待补充

## 自检清单

- [ ] 指标点原文逐字抄录，编号沿用官方写法，无自拟编号
- [ ] 每条指标点已拆成 2–4 个可观察能力成分
- [ ] 课程目标以可观察动词开头，权重加总 = 100%
- [ ] 每个打勾的格子都有一句判据
- [ ] 每条指标点的支撑强度已统计，单课依赖已标出
- [ ] 双向缺口都已定性并给出处置与责任人
- [ ] 每条标 I 的指标点都有完整证据链（来源、时点、计算方式）
- [ ] 课程思政的指标点归属以本校原文为准，未自行归类
- [ ] ISBN、达成度目标值等事实项：真实或已列入待补充，无编造
