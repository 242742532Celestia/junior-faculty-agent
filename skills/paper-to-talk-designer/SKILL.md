# 论文转汇报设计器

## 这个技能解决什么

教师把自己的论文（或学生的论文、一项研究）转成一场 12–15 页的学术汇报时，最常见的失败不是"做不出 PPT"，而是**把论文的段落结构直接搬到幻灯片上**：页标题就是论文章节名、每页塞四段正文、图表原样贴上去不写结论句、15 分钟讲 40 页。评委听完记住了方法流程，却没记住这篇工作主张了什么。

根子是**单位错了**。论文的组织单位是"章节"，汇报的组织单位应当是**听众应该接受的结论**：一个结论一页，论文的一个小节可能对应零页、三页，也可能被打散到叙事的三处。

本技能给出从论文到汇报叙事的**映射方法**，交付三件套：幻灯片规格、逐页讲稿、问答预案。

**与包内 `scientific-slides` 的分工**：`scientific-slides` 管**会议 slides 的通用方法与 Beamer 模板**（LaTeX 排版、英文场次）；本技能管**中文高校场景下"一篇论文 → 一场汇报"的叙事重构**，产出中文讲稿 + 幻灯片规格 + 问答预案，不涉及模板与排版实现。

## 什么时候用

用：

- 学位论文、期刊论文、会议投稿要做答辩或组会汇报时；
- 基金项目要做立项/中期/结题汇报时；
- 学生论文答辩前，需要从论文里抽出"该讲什么、不讲什么"时；
- 同一篇论文要准备不同听众版本（专家版 / 全场版 / 学生版）时；
- 已有 PPT 但"听着像在念论文"，需要重构叙事时。

**不用**：要生成 Beamer/LaTeX 会议模板或英文 slides 排版时（用 `scientific-slides`）；要的是论文写作本身而不是汇报时（用 `scientific-writing`）；要的是海报时（用 `latex-posters`）。

## 输入

**必填**（缺项时先按默认起草并标为待核验假设）：论文全文或其摘要、方法、结果、结论四部分；听众构成（同行评审 / 答辩委员会 / 本课学生 / 基金评审）；时长（是否含问答、问答预留多久）；场合（正式答辩 / 组会 / 学术报告 / 课程汇报）。

**选填**（**没给就留空，不编**）：已发表或已投稿状态；数据保密等级与可否展示的界限；是否有合作者与致谢名单；是否需要英文版。

**不编造原则**：本技能不生成论文里没有的数据、结论或文献。摘要里没有的一句话主张，不要替作者"总结"出一条新主张——那属于越权。

## 执行步骤

### 第 1 步：先定听众与时长

听众决定"哪些结论必须被接受"，时长决定"能承载几个结论"。这两件不定，后面全是返工。

**表 1 · 听众-时长-页数-版式配比表**

| 时长 | 总页数（含封面与收束） | 建议版式配比 | 说明 |
|---|---|---|---|
| 10 分钟 | 9–12 | 封面 1 + 主张 1 + 证据 5–6 + 收束 1 | 只讲一个主张，不铺背景 |
| 15 分钟 | 12–15 | 封面 1 + 主张 1 + 承接 1–2 + 证据 6–8 + 收束 2 | 组会与答辩的常态档 |
| 20 分钟 | 16–20 | 封面 1 + 主张 1 + 承接 2 + 转折 1 + 证据 8–10 + 收束 2 | 课程汇报与专题报告 |
| 40 分钟 | 28–35 | 封面 1 + 主张 1 + 承接 2–3 + 转折 1–2 + 方法 3–4 + 证据 12–15 + 收束 2 + 致谢 0–1 | 学术报告与基金汇报 |

经验带是**每分钟 0.8–1.2 页**；证据页比背景页值钱，宁可少排背景页也要把证据页留够。每页再标一个**时间预算**（分钟），全篇加总必须 ≤ 时长，并留出问答时间。

### 第 2 步：抽出一句话主张

从摘要或结论里抽出"这篇论文要让听众记住的一句话"。写不出，就是论文本身还没有一句话主张——回到论文改摘要，而不是在汇报里硬造。

检验方法：念给一个没读过论文的人听，他能复述吗？不能，说明还太宽（"本文研究了 X 领域"）或太窄（"我们测了 12 个样本"）。主张句可以是结论型（证明/发现 X）、问题型（针对空白给出 Y）或反直觉型（常识认为 X，实际是 Y），多数论文首选结论型。

### 第 3 步：把论文章节映射成叙事段落

**表 2 · 论文结构 → 汇报叙事映射表**

| 论文部分 | 汇报中的角色 | 页数 | 处理方式 |
|---|---|---|---|
| 摘要 | 一句话主张 | 1 | 抽成断言式标题，占第一页 |
| 引言 | 承接页 | 1–2 | 只留"为什么这个问题值得做" |
| 相关工作 | 转折页 | 1 | 改成"前人做到哪、还缺什么" |
| 方法 | 证据页（可信度） | 2–4 | 只讲影响可信度的设计选择 |
| 实验与结果 | 证据页（主体） | 5–12 | 每张图表配一句结论句 |
| 讨论 | 转折页 | 1 | 机制解释 + 适用边界 + 与前人的差别 |
| 结论 | 收束页 | 1 | 做了什么 / 发现了什么 / 意味着什么 |
| 致谢 | 可选 | 0–1 | 念出来或压进最后一页页脚 |

关键判断：**某章节对应的页数由"它能贡献几个听众必须接受的结论"决定，不由它在本论文字数里占多少决定。** 结果部分字数最多，短汇报里却可能只占一半页数；方法部分可能只有一段话，却要拆成两页。

### 第 4 步：区分三种页

**表 3 · 三种页的判定与版式建议**

| 页型 | 判定标准 | 版式建议 | 失败信号 |
|---|---|---|---|
| 承接页 | 建立听众的共同起点，不引入新结论 | **section** / **bullets** | 堆到讲者自己都读不下去的背景 |
| 证据页 | 承担论证：图表、数据、实验、推导 | **image-focus** / **bullets** | 图表裸贴，页标题写成"结果""实验" |
| 转折页 | 改变听众的预期或立场 | **quote** / **bullets** | 用"但是""然而"开头，却没落到具体结论 |

一张表里混合多种页型是典型错误：把"背景 + 方法 + 结果"压在一页，页标题只能写成"研究内容"这种分类词。

### 第 5 步：证据页必须有结论句

图表不能裸贴。每张进入汇报的图表，都要在同页配一句"这张图说明什么"。**结论句模板：「图 N 显示 A，因此 B。」** 或 **「数据表明 A，这支持 B。」** A 必须是论文里真实存在的观察，B 必须是论文里真实成立的推论；具体数值一律填论文原值，不得改写、不得取整到失真。

标题承担同样的功能：把论文章节名"3.2 实验结果"换成断言式标题"该设计是误差的主要来源"。

### 第 6 步：处理时间不足

讲不完是常态。砍页有固定优先级，**按这个顺序砍，不按讲起来顺不顺砍**：

1. **先砍背景综述**——听众不关心你的领域史。
2. **再砍相关工作的逐条列举**——只留与本文最相关的一到两篇，一句话带过。
3. **再砍方法的实现细节**——保留影响可信度的设计选择，删掉参数怎么调、代码怎么写。
4. **再砍次要证据页**——按重要性排，重要性不明的先标为待砍。
5. **绝不砍核心证据页**——主张所依赖的那张图、那张表、那组数据，必须留。
6. **绝不砍结论与含义页**——没有收束，听众记不住任何东西。
7. **致谢页最先合并**——念出来或压进最后一页页脚。

砍完重排页码、重算时间预算，并确认证据页与结论句仍然成对存在。

### 第 7 步：设计问答预案

答辩的问答环节，提问几乎总落在六个方向。逐类预判，每类准备两到三条，并**指明依据在论文的哪一节**——没有依据的回答就是话术。

**表 4 · 六类预判提问与应对**

| 预判方向 | 典型问法 | 回答要点 | 依据应在论文的哪一节 |
|---|---|---|---|
| 方法质疑 | 这个设计真能测出你要的东西吗 | 承认局限，说明为什么在当前条件下这是最优可行解 | 方法部分的设计取舍与局限性说明 |
| 样本质疑 | 这些样本有代表性吗 | 说清抽样框、纳入排除标准、样本量为何够用 | 数据与样本说明部分 |
| 指标定义 | 这个指标为什么这样定义 | 给出定义式与选择理由，承认替代指标的差异 | 方法中的指标定义处 |
| 因果性 | 这个变化是原因造成的吗 | 明确是相关还是因果，说明控制了什么、没控制什么 | 设计与结果解释部分 |
| 可推广性 | 换个场景还成立吗 | 给出成立条件与失效边界，不做无限外推 | 讨论部分 |
| 后续工作 | 下一步做什么 | 先答最直接的延伸，再说数据与资源上的限制 | 结论与展望部分 |

每条预案还要写一行**"不要说的"**：不要在证据不足时把相关说成因果；不要承诺尚未开展的工作；不要引用自己没读过的文献。

### 第 8 步：交付三件套

1. **幻灯片规格**——可直接喂给本仓库 `teaching-slide-builder` 技能的生成器与审查器（那边已内置纯标准库 PPTX 生成器与教学规范 lint），字段结构沿用那套 spec；内容口径见 `teaching-slide-designer`。
2. **逐页讲稿**——每页写清"这一页要观众接受什么 + 口述内容 + 时间预算"，而不是把幻灯片上的字再抄一遍。
3. **问答预案**——六类方向各两到三条，每条带论文依据位置与"不要说的"。

三件套缺一不可：只有幻灯片，现场讲不动；只有讲稿，听众看不见结构；没有预案，答辩会失控。

## 中国高校语境要点

- **答辩委员会的构成**：通常是校外学科专家 + 校内同行 + 导师，多人提问、逐条回应、允许追问。校外专家关注方法的普适性与工作量，同行关注创新点是否成立，导师关注答辩能否过关——三者的关注点要在问答预案里分别覆盖。
- **盲审与答辩的差别**：盲审看文本，评委只依据论文判断，没有现场追问缓冲；答辩给了口头解释与澄清的机会。因此**论文文本要自足**（不依赖现场补充才能读懂），而**汇报可以有节奏地省略**（现场能补）。
- **中文学术语境**：术语首次出现必须中英并列，避免同一概念在幻灯片、讲稿、答辩回答里用三种译法；能用中文解释的概念不必硬译。
- **基金项目的汇报逻辑**：基金汇报不是研究报告汇报，逻辑是"要解决什么 → 计划怎么做 → 做到哪一步 → 还需要什么支持"，经费与考核要点必须出现；这部分可参考 `project-brief-designer`。
- **存档要求**：课件通常要交研究生院或学院留存，交付物要含可编辑源与讲稿，讲稿还能作为过程性材料存档。
- **图表中的中文字体与字号**：正文字号不低于 18pt，坐标轴与图例字号不低于 14pt，投影环境下再放大；中文图表优先用黑体系字体，避免艺术字与细体。
- **单位与量纲**：所有数值必须带单位与量纲，坐标轴标注量纲，同一张图内不要混用不同量纲；换算过的要说明换算口径。
- **数据保密与未发表数据**：未发表数据、涉密项目数据、受伦理审查约束的数据，默认不整表展示；必要时用示意化、区间化或占比化方式呈现，并在讲稿里说明脱敏口径。涉及个人信息的原始数据一律不出现在汇报中。
- **页数与时长受控**：答辩与报告通常有明确的时长上限与问答时长，超时会被打断，被打断时听众往往只听到前三分之一。**必须先排完时间预算再排页序。**

## 易错点

- ❌ 按论文章节顺序排页 → ✅ 按"听众要接受的结论"排页；章节只提供素材，不提供顺序。
- ❌ 图表裸贴没有结论句 → ✅ 每张图配一句"图 N 显示 A，因此 B"，标题也改成断言句。
- ❌ 页数超时长 → ✅ 先按每分钟 0.8–1.2 页定上限，再用砍页优先级压回来。
- ❌ 方法讲太久 → ✅ 方法只讲影响可信度的设计选择，实现细节删掉或移入问答预案。
- ❌ 回避方法学质疑 → ✅ 方法页上明确写出局限与取舍，答辩时才不会被追问打穿。
- ❌ 用"研究表明"而不给具体文献 → ✅ 说清是谁、在什么工作里、用什么方法得到的；给不出就换成本文自己的数据。
- ❌ 直接贴论文里的图不重新标注来源 → ✅ 进入汇报的图表要重标坐标轴与图例、在页脚标注论文出处与改绘说明。
- ❌ 结论页写成"结果与讨论" → ✅ 收束页用三句话：做了什么 / 发现了什么 / 意味着什么。
- ❌ 问答预案只写套话 → ✅ 每条预案写明论文依据在哪一节，并列一行"不要说的"。
- ❌ 把未发表或涉密数据随意展示 → ✅ 默认脱敏、区间化、示意化，讲稿里写清口径。
- ❌ 致谢页浪费黄金时间 → ✅ 致谢念出来或压进最后一页页脚，把时间留给结论页。
- ❌ 页标题沿用论文章节名 → ✅ 标题是听众该记住的那句话，不是目录项。
- ❌ 通篇"本文提出""我们发现" → ✅ 汇报是对听众说话，写成"该设计把误差的主要来源从 X 换成了 Y"。

## 自检清单

- [ ] 一句话主张已抽出，且能在三句话内复述
- [ ] 主张确实来自摘要或结论，不是汇报时新造的
- [ ] 听众构成与时长已确定，问答时间已预留
- [ ] 每页都有断言式标题，没有沿用论文章节名
- [ ] 每页对应一个听众该接受的结论，不是论文一个小节
- [ ] 证据页全部配有结论句，没有裸贴的图表
- [ ] 所有图表的坐标轴、图例、单位与量纲已核对
- [ ] 每张图都在页脚标了论文出处与改绘说明
- [ ] 全文没有编造的文献、数据或结论
- [ ] 方法页写明了局限与设计取舍
- [ ] 每页有时间预算，全篇合计落在时长内
- [ ] 砍页预案已按优先级排好，并标注了核心证据页不可砍
- [ ] 结论页是三句话结构（做了什么 / 发现了什么 / 意味着什么）
- [ ] 致谢不单独占页
- [ ] 问答预案覆盖六类方向，每条有论文依据位置与"不要说的"
- [ ] 未发表或涉密数据已按脱敏口径处理
- [ ] 术语首次出现中英并列，全篇同一概念只用一种译法
- [ ] 三件套齐备：幻灯片规格 + 逐页讲稿 + 问答预案

## 方法论依据

- **技术报告与学术报告的"结论先行"式信息组织**：先给结论与关键证据，再给支撑与限定条件；听众中途离场或被打断时，已经听到的仍然是完整的核心。这支撑"主张页在最前、证据页配结论句、背景页可砍"的排布。
- **认知负荷理论（Sweller 的认知负荷理论）**：听众的工作记忆容量有限，同时呈现的图表与论点越多，理解越浅。据此限制一页一个结论、限制图表页的要点条数，并把推导过程移入口述。
- **Mayer 的多媒体学习原则**：信号词原则（结论句与断言式标题突出关键信息）、空间邻近原则（图与它的结论句必须同页相邻）、冗余原则（幻灯片不重复讲稿里的话）。据此禁止裸贴图表与逐页朗读式排版。
- **答辩的问答结构**：答辩是以"预设质疑 + 现场辩护"为核心环节的交流形式，提问方向高度集中于方法有效性、样本代表性、指标定义、因果推断、可推广性与后续工作。据此把问答预案作为正式交付物而非临场发挥。
