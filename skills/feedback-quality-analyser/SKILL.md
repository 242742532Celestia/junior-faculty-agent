# 反馈质量诊断与评语句式改造

## 这个技能解决什么

批改卷子花了两小时，评语只剩三类：

> "不错，继续努力。"　"第 3 题错了。"　"本次不及格。"

学生拿到手不知道该改哪一句、下一份作业该怎么写。这类反馈的共同毛病不是"不认真"，
而是**结构上缺了信息**：没有目标参照、没有进展、没有差距的定位、没有下一步动作。

另一些看起来认真、实际无效的版本：

- 一段评语里塞了 8 个问题："符号不规范、思路不清、计算粗心、结论不完整、格式不对、
  引用不规范、图画得丑、字数偏少"——学生不知道先改哪个，多数人一个也不改；
- "你思维太粗糙""态度不端正"——评价的是人，学生无法据以行动，还可能记恨；
- 论文改了五轮，每轮只说"再深一点"——没有参照系，"深"永远达不到；
- 反馈两周后才发，学生已经忘了当时怎么写的，修改窗口关闭；
- 只标红不标黄：红是错、黄是"看着别扭但说不清哪里别扭"——后者反而更消耗人。

反馈研究里最有用的那个框架来自 Hattie 与 Timperley：高质量反馈要回答四个问题——
**我要去哪（目标）、我现在到哪了（进展）、差在哪（差距）、下一步往哪走（动作）**。
四格缺一，句子就漏；四格齐全，学生才知道明天动哪里。

## 什么时候用 / 什么时候不用

**用**：

- 批改完作业/实验报告/论文后，需要把评语改写得更有用
- 一次批改后发现学生改不动，要复盘反馈本身有没有给动作
- 设计课堂反馈话术、期中反馈、答辩后反馈
- 建立"常见问题库"，让反馈可复用、可沉淀
- 培训新教师或助教统一评语口径
- 把零散的课堂点评变成可统计、可改进的数据

**不用**：

- 纯分数与等级评定（那是评分量规的事，本技能只管评语与反馈动作）
- 事实性勘误（错别字、公式誊写错误这类，直接改）
- 学术不端认定（需按学校程序走，不能用反馈评语替代程序）
- 给学生看分数排名或与他人比较（不在本技能范围）
- 面向公众的宣传文案、课程介绍

## 输入

**必填**（缺项先出草稿，把缺口写进核验清单）：

1. 被评价的学生作品（作业、答卷、报告、代码、实验记录）
2. 该作品对应的评分标准或量规（没有量规就先用课程目标倒推一条）
3. 这次反馈要解决的主要问题（可只选 1–2 个）
4. 学习者层次（大一／大三／研究生）与班级规模

**选填**（用户没给就留空，**不许编**）：

5. 反馈用途（课堂即席、课后书面、期中报告、答辩后）
6. 提交与反馈的时序安排
7. 是否引入同伴互评与学生自评
8. 学期总评的考核构成与权重
9. 教材版本与 ISBN
10. 毕业要求指标点编号

## 执行步骤

1. **先立参照系。**
   把评分标准摊开，逐条对照作品。反馈说不出"好在哪、差在哪"，往往不是教师不认真，
   而是课程根本没有可对照的判据。标准缺失时先补一条最粗的判据（如"步骤是否可复现"）。

2. **在作品上取证。**
   反馈必须指向作品中**看得见的位置**（第几页第几行、哪一步、哪一栏）。
   凭印象写评语是无效反馈的起点：学生无法核对你说的对不对，也就无法改。

3. **定层级：这次反馈打哪一层。**
   反馈有三个可用层级，同一件作品可以分别打：

   - 任务层：这题的答案对不对、结论是否成立；
   - 过程层：思路、步骤、策略、依据选择是否站得住；
   - 自我调节层：计划、监控、修订、求助行为是否到位。

   另有一层**不要用**：评价学生个人特质（聪明、懒、没天赋）——它不可改变，也不可据以行动。
   一次反馈只设一个主层级，其余层级放进问题库。

4. **按四问填空。**
   对每一条反馈逐格填：

   | 要素 | 要写什么 | 写不出时的诊断 |
   |---|---|---|
   | 目标 | 学生被要求做到什么（可观察） | 目标没传达到，先补目标 |
   | 进展 | 作品中已经做到的具体点 | 只说"不错"而不说哪里不错，缺进展 |
   | 差距 | 差距在哪个位置、差在哪个判据上 | 只说"错"而不定位，缺差距 |
   | 动作 | 学生下一次具体要做的那个动作 | 缺动作 = 学生无从下手 |

   四格全空或只填一格，就是无效评语，必须重写。

5. **写句式。**
   用三段式，控制在三句以内：
   **做对的具体处（带位置）→ 差距的具体位置与判据 → 一个可执行的下一步动作。**
   主语必须是作品或行为（"第 2 段的数据处理"），不是人（"你"）。
   动作要小到一节课内能做完："在第 3 段前加一句说明为什么用平滑而不是均值"，
   而不是"加深理解""提高水平"。

6. **自检可执行性。**
   问一句：学生看完这句，明天能不能自己动手改？如果不知道改哪一行，就是无效反馈。
   动作要可检查：改完能说清"我改了什么、为什么"，而不是"我懂了"。

7. **排时序与渠道。**
   顺序是：**学生自评 → 同伴互评 → 教师反馈**。学生先自评，反馈才有对照，
   才可能产生"我以为对的地方其实错了"的校准；教师反馈放在最后，权威性和精度最高。
   提交后 72 小时内给出去，越晚越无效。

8. **沉淀问题库并回流教学。**
   把本批高频错误按类型归档，形成可复用句式；同时统计"哪类错误反复出现"，
   这类错误多数不是学生问题，而是教学环节没讲透或练习设计缺失——把它写进下次改进清单。

9. **标注假设与待补充。**
   凡是"学生读不懂术语""学生没有背景知识"这类推断标「假设」；
   权重、ISBN、指标点编号等由课程方提供的标「待补充」。

## 中国高校语境要点

- **学时制**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟，中间不宜超过 15 分钟连续讲授。
  课堂反馈按 3–8 分钟一段设计：一次错误暴露、一次同伴互评、一次全班点评，
  每段都要落到一个具体动作上，不要变成"大家一起讨论下"。
- **评价制度**：反馈主要属于形成性评价（课堂提问、同伴互评、随堂小测、阶段报告），
  终结性考核给出的是分数与等级；分数本身不构成反馈，
  期末评语仍应包含一条最关键的差距和一个可迁移的动作。
- **考核权重**：若把自评、互评纳入平时成绩，各项**加总恰好 100%**，不要凑整，
  临时加项必须同步改权重表。
- **毕业要求支撑**：反馈可以服务于课程目标的达成证据，
  毕业要求指标点编号由院系给定，**用户没给就留空**，不要自己编"毕业要求 3.2"。
- **课程思政**：把职业规范写进反馈的具体要求里（数据来源要注明、引用要规范、
  不得篡改实验记录），学生照着做；不要写成"要树立严谨求实的态度"这类贴在评语末尾的话。
- **教材与评分细则**：教材版本与 ISBN 必须真实且与课程内容对应，查不到写「待补充」；
  反馈引用的判据要与大纲公布的评分细则一致，改细则要提前公布，不能在批改时临时加标准。
- **学术诚信**：批改前先分清"不会"与"不是自己写的"。反馈只陈述可核实的事实与差距，
  诚信问题按学校程序另行走，不在评语里定性。
- **大班现实**：上百人的大班无法逐份写评语。改用"错误类型—句式模板—全班点评"：
  统计本班前三类高频错误，课上集中点评，个别问题约谈，一个学期积累下来就是一份班级学习画像。

## 易错点

- ❌ "写得不错，继续努力" → ✅ 三段式：做对的具体处（带位置）→ 差距的具体位置与判据 → 一个可执行动作
- ❌ 只给分数和等级 → ✅ 等级之外补一条最关键的差距 + 一个能带走的动作
- ❌ 一次反馈覆盖 8 个维度 → ✅ 一次只给 1–2 个维度，其余进常见问题库
- ❌ "你不够认真""你思维太粗糙" → ✅ 指向作品里的可观察行为（第几步、哪一行、什么特征）
- ❌ 评价人的能力或态度 → ✅ 评价作品与过程；个人特质层反馈出现即删
- ❌ 提交两周后才给反馈 → ✅ 同一批次 72 小时内给，修改窗口越短越有效
- ❌ 只有教师一个反馈来源 → ✅ 学生先自评、再同伴互评，教师反馈放最后
- ❌ 把"抄"当成"不会"来写评语 → ✅ 反馈前先分清错误类型，诚信问题另走程序
- ❌ 编造教材 ISBN、权重或毕业要求编号 → ✅ 查不到写「待补充」并进核验清单

## 自检清单

- [ ] 每条反馈的四要素都填了，缺的格已标出
- [ ] 每条反馈都能在作品中指出具体位置
- [ ] 一次反馈只针对 1–2 个维度，其余已归档到问题库
- [ ] 没有个人特质层评价（聪明/懒/态度差一类）
- [ ] 每个差距都对应到评分标准里的某一条判据
- [ ] 每个动作具体到一节课内能完成、能被检查
- [ ] 顺序是自评 → 互评 → 教师反馈
- [ ] 反馈在提交后 72 小时内给出
- [ ] 负向反馈里也给出了做对的具体点
- [ ] 高频错误已统计，并已写出教学侧对策
- [ ] 涉及平时成绩时，权重分配加总 = 100%
- [ ] 教材 ISBN、权重、毕业要求编号等事实项：真实或已列入待补充，无编造
- [ ] 假设与待确认项已单列

## 交叉技能

- 反馈落在课堂哪个环节、怎么闭环 → `formative-assessment-loop-designer`
- 课堂反馈用什么形式（小测、投票、举牌）→ `formative-assessment-technique-selector`
- 评分量规与反馈条目对齐 → `criterion-referenced-rubric-generator`、`single-point-rubric-designer`
- 从学生作品里找差距证据 → `gap-analysis-from-student-work`
- 错误分类与归因 → `error-analysis-protocol`
- 让学生能读懂并使用反馈 → `teach-back-evaluator`
- 学生自我监控脚手架 → `self-regulation-scaffold-generator`
- 学期考核方案整体设计 → `assessment-design-orchestrator`、`assessment-validity-checker`
