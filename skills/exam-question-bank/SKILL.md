# 课程考核命题与题库

## 这个技能解决什么

命题不是"找几道题凑一张卷"。命题要保证：
**这张卷能测出课程目标，且难度分布合理、覆盖完整、评分可执行。**

本技能处理**命题的设计与生成**，具体知识点的考察角度依赖上游技能的
（`backwards-design-unit-planner` 的课程目标与考核证据对齐、
`criterion-referenced-rubric-generator` 的评分标准）。

## 先确认（缺了就问）

1. **课程与章节范围** —— 考哪几章。
2. **考核形式** —— 闭卷 / 开卷 / 笔试 / 机考 / 论文 / 答辩 / 综合考核。
3. **考试时长与总分** —— 如 120 分钟、100 分。
4. **题型约束** —— 有些课程有强制题型要求（必须有论述题、必须有实验题等）。
5. **课程目标清单** —— 从 `backwards-design-unit-planner` 或用户提供。
   **没有目标清单就没有命题依据**，此时应先回退到目标澄清，而不是凭章节标题猜重点。

## 命题工作流

### 第 1 步：建立「目标—题型—认知层次」映射表（**先做这个**）

| 课程目标 | 对应题型 | 认知层次 | 分值 | 题量 |
|---|---|---|---|---|
| 目标1：理解 X 的机理 | 选择题 / 简答 | 理解 | 20 | 4 |
| 目标2：运用 X 分析 Y | 计算题 / 应用题 | 应用 | 35 | 3 |
| 目标3：设计 Z 方案 | 论述题 / 设计题 | 创造 | 35 | 2 |
| 目标4：评价方案的优劣 | 综合题 | 评价 | 10 | 1 |

**分值合计必须 = 满分。** 这一步做完后才能动笔出题。
出完题回来核一遍：**每个目标都要有题覆盖，不能有题不对应任何目标。**

### 第 2 步：难度分布与认知层次分布

高校课程常见参考（**按课程性质调整**，不要照抄）：

| 课程性质 | 容易 | 中等 | 困难 |
|---|---|---|---|
| 通识/基础课 | 30% | 50% | 20% |
| 专业基础课 | 20% | 55% | 25% |
| 专业核心课 | 15% | 50% | 35% |
| 研究生课/研讨课 | 10% | 45% | 45% |

认知层次参考（借用 Bloom 修订版）：
**记忆 20% / 理解 30% / 应用 30% / 分析 15% / 评价创造 5%**（可按课程目标调整）。

> **难度是命题者对"及格线"的判断**，不是题目算出来的数值。
> 写"难度：中等"是教师判断题目的常规标注方式，不要假装有量化难度系数。

### 第 3 步：出题

**通用规则**
- 每道题标注：题号、分值、**对应目标**、认知层次、难度、建议用时。
- **题干干净**：不含多余信息、不含暗示答案的措辞、不用"以下哪个不是"这类易混句式除非刻意。
- **数据真实**：题中数值必须自洽（这正是能力矩阵里最容易翻车的地方）。
  若题目依赖真实数据（如"某地 2024 年发病率为 X"），**X 必须是可核实的真实值**；
  查不到就用「设定情景」明确标注为假设数据，不能伪装成真实统计数字。

**分题型要点**

| 题型 | 要点 |
|---|---|
| 单选题 | 干扰项必须是"学生会犯的典型错误"，不是明显荒谬项；只有 1 个正确答案 |
| 多选题 | 明确"多选，少选得 1 分、多选或错选不得分"之类的计分规则 |
| 判断题 | 避免绝对化表述；对错各半 |
| 填空题 | 关键词唯一；问法明确「填『术语』」而非「填空」 |
| 简答题 | 采分点写清楚（"答出 3 点得 6 分，每点 2 分"） |
| 计算题 | **必须给出完整推导过程的评分细则**，不只给答案 |
| 论述题 | 分档给分（优/良/中/及格），每档写明**行为特征**，不是形容词 |
| 设计题/综合题 | 给出约束条件、评分维度（用 `criterion-referenced-rubric-generator`）、示例答案要点 |

### 第 4 步：答案与评分细则

**每道题都要有**，这是硬要求：
- **参考答案**（要点式，不要写成整段范文）
- **评分细则**（分点、分值、扣分规则）
- **常见错误**（可选但推荐，用于讲评）

> ⚠️ 论述题/设计题给"唯一范文答案是错的"——给**评分维度 + 样例**，
> 允许其他合理答案。这是命题质量的标志。

### 第 5 步：A/B 卷与题库

- **等价卷**：A/B 卷**考点相同、题型相同、难度相同**，只是具体题目与数据不同。
  ⚠️ "相同"是**统计意义上的**（覆盖同一批目标、同层次、同难度），不是同一道题换数字。
- **题库**：按目标编号归档，标注每题的目标/层次/难度/用时，
  形成**题库覆盖矩阵**——用来看哪个目标题量过多、哪个目标没题。
- **备用卷**：留一套题，避免考试泄题后无卷可用。

## 输出格式

```
一、命题设计说明（目标—题型—层次映射表 + 难度/层次分布 + 分值核对）
二、试题（A 卷）
   每题：题干 / 分值 / 目标 / 层次 / 难度 / 建议用时
三、答案与评分细则（逐题）
四、备用卷 B（同结构）
五、题库覆盖矩阵（目标 × 题量 × 难度 × 层次）
六、需人工核验清单（引用的真实数据、需教师确认的评分尺度）
```

## 交付前自检（逐条打勾）

| 检查项 | 判定 |
|---|---|
| 每个课程目标都有题覆盖，无目标落空 | ☐ |
| 没有题目不对应任何课程目标 | ☐ |
| 各题分值合计 == 满分 | ☐ |
| 难度分布与层次分布符合课程性质 | ☐ |
| 每题都有答案与评分细则 | ☐ |
| 选择题干扰项对应典型错误，且答案唯一 | ☐ |
| 题中数据自洽；引用的真实数据已核实或标注为假设 | ☐ |
| 论述题给的是评分维度而非唯一范文 | ☐ |
| A/B 卷考点、层次、难度等价 | ☐ |
| 题库覆盖矩阵已产出 | ☐ |

## 纪律

- **不编造真实统计数据**（发病率、市场规模、文献结论）——查不到就标「假设数据」或「待补充」。
- **不低估难度自欺**：写"较易"但学生根本做不到，是命题质量事故。
- **不追求刁钻**。高校命题的判据是**测得出目标**，不是**区分度最大化**。

## 交叉技能

- 目标与考核对齐 → `backwards-design-unit-planner`、`learning-target-authoring-guide`
- 评分量规 → `criterion-referenced-rubric-generator`、`single-point-rubric-designer`
- 考核效度 → `assessment-validity-checker`
- 认知负荷与题目梯度 → `cognitive-load-analyser`、`practice-problem-sequence-designer`
- 错误类型分布 → `error-analysis-protocol`

## 高校语境适配（必读 · 本 Agent 追加）

本技能上游为英式 K-12 语境。执行前**必须**先读 `references/he-context-adapter.md`
（路径相对于 Agent 根目录），
按其中的映射表把学段、课时、评价制度换算成中国高校口径。

三条硬性要求：

1. **输入里的 `Year N` / `KS3` 等一律先映射**再执行：Year 7–9 → 本科大一，
   Year 10–11 → 本科大二，Year 12–13 → 本科三四年级。
2. **产出正文用中文**，专业术语首次出现时中英并列（形成性评价 / formative assessment）。
3. **不得编造** ISBN、学分号、毕业要求编号、参考文献、政策文件号。查不到就写「待补充」。

上游示例中的具体学科内容只作方法演示，**主产出必须是用户自己的课程内容**。
课程思政、毕业要求支撑、考核方式百分比构成等中国高校特有维度，
按适配表第五节补齐并标注为高校语境补充项。
