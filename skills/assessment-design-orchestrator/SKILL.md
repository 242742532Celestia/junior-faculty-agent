# 考核方案编排与效度审查

## 这个技能解决什么

一门课有四次小测、一次大作业、一次期末笔试，权重写在教学大纲里，
但没人说得清"这门课的及格线到底证明了学生什么"。具体长这样：

- 课程目标写了 10 条，期末卷只碰到 4 条，另外 6 条全课没有任何证据；
- 大作业占 30%，但没有评分量规，阅卷人凭印象给分，学生无法申诉；
- 卷面 20 道题里 14 道是客观题，与"能评价、能设计"这类高阶目标毫无关系；
- 权重写的是平时 30% + 大作业 30% + 期末 50% = 110%，公布后被学生当场问住。

"考过了"不等于"测到了"，"分数高"也不等于"能力被评准了"。

考核编排不是排一张时间表，而是把"这门课要证明什么"翻译成一组
**可评分、可追溯、权重闭合**的考核项，并且能对每一个考核项回答：
"它测的是哪条目标？凭什么说这次评分是有效的？"

## 什么时候用 / 什么时候不用

**用**：
- 新开课或首次制定考核方案，需要一份能直接提交、可归档的考核方案表
- 现有考核"分数拉不开差距"：题目都做对了，但学生之间的能力差异看不出来
- 大作业 / 课程论文占比高，需要补评分量规、阅卷口径与申诉说法
- 教学督导检查、专业认证材料、评估整改要求出具"考核有效性证据"

**不用**：
- 只想出一套题（用 `exam-question-bank`）
- 只想设计一个章节的单元考核（用 `backwards-design-unit-planner`）
- 单次课堂小测的即时反馈闭环（用 `formative-assessment-loop-designer`）
- 学生个人学习计划或复习安排

## 输入

**必填**（缺任何一项就停下来问，或先出草稿并把假设标出来）：
1. 课程名称、课程代码、学分、总学时
2. 课程目标清单（学习成果陈述）；没有就请对方提供，或从现有大纲抽取并标注「待确认」
3. 课程在培养方案中的性质（专业核心课 / 必修 / 选修 / 实践环节）
4. 学生层次与班级规模（大一…；班均人数、是否分组）
5. 院系已有的考核规定（如"实践课单列""过程性考核占比下限""补考规则"）

**选填**（用户没给就留空并列入"待补充清单"，**不许编**）：
6. 现有考核方案与权重（用于整改，而不是从零设计）
7. 成绩口径（百分制还是等级制、是否按绩点换算）
8. 毕业要求指标点编号（**院系给定；没给就留空**，绝不自行编写）
9. 教材版本与 ISBN（查不到写「待补充」）
10. 是否分组、是否允许跨班组队、可用机房与实验条件
11. 补考 / 重修 / 缓考规则

## 执行步骤

1. **先把目标写成可判定的形式。**
   目标里出现"理解 / 掌握 / 熟悉 / 了解"时，先改写成可观察动词；
   改不动的（例如"了解本学科发展脉络"）标记为「内容性描述，不作为考核依据」。
   判定标准是：每条目标都要能回答"拿哪份证据、凭什么算达成"。

2. **给目标定考核覆盖等级。**
   **核心目标**：本轮必须考，设定权重下限（自定，建议不低于 15%）；
   **支撑目标**：可由其他课程或本课其他考核项支撑，本轮可不单独考；
   **暂不考**：本轮不考，必须写明理由与后续安排（哪学期、由谁补）。
   这一步治的是"把所有目标都塞进卷子"和"目标写了但没人管"。

3. **把目标分配到考核项，画出考核蓝图。**
   每个考核项必须写清：名称、形式、施测时间、时长、评分主体（个人 / 小组 / 机评 / 互评）、
   评分依据（量规 / 标准答案 / 阅卷细则）、对应目标、承载分值、权重。
   蓝图是"目标 × 考核项"的矩阵，空白格即"该目标在这项考核里没有证据"。

4. **三层权重闭合校验（写算式，不写"大致平衡"）。**
   - 第一层：各考核项权重合计 = 100%；
   - 第二层：每条核心目标被分配的权重 ≥ 你设定的下限；
   - 第三层：每个考核项至少服务一条目标（禁止"孤儿考核项"），每条目标至少落在 1 个考核项上。
   任一层不过，就地改表，不要靠文字说明掩盖。

5. **逐项过效度威胁清单**（本技能的核心步骤，不可跳过）。对每个考核项检查五类威胁：
   **构念代表不足**（目标只被考了其中一个片段，例如"能评价方案"只考成选择题）、
   **构念无关变异**（与目标无关的因素主导了得分：超纲记忆、限时压力、无关写作训练）、
   **评分者不一致**（无评分依据、无双评、无抽检）、
   **推测性构念**（用一次成绩推断稳定能力）、
   **分数误用**（及格线、绩点、评优、保研资格直接挂钩）。

6. **把威胁转成修补动作。**
   每条威胁必须落一条具体动作 + 责任人 + 是否改变权重或评分方式；
   改不动的写成「残余风险」并给出接受理由，不允许只写"继续改进"。

7. **补程序性材料与待补充清单。**
   成绩构成口径、补考与重修口径、查卷与申诉口径、阅卷培训安排；
   凡未由用户或院系提供的事实项（指标点编号、ISBN、学院规定比例）一律进"待补充清单"，
   写明用途与建议确认方。

## 中国高校语境要点

- **学时制**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。考试时长与学时不是一回事，
  笔试通常 90 或 120 分钟，须与学院规定一致；规定未提供时写「待确认」，不要自行假定。
- **权重**：平时 / 大作业 / 期末各项加总**恰好 100%**。过程性考核占比偏高时，
  必须写清评分点、评分主体与公示方式，否则学生无法申诉。
- **评价制度**：形成性评价（课堂提问、随堂小测、discussion、同伴互评）与终结性考核分栏列出。
  形成性条目要注明"是否计入总评、计入多少、谁记录"，不要既算过程分又不给标准。
- **毕业要求支撑**：指标点编号**由院系与专业认证材料给定**；用户没给就留空并标「待补充」，
  不得自造"毕业要求 3.2"之类编号。
- **课程思政**：若考核方案里有思政融入的考核点，写明它考在哪个考核项的哪个**可观察行为**上
  （如"小组答辩中说明方案的公共安全取舍"），不要写"提升家国情怀"这类不可评分的表述。
- **教材与参考书**：ISBN 必须真实并与考核范围对应，查不到写「待补充」。
- **实践环节**：实验 / 实践课单独列为考核项，注明学时数、分组方式与占比。
- **学术诚信**：方案中写明查重方式、允许的协作范围、代码与数据引用规范。

## 易错点

- ❌ 目标写"理解 / 掌握"就直接拿去命题 → ✅ 先改写成可判定形式，改不了的标为内容性描述，不作考核依据
- ❌ 每条目标都塞进卷子 → ✅ 分核心 / 支撑 / 暂不考三档，"暂不考"要写理由
- ❌ 权重写成 30% + 70% + 20% → ✅ 写出算式并校验到 100%，三个层次都过一遍
- ❌ 只画蓝图不判断覆盖 → ✅ 蓝图里出现 0% 的目标行就是警报，必须处理
- ❌ 用"难易适中"当效度论证 → ✅ 效度看构念代表性与无关变异，不看难度
- ❌ 大作业没有量规 → ✅ 无评分依据的评分项一律标「评分依据缺失」，列为高风险
- ❌ 把"考过了"当"测到了" → ✅ 每个考核项都要能反查它对应哪条目标
- ❌ 编造毕业要求编号、ISBN、学院规定比例 → ✅ 留空并进待补充清单
- ❌ 把及格线当成效度保障 → ✅ 及格线属于分数误用，需单独写处理方案

## 自检清单

- [ ] 每条课程目标都可判定，能回答"拿什么证据算达成"
- [ ] 每条目标标了考核覆盖等级，"暂不考"有理由
- [ ] 蓝图矩阵填满，或 0% 处有明确处理说明
- [ ] 考核项权重合计 = 100%，算式写出来了
- [ ] 每条核心目标的权重达到设定下限
- [ ] 没有孤儿考核项
- [ ] 每个考核项都写了评分依据与评分主体
- [ ] 效度威胁清单逐项过了，每条有修补动作或残余风险
- [ ] 评分等级可观察性判据已填
- [ ] 形成性与终结性分开列出，过程分的计入口径明确
- [ ] 毕业要求编号 / ISBN / 学院规定：无编造，缺失项已进待补充清单
- [ ] 假设与待确认项已单列并标「待补充」

- 单元级目标—证据对齐 → `backwards-design-unit-planner`

- 单一整体等级量规 → `single-point-rubric-designer`

- 试题与目标匹配 → `exam-question-bank`
- 形成性评价闭环 → `formative-assessment-loop-designer`
