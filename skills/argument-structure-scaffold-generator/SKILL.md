# 论证结构脚手架生成器

## 这个技能解决什么

学生的综述写成了"摘要串烧"：每段开头一句"某某认为……"，通篇找不到一句作者自己的判断句，读者读完也不知道论文到底主张了什么。

文献摆在正文里却像挂件：把参考文献删掉，论证照样"成立"，因为论点从来没有真的靠证据承重。

推理被跳过了：从"某研究发现 X"直接跳到"所以本文主张 Y"，中间的推理环节只存在于作者心里，读者补不上。

结论和开头不呼应：引言提出的问题有三个，结论只回答了其中一个，而且换了说法。

教师批注写"论点不清""论据不足"，学生不知道下一稿该改哪里——评语指向的是人格缺陷，而不是可执行的动作。

这个技能把这些失败场景转成一张可以逐格填写的骨架表：每个论证单元回答一个问题、压成一句可证伪的主张、配上可定位的依据、把推理写成句子、补上限定语、交代反例。

## 什么时候用

**用**：

- 学生要写课程论文、文献综述、开题报告、毕业论文的某个章节，需要一份能照着填的结构。
- 学生已有草稿，但通篇是资料搬运，教师需要一份"逐单元体检表"来给出可执行反馈。
- 教师要设计论证写作的课堂练习或过程性考核（骨架表本身就是过程稿，可直接评）。
- 学生答辩前自查：主张是否可证伪、依据是否可追溯、结论是否回扣问题。

**不用**：

- 只是要一段通顺的引言或摘要——那是文字润色，不是结构问题，用 `feedback-quality-analyser` 更合适。
- 纯粹的文献检索与获取——先用 `citation-audit` / `literature-review` 把材料找齐，本技能管的是找齐之后的组织。
- 选题本身还没定下来（题目过大、对象不清）——先做选题压缩或课题立项，不进入骨架填表。
- 学生需要的是背诵知识点或计算训练——与论证结构无关。

## 输入

**必填**：

1. 写作任务与体裁：课程论文 / 文献综述 / 开题报告 / 学位论文章节 / 答辩陈述稿。缺省按"课程论文"处理，并在输出中标注该缺省。
2. 题目或研究问题原文（学生尚未确定时填"待学生填写"，同时给出格式要求：一句话、不超过 30 字、含研究对象与研究关系）。
3. 学分与课时（决定模板深度与时间盒）。缺省按 2 学时（45×2 分钟）、终结性课程作业处理。
4. 已有材料清单：文献（题录 + 是否已读原文）、数据、导师或同伴批注、往届范文。没有材料时输出一份"空白骨架 + 检索任务单"。

**可选**：

5. 目标评分量规或优秀样例（提供时据其反推结构权重，不提供时用默认五段骨架）。
6. 学生人数、是否分组（决定骨架表是个人作业还是同伴互评对象）。
7. 学校关于 AI 辅助写作的规定。缺省按"允许辅助检索与语言润色、禁止由 AI 生成正文论证段落"处理，并在输出中显著标注这是待确认假设。
8. 引用格式要求（缺省按 GB/T 7714—2015 处理）。

## 执行步骤

1. **把题目压成可证伪的问句。** 写下来："如果出现什么证据，我就得放弃这个主张？"写不出来，说明题目还不可研究，先做拆分或换题，不进入后续步骤。
2. **切出论证单元。** 每个单元只回答一个问题，单元数控制在 3–9 个；超过 9 个说明主题发散，先合并。
3. **先填两列草稿。** 只填"本单元回答的问题"和"主张"，每个主张压到一句话且能被证伪；此时不写依据、不写正文。这个顺序是为了避免学生一开始就查资料、最后写成串烧。
4. **补三列：依据、推理链、限定条件。** 依据必须能定位到具体位置（页码、表号、章节或数据源链接）；二手综述不得单独支撑一个关键主张。
5. **核验依据，标红退不回去。** 逐条打开原始来源核对；查不到的直接标为"待检索"并列入检索任务单，不允许留在正文里当依据。这一步最容易漏，漏了整张表就是假骨架。
6. **做八项健康度自评并给出动作。** 每项未达标必须对应一条具体改法，不接受"加强论证""注意逻辑"这类无动作评语。
7. **产出三件交付物**：骨架表（学生填、教师批注）、手术式改写清单（针对最弱的两个单元）、限时修改计划（见输出模板的时间盒）。

## 输出模板

### 模板 A｜论证骨架表（主表，学生填，教师批注在最后一列）

| 单元号 | 本单元回答的问题 | 主张（1 句，可证伪） | 依据（类型·数量·出处定位） | 推理链（写成完整一句） | 限定条件 | 主要反例及处置 | 与前一单元的衔接 |
|---|---|---|---|---|---|---|---|
| U1 | | | | | | | — |
| U2 | | | | | | | |
| U3 | | | | | | | |

填表硬约束：

- 主张必须能被证伪：每个主张下面要能写出"什么情况算被推翻"。写不出就改成描述性句子或删掉。
- 依据类型须标明：原始数据 / 元分析 / 经典理论 / 权威教科书 / 二手综述 / 单案例 / 访谈材料 / 个人经验。其中"二手综述"和"个人经验"不得作为关键主张的唯一支撑。
- 关键主张至少 2 条相互独立的依据，其中至少 1 条是原始研究或权威综述。
- 推理链必须写成完整句子，形如"因为 X（依据），在条件 Y 下可得 Z，因此本文主张 M"。禁止只用一个"因此"跨接。
- 主张总数：短报告 3–5 个；长论文 6–9 个。

### 模板 B｜推理关系与连接词对照表（教师批改时对照）

| 关系类型 | 可用连接词 | 成立的前提 | 高频误用 |
|---|---|---|---|
| 充分 | 因此、由此可见、从而 | 依据为真，且推理步骤有效 | 用"因此"连接两件无关的事实 |
| 必要 | 只有……才、除非、必须 | 说清"不满足时会怎样" | 省略"如果不成立"的前件 |
| 类比 | 类似于、正如 | 两个对象的关键结构相同 | 只有表面相似就推同结论 |
| 因果 | 导致、使得、归因于 | 已排除共同原因 | 相关当因果 |
| 统计 | 表明、显著高于 | 报告了效应量与不确定性 | 只报 p 值、只报百分比 |
| 权衡 | 尽管如此、不过 | 前一句限定了后一句的适用范围 | 转折前后说的不是同一对象 |

### 模板 C｜限定语清单（四类，每类取 1 个）

| 类别 | 可选表述 |
|---|---|
| 强度 | 显著 / 大致 / 略微 / 在……范围内 |
| 范围 | 在本样本中 / 在本科 X 专业场景下 / 就本文所考察的 X 而言 |
| 条件 | 在 Y 成立的前提下 / 只要 X 不超过某阈值 |
| 时间 | 就 2023 年前的公开文献而言 / 截至 2026 年 3 月 |

### 模板 D｜论证健康度八项自评（教师与学生共用）

| # | 检查项 | 合格标志 | 未达标时的具体动作 |
|---|---|---|---|
| 1 | 主张可证伪 | 每个主张都能写出被推翻的条件 | 补写可证伪条件，否则降级为描述句 |
| 2 | 依据可追溯 | 每条依据能翻到具体页码/表号/数据源 | 退回检索任务单，正文暂缺该依据 |
| 3 | 推理显性 | 依据与主张之间有书面推理句 | 补写推理句，删掉裸"因此" |
| 4 | 依据够强 | 关键主张 ≥2 条独立依据 | 补检索或把主张强度下调一级 |
| 5 | 限定到位 | 每个主张都写了适用范围 | 从模板 C 补限定语 |
| 6 | 反证有交代 | 每个主要反例有回应或明确承认限制 | 补"回应"小段，放在对应单元之后 |
| 7 | 回扣问题 | 结论回答了引言提出的全部问题 | 重写结论，逐条对应引言问题 |
| 8 | 证据独立 | 关键依据之间无共同源头 | 追查到最初来源，替换二手转引 |

### 模板 E｜症状 → 手术式改写（发回学生时逐条对照）

| 症状 | 改写前 | 改写后 |
|---|---|---|
| 无主的综述 | "许多研究表明 A 与 B 有关。" | "X 等（2023，样本 1200，报告了效应量 r=.09）在本科场景下发现 A 与 B 弱相关；Y 等（2021）在大样本中未复现该关联，因此本文只把 A–B 视为待检验线索。" |
| 跳步推论 | "该方法在实践中效果良好，因此值得推广。" | "该方法在 3 项对照研究中均使处理时间缩短（平均 −18%），但 3 项研究来自同一团队、样本集中于同类人群，因此本文的推广结论限制在同质人群内。" |
| 结论换题 | "综上，本文认为该技术路线可行。" | "综上，本研究在样本 A 中支持假设 1，在样本 B 中只得到部分支持；二者差异可能来自工况差异，这一解释尚未被检验。" |

### 模板 F｜限时修改计划（按 45×2 学时拆分）

| 阶段 | 时长 | 只做什么 | 产出 |
|---|---|---|---|
| T0 骨架 | 25 分钟 | 填"问题"与"主张"两列 | 单元清单 + 主张初稿 |
| T1 核证 | 40 分钟 | 逐条打开原始来源核对定位 | 依据列 + 检索任务单 |
| T2 成链 | 30 分钟 | 写推理句、补限定语 | 模板 B、C 填充完成 |
| T3 自评 | 20 分钟 | 跑八项健康度自评 | 未达标项清单 |
| T4 改写 | 30 分钟 | 只改最弱的两个单元 | 改写前后对照 |

合计约 145 分钟。8000 字以上的论文，骨架阶段按总投入的 15% 预留。

## 中国高校语境要点

- **学时制**：完整流程建议占 2 学时（45×2）。若只有 1 学时，只做 T0 + T1，把 T2–T4 转为课后线上提交的过程稿。
- **评价制度**：骨架表是天然的过程性评价载体。建议过程性评价合计不低于 30%（如：课堂互评 10% + 骨架过程稿 15% + 修改说明 5%），终结性考核 50%–60%。所有权重须与课程大纲一致且合计 100%；若本校大纲另有规定，以大纲为准，本模板不改大纲。
- **毕业要求支撑**：每条主张标注其对应的毕业要求指标点**类别**（如"问题分析""工程与社会""沟通表达"），编号必须照抄本校毕业要求指标点原文，不得自行编号或简写。
- **课程思政**：在"权衡""反证""限定条件"三处自然融入价值讨论，例如"当效率与安全冲突时本文如何取舍及其理由"，写进论证本身而非另贴标签段。每份学生作业至少标注 1 个融入点，并写明融入方式（案例 / 问题导入 / 价值讨论）。
- **学术诚信与 AI**：AI 生成的综述段落不得作为依据；AI 只能用于检索线索与语言润色，须在文末声明使用环节。二手综述要追到原始研究再引用。参考文献著录按 GB/T 7714—2015；引用格式细则引用本课程或本学院现行规定，不自拟。
- **教材与参考书**：若提供论证写作范例章节作为模板附件，须给可核验的书目信息（有 ISBN 就写 ISBN，没有就写"待补充"并注明核验渠道），不得编造 ISBN。

## 易错点

- ❌ 把"学生写不出主张"当成语言问题去润色 → ✅ 先用模板 A 的"本单元回答的问题"列逼出一个可证伪主张，润色排在结构之后。
- ❌ 让学生一次性把整篇写完再检查结构 → ✅ 强制 T0 阶段只填两列，把结构决策与文字表达分开。
- ❌ 批注写"论据不足"就结束 → ✅ 用模板 D 第 4 项给出动作（补检索 / 下调主张强度），让学生知道下一步做什么。
- ❌ 允许"综合多篇文献的观点"充当一条依据 → ✅ 二手综述必须追到原始研究，否则只能作为线索，不能进入依据列。
- ❌ 把反例塞进"局限性"一段统一处理 → ✅ 反例按单元就地回应，或明确写"本文不处理，理由是 X"。
- ❌ 用"许多研究表明"保留模糊感 → ✅ 报告具体作者、年份、样本量与效应量；缺任一项就标"待检索"。
- ❌ 骨架表一次填到底不再回看 → ✅ 每完成两个单元回看一次前两列，确认单元之间没有重复作答。

## 自检清单

- [ ] 题目已压成可证伪的问句，并写出了"什么证据会推翻我"
- [ ] 论证单元数量在 3–9 之间，每个单元只回答一个问题
- [ ] 每个主张都是一句话，且能被证伪
- [ ] 每条依据都能定位到页码、表号、章节或数据源
- [ ] 关键主张都有 ≥2 条独立依据，来源不互相转引
- [ ] 每处依据与主张之间都写了完整推理句
- [ ] 每个主张都补了限定语（四类中至少一类）
- [ ] 每个主要反例有回应或明确的范围声明
- [ ] 结论逐条回扣了引言提出的问题
- [ ] 模板 D 八项自评已逐项判定，未达标项都配了具体动作
- [ ] 模板 E 至少处理了最弱的两个单元（改写前后对照可见）
- [ ] AI 使用情况已声明，且没有把 AI 生成段落当作依据
- [ ] 引用格式符合本课程或本学院规定

## 交叉技能

→ `competency-unpacker`（先把任务拆成能力点，再决定要论证哪些主张）
→ `citation-audit`（依据的著录格式与引用真实性核验）
→ `feedback-quality-analyser`（把教师批注改写成学生可执行的修改指令）
→ `coherent-rubric-logic-builder`（用评分标准反推结构权重与单元顺序）
→ `formative-assessment-loop-designer`（把骨架表设计成"提交—反馈—修改"的阶段循环）
→ `peer-review`（组织同伴按模板 D 互评，避免教师评语资源不足）
