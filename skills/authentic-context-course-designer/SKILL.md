# 真实情境驱动的课程与单元设计

## 这个技能解决什么

课程设计最常见的失败不是"没认真设计"，而是**情境化只做到第一页**：开头讲了一个真实案例，此后案例再没出现；中心任务退化成普通练习题；评价用的是另一套题。学生带走的是知识，不是用知识。

本技能用一条不变量串起全部产出：

**真实情境 → 表现性任务 → 学习活动 → 可观察证据 → 迁移**

链上任何一环断裂，设计就退回"讲过了"而非"会用了"。两条判据贯穿全文：

- **第 1 页之后就被丢弃的故事是装饰，不是情境。**
- **给一道普通练习题贴上个人名，不是真实问题。**

**学习契约句式**（写进任务书，让"学到什么"变成可验收的承诺）：

> 学生将**做 X**，以使**能力维度 Y** 通过**证据 Z** 变得可观察。

"理解""掌握""培养思维"不构成契约，必须换成可见动词：标注、建模、比较、论证、检验、修订、设计、决策、创作、呈现。

**情境必须贯穿三关**，缺一关即判失败：

1. 情境造出开头那个未解决的问题（不解决它，后续学什么都会被卡住）；
2. 学习者在中心任务里真的用到它（不是"有关联"，是要靠它把任务做出来）；
3. 评价回到同一情境，但换新案例或换条件（考的是能力，不是记住原文）。

## 什么时候用

用：

- 需要把一个"章节/单元"重构成情境驱动，而不是知识点罗列时；
- 教学设计文件、课程大纲、单元整体方案需要一条贯穿的真实案例链时；
- 评审中发现"案例只出现在开头"或"任务与情境无关"需要返工时；
- 应用型、师范型课程需要一份能对得起毕业要求指标点的任务书时。

**不用**：

- 纯理论讲授、概念定义与公式推导为主的章节（本技能会强行制造假情境）；
- 只需要一份知识点讲解提纲、复习提纲时；
- 只需要单次课堂活动设计、没有单元级贯通需求时（改用任务级设计工具）。

## 输入

**必填**（缺任一项时，先按合理默认起草，并在需人工核验清单中标注为假设）：

- 课程与单元主题；
- 学时（理论/实训分列）与班级规模；
- 学生层次与先修基础；
- 承载的真实情境来源（真实案例、数据、史料、现场问题等）；
- 评价制度（哪些进入计分、哪些只记不评）。

**选填**（**没给就留空进核验清单，不许编**）：

- 毕业要求指标点编号；
- 教材版本与 ISBN；
- 具体案例/数据来源与获取方式；
- 学院是否有指定思政融入点数量。

## 执行步骤

1. **锁定情境与未解决问题**：写清"真实世界里谁遇到了什么问题"，以及"不解决它，后面学什么都会被卡住"。一个情境只服务一个未解决问题，多了就散。
2. **写学习契约**：用「学生将做 X，以使能力维度 Y 通过证据 Z 变得可观察」句式把目标改写成可见动词。契约先写，任务后定。
3. **定表现性任务**：中心任务必须是情境内的一个真实产出（解释、模型、决策、文本、设计、演示之一），不是"做几道题"；任务跨多个课时完成。
4. **拆学习活动并选载体**：按载体决策表给每一段选形态，写清每段"改什么、看什么、看出什么"。
5. **配可观察证据**：每个活动都要有对应证据（作品、判读记录、对照表、修订稿、口头论证），证据与活动同源——**证据不能由一个没做过的活动产生**。
6. **设计迷思诊断**：诊断项的干扰项必须来自真实存在的迷思概念，并写明"反馈要教会什么"，不能只判对错。
7. **设计迁移任务**：回到同一情境但换新案例或换条件，并写明迁移失败说明哪条能力未建立。
8. **固化成功标准与脚手架**：明确什么叫"做成了"，在哪些点提供哪些支架，支架须在产出前撤除。
9. **对齐评价与合规**：核对各项权重合计恰好 100%；情境化任务若计入平时成绩，写进第一周公布的规则与申诉方式；指标点编号、ISBN 等外部事实一律留空待补。
10. **过一遍易错点与自检清单**，确认三关情境与不变量链完整。

**默认弧线**（2 学时连堂 90 分钟，默认 6–10 页；页数是建议，不是硬上限）：

情境与未解决问题 → 取证/观察 → 比较/分类/建模/细读 → 迷思诊断 → 主产出（解释/模型/决策/文本/设计/演示）→ 成功标准与脚手架 → 迁移到同情境的新案例 → 收束（固化方法 + 明确还 open 的问题）。

**载体决策表**：

| 载体 | 什么时候用 | 判据 | 不许变成什么 |
|---|---|---|---|
| 讲授呈现页 | 框定问题、承载材料/史料/数据、固化方法 | 必须承载材料或结论，不做教师连续讲授 | 一串教师独白页 |
| 任务/实验/研讨页 | 改变变量、跑通流程、动手操作、逐步推理 | 一页只承载一个机制，写明"改什么、看什么、看出什么" | 变成放题目的空壳 |
| 诊断页 | 诊断最可能的迷思概念、比较不同解释、检查迁移 | 干扰项必须来自真实迷思，反馈要能教会而不只是判错 | 变成测记忆的小测 |
| 项目/综合实践页 | 真正的多步探究、产出作品、公开展示 | 必须有多步、跨课时、有外部读者 | 把简单练习包成 PBL 架子 |

**标题规范**：标题写学生**发现什么/做出什么**，不写知识点名字。

- 好：「拖动倾角，看射程怎么变」「两份史料为什么说得不一样」「给校园开放日改写导览词」。
- 坏：「概念介绍」「知识讲解」「案例分析」「课堂总结」。

**学段差异**：本科重证据、论证与规范（能拿出理由，也知道规范边界在哪）；研究生重系统、模型、多源材料与有依据的价值判断（要能跨材料建模，并说明取舍理由）。

## 中国高校语境要点

- **课时换算**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。默认弧线按 90 分钟设计，各段时长写进任务书。
- **权重**：评价各项权重合计**恰好 100%**。权重未定时写「待考核方案确定」，合计栏写"待定"，不许填占位数字。
- **平时成绩**：情境化任务若计入平时成绩，须在**第一周**向学生公布评分规则并写明**申诉方式**；只记不评的证据也要在任务书里标明。
- **课程思政自然融入**：价值引领挂在情境本身真实的利害关系上（谁承担风险、谁受益、代价落在谁头上），写在情境卡的"谁受影响"与任务的"错误后果"里；**不写**"提升家国情怀"这类不可验收的表述。
- **毕业要求指标点编号**：由院系给定；**没给就留空标「待补充」，不自造**编号。
- **引用与教材**：引用一律 GB/T 7714 格式；教材 ISBN 查不到写「待补充」，不估不编。
- **班级规模与分组**：按学院实际；未给标「待补充」，并在任务书中按上限留出分组方案。

## 易错点

- ❌ 情境装饰化：开头讲完真实案例就再不提 → ✅ 每个活动与证据都能指出它用到了情境的哪一处利害或约束。
- ❌ 契约用弱动词（理解、掌握、培养思维） → ✅ 换成可见动词：标注、建模、比较、论证、检验、修订、设计、决策、创作、呈现。
- ❌ 证据与活动不同源（活动做 A，评价考 B） → ✅ 证据对照表逐行核对，任务产出本身就是评分对象。
- ❌ 干扰项凭空编造 → ✅ 干扰项来自真实迷思概念，并写明"反馈要教会什么"。
- ❌ 标题写成知识点（概念介绍、案例分析、课堂总结） → ✅ 标题写学生发现什么 / 做出什么。
- ❌ 迁移任务是原题重做 → ✅ 换新案例或换条件，并写明迁移失败说明哪条能力没建立。
- ❌ 权重凑整（无依据地凑成 100） → ✅ 权重有出处且合计恰好 100%；未定就写「待考核方案确定」。
- ❌ 编造毕业要求编号或教材 ISBN → ✅ 一律「待补充」并进需人工核验清单。
- ❌ 用学科发展史代替情境 → ✅ 情境页必须给出未解决问题，不是定义页。
- ❌ 一个情境塞多个问题 → ✅ 一个情境只服务一个未解决问题，其余下沉为子任务。

## 自检清单

- [ ] 情境造出了未解决问题，且不解决它后续学不下去
- [ ] 学习契约用可见动词，没有"理解 / 掌握"这类弱目标
- [ ] 情境贯穿三关：造问题、任务中真用到、评价换案例或换条件
- [ ] 中心任务是情境内的真实产出，不是若干练习题
- [ ] 每个活动都能指出对应证据，证据与活动同源
- [ ] 诊断页的干扰项来自真实迷思，反馈有教学意图
- [ ] 迁移任务换了新案例或新条件，不是原题重做
- [ ] 环节标题写的是学生发现 / 做出什么，不是知识点
- [ ] 载体选择有判据支撑，没有把简单练习包成项目
- [ ] 评价各项权重合计恰好 100%，或明确写「待考核方案确定」
- [ ] 计入平时成绩的任务已在第一周公布规则与申诉方式
- [ ] 课程思政挂在真实利害关系上，无不可验收的口号
- [ ] 毕业要求编号、教材 ISBN、案例来源等外部事实均未编造，未知项写「待补充」
- [ ] 输出含需人工核验清单，且清单可被逐项销账
