# 分层任务与支架设计

## 这个技能解决什么

一节课布置一份任务，全班一起做。结果是两极分化：前排几个学生五分钟就做完了，
开始发呆；后排一半学生卡在第一步，抄着做。课后教师说"这个任务难度不适合我们班"，
但下节课还是同样的任务、同样的难度。

常见的两种应对都不解决问题：一是**加量**——给快的学生多加两题，结果是把任务变成刷题；
二是**分层降低要求**——给慢的学生换成更简单的题，于是慢的学生永远没碰过这门课
真正要练的那个动作，课程目标对他等于不存在。

分层的正确做法是**分支架，不分内容和标准**：所有学生做同一件事、同一份产出，
区别只在于"在动手前获得多少支持、以及允许做到哪一步"。支架是可撤的：
证据显示学生能独立做，就把支架撤掉。把这条做对，分层就不再是"照顾差生"，
而是教学脚手架的常规调度。

还有一个常被忽略的前提：**分档必须由数据决定，且必须能变**。
凭印象分一次然后固定一学期，分层就从教学设计变成了贴标签。

## 什么时候用 / 什么时候不用

**用**：
- 同一任务上，一部分学生独立完成、另一部分大面积卡住
- 有前测、随堂小测或已批作业的数据可用，想据此设计不同支架
- 需要在统一终结性考核的前提下，为不同起点的学生铺不同路径
- 想给学有余力的学生设计扩展任务，而不是简单加量

**不用**：
- 数据还不可信（样本太少、评分标准没统一）——先去诊断，见 `gap-analysis-from-student-work`
- 学生间差异主要来自出勤、作业抄袭等非学习因素（那是管理问题，不是教学设计问题）
- 需要的是把一个大目标拆小（那是 `competency-unpacker`）
- 课程已没有统一的共同核心可保留（先做 `backwards-design-unit-planner`）

## 输入

**必填**（缺任一项先出草稿并把假设标出来）：
1. 学生数据：前测成绩分布、错题分布、已批作业的错误类型（写明样本与时间）
2. 本次任务的原文要求（学生看到的版本）
3. 课时长度：45 分钟 / 2 学时连堂 90 分钟
4. 班级规模与可分组条件（人数、桌椅布局、是否分组）
5. 统一终结性考核的要求（哪些标准不因分层而变）

**选填**（没有就留空，写进"需人工核验清单"，**不许编**）：
6. 课程各项考核权重构成（用于合计 100% 校验）、教材版本与对应章节（ISBN 需真实）
7. 是否有实验/实践环节及其设备与分组限制
8. 毕业要求指标点编号（**用户没给就留空**）、学院学业预警的既有规定

## 执行步骤

1. **先把数据翻译成"错误模式"，而不是"分数段"。**
   分档依据必须是"学生卡在哪一步、错成什么样"，不是"这次考了多少分"；数据太薄（样本 < 10 份或只考了 1 道题）时不要分档，
   先补测或做一次错误编码（方法见 `gap-analysis-from-student-work`）。

2. **定共同核心。**
   明确所有学生都要完成的那部分：同一份产出、同一个核心动作、同一个评分标准。后进生被排除在共同核心之外，
   分层就变成了分流。

3. **设计三档支架，而不是三档任务。**
   **入口档**提供完整示例 + 部分完成的模板（关键第一步已给出，学生接着做）；
   **标准档**是完整任务、无示例；**扩展档**在同一任务上加"变式"——换数据、换情境、
   找反例、自己加一个条件。扩展档是**改任务参数**，不是"多给几道题"：
   加量增加的是工作量，不是挑战性。

4. **为每档写撤架条件。**
   撤架条件是可判定的证据，不是印象："能在不给模板的情况下独立完成变量识别并写出操作化方式"
   → 进入标准档。没有撤架条件的支架会变成永久拐杖。

5. **写匹配规则。**
   用数据判据自动配档，例如"第 3 类错误（把混淆当因果）在最近两次作业中出现 ≥2 次 → 入口档"。
   写不出判据就说明数据不支持分档。规则要写明复核频率（每 2–3 周一次）。

6. **留出"自选升档"通道。**
   学生可以凭一份自评和一次尝试申请进入更高一档，教师只需审核，不设排队。
   没有上行通道的分层会让学生把最低档当成自己的身份。

7. **排课堂时间盒。**
   45 分钟内同时运行三档的可行做法：共同核心（统一讲 + 共同例）→ 档位任务
   （分组进行，教师按撤架条件巡视）→ 出口条（exit ticket，每人写"我卡在哪一步"）→
   收束（暴露共同误解，集体处理）。入口档的教师巡视时间最多，
   安排在学生已经卡住 5 分钟之后，别提前占用。

8. **定公平性红线。**
   写明哪些东西不因分层而变：及格线、评分量规、终结性考核内容、毕业要求指标点、课程思政要求。
   分层只改支持方式，不改标准。分层数据用于**支持**（增加辅导、调整支架），
   不用于惩罚性用途（评优、奖学金、用人单位推荐），并把这一条写进给学生的说明里。

9. **做效果检验。**
   下一次同构任务（相同子目标、相近情境）上，看各档学生的表现是否上移。
   检验对象是"支架是否有效"，不是"学生是否听话"。
   若入口档连续两周没有上移，问题多半在支架设计，而不在学生。

10. **收口：列出不确定项。**
    数据样本量、误差来源等标「假设」；缺的事实信息（权重、ISBN、指标点、学院规定）标「待补充」。

## 中国高校语境要点

- **学时与时间盒**：1 学时 = 45 分钟；2 学时连堂 = 90 分钟。
  表 4 的时间盒按实际课时重排，90 分钟连堂的扩展段是"加练 + 展示"，
  不是把 45 分钟的内容拉长。课表上每 45 分钟要有一个可观察的学习动作。
- **大班现实**：60–120 人的课堂分组按 4–5 人一组设计，入口档以小组形式提供支架时，
  组内必须有明确角色（操作、记录、提问、汇报各一人），否则会出现"一人做、多人看"。
  分组名单不公开排名。
- **评价制度与红线**：分层只发生在**形成性评价**环节（随堂小测、课堂任务、阶段作业、discussion）；
  终结性考核（期末笔试/开卷/机考）内容、评分量规、及格线、等级切分点**不因分层而变**。
  权重构成必须写清且加总**恰好 100%**。
- **学业预警的关系**：学业预警是**结果提示**，分档是**教学过程工具**，两者不得共用一套标签。
  不要把"入口档"直接等同"预警学生"，也不要把分档结果直接作为预警触发或撤销的依据
  （除非院系明文规定，规定未提供就列入核验清单）。
- **数据使用边界**：分档数据用于安排支架与辅导，不进入评优、奖学金、用人单位推荐等评价性环节；对学生的说明里要写清这一点。
- **毕业要求支撑**：所有档位学生都要能触达同一组毕业要求指标点，只是路径与支架不同。
  指标点编号由院系给定，**没给就留空**，不要自造编号。
- **课程思政**：思政融入点放在**共同核心**中，不因档位而增减；分层不提供"思政免修"路径。
- **教材与参考书**：示例与模板要能指回教材对应章节，ISBN 需真实，查不到写「待补充」。
- **实验/实践环节**：实验课分组受设备与场地限制，分档体现在"先做哪一步"（如先做数据预处理模板），
  不体现在"少做几步"；注明实验学时数与考核占比。
- **跨专业与先修差异**：文理交叉、跨专业选课学生的先修差异要用前测单独识别，不要默认按行政班分组掩盖差异。

## 易错点

- ❌ 按分数段分档、每次布置不同的三份任务 → ✅ 按错误模式分档（分数是结果不是原因）；同一份任务，分的是支架与撤架条件
- ❌ 给慢的学生换更简单的题 → ✅ 核心动作不变，只在入口处给支持
- ❌ 扩展档 = 多加两道题 → ✅ 改任务参数（换情境、找反例、自设条件）
- ❌ 支架没有撤架条件、分档固定一学期 → ✅ 每档写明可判定的达标证据；每 2–3 周依新证据复核，并留自选升档通道
- ❌ 分层连带降低及格线、量规、毕业要求 → ✅ 标准不变，变的只是支持方式
- ❌ 把入口档学生等同于学业预警学生 → ✅ 教学过程工具与结果提示分开
- ❌ 数据只有一次小测就分档、编造权重与 ISBN → ✅ 样本太薄先补测；查不到写「待补充」并列入核验清单

## 自检清单

- [ ] 分档依据是错误模式，不是分数段，且写明了样本量与来源
- [ ] 所有学生做同一份产出、同一套标准，共同核心明确写出
- [ ] 每档都有撤架条件，匹配规则写明了判据、数据源、阈值、复核频率
- [ ] 留有自选升档通道及审核方式
- [ ] 课堂时间盒与实际课时（45 / 90 分钟）吻合，每段都有证据采集
- [ ] 及格线、量规、终结性考核、毕业要求指标点未因分层变动
- [ ] 分档数据的使用边界已写明，且不与学业预警混用
- [ ] 效果检验计划已排（下一次同构任务）
- [ ] 课程各项权重加总 = 100%
- [ ] 指标点编号、ISBN、学院规定等事实项：真实或已列入待补充，无编造

## 交叉技能

- 错误模式的系统诊断 → `gap-analysis-from-student-work`、`error-analysis-protocol`
- 目标先拆成可教可评的子目标 → `competency-unpacker`
- 共同核心与目标对齐 → `backwards-design-unit-planner`
- 支架（示例—部分完成）序列设计 → `worked-example-fading-designer`
- 课堂追问与出口条 → `checking-for-understanding-protocol-designer`、`hinge-question-designer`
- 形成性评价闭环 → `formative-assessment-loop-designer`
- 学段与课时制度换算 → `he-context-adapter`
