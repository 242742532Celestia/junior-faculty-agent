# 课堂对话动作生成器

## 这个技能解决什么

课上抛出问题，全班沉默；改成"有没有人愿意说"，前排两三个人说完，剩下的人低头看手机，讨论在第三分钟就结束了。

讨论看起来很热闹，但每一轮都是重复上一轮的话，学生换了个说法，内容没前进；教师几次想问"为什么"，又怕让学生卡住，于是回到讲授。

教师的问题自带答案（"这个方案好不好？"），学生一律答"好"，看似一致，其实没有人真的比较过。

课快结束了，学生记住了几个结论，却说不清结论是怎么得出来的；教师想收一收，却发现对话没有可以收的口。

这个技能把一节课的对话拆成四类可排布的教师动作：定锚、开路、施压、收束。每类动作给触发条件、起手话术、追问句、退出条件和分钟级时间盒，让教师在课前就能排出整节课的对话脚本，而不是临场靠直觉。

## 什么时候用

**用**：

- 备课时要为某个概念、某段案例、某个争议点安排课堂对话，而不是单向讲授到底。
- 现场讨论"卡住了"或"绕圈了"，需要立刻判断下一步该做哪类动作。
- 同一内容连续几届学生都似懂非懂，需要换一种对话推进方式。
- 教师要训练学生回答质量（不是要正确答案，而是要回应别人、给出理由）。

**不用**：

- 需要的是事实核查、计算、公式推导——那是讲授与练习的事。
- 学生尚未具备讨论所需的前置知识（这时对话只会变成表态），先用讲解补齐。
- 课堂目标是传授统一的操作步骤，按部就班的演示更有效。
- 面向大规模班次（>120 人）的即时互动，需要另做组织设计。

## 输入

**必填**：

1. 教学目标一句话（学生下课时应该能做到什么）。缺省从该节课的教学目标直接摘取，并在输出中标注为假设。
2. 目标概念或争议点（本节课要通过对话搞清楚的那件事）。缺省按"教学目标中的核心概念"处理。
3. 可用对话时间（分钟）。缺省按单次课 45 分钟中的 12–18 分钟对话段处理。
4. 班级规模与可分组条件。缺省按 30–45 人、可自由移动分组处理。

**可选**：

5. 学生先备知识状况（已读材料、已做前置任务）。缺省按"概念刚讲完、尚无独立经验"处理。
6. 座位形式（固定座位 / 可移动 / 阶梯教室）。缺省按固定座位处理，并在动作卡里写明可移动时的变体。
7. 该节课是否需要留下书面产出（讨论结论是否要进入作业或随堂记录）。缺省按"需要一份全班可见的结论清单"处理。
8. 课程是否要求课程思政自然融入。缺省按"在价值取舍类追问处融入，不另设环节"处理。

## 执行步骤

1. **把教学目标改写成对话要解决的那一件事。** 用一句话写清"这节课靠对话要弄清楚 X"。写不出说明这节课不需要对话，直接做讲授设计。
2. **标记对话中的分歧点。** 在材料中找出至少一处学生几乎必然意见不一致的地方（两个做法、两种路径、两种定义、两个数据口径）。分歧点是转折问题与收束动作的挂载点。
3. **排布四类动作。** 一节课的对话通常按"定锚 → 开路 → 施压 → 收束"推进，定锚 1–2 次、开路 1–3 次、施压 2–4 次、收束 1 次（必须收束，不收束的讨论等于没上）。
4. **给每个动作写退出条件。** 退出条件是"看到什么就停止这个动作"，例如"学生已用本节课的术语复述自己的理由，就停止追问"。没有退出条件，动作会无限吞噬时间。
5. **压时间盒。** 单个动作 1–3 分钟：定锚 30–60 秒、开路 60–90 秒、施压 2–3 分钟（一次施压含 1–2 轮追问）、收束 2–3 分钟。总时长不得超过输入的对话时间上限。
6. **写话术并做反向测试。** 每个起手话术自问："学生能不能用一句话答完？"不能，就改短。同时检查是否把开放问题问成了封闭问题。
7. **准备接不住预案。** 对每个施压动作预写一句"学生答不出时的降级动作"（换更小的台阶、给出一个选项、暂时记录后继续），避免冷场。

| 学生答不出时的降级动作 | |

### 模板 B｜四类动作的选用判据

| 局面 | 该用 | 不该用 | 理由 |
|---|---|---|---|
| 全班沉默，无人开口 | 开路（先给 20 秒两人同时说，再请一人复述） | 反复重复原问题、点名开刀 | 沉默多是"没想好"或"怕说错"，重复提问只会加深 |
| 学生各说各话，话题漂移 | 定锚（把问题重述成一句可回答的话） | 定论式点评 | 漂移说明可回答的问句没被听见 |
| 学生答得笼统（"都行""差不多"） | 施压（要一个具体例子或一次比较） | 换更大的问题 | 笼统回答要具体化，不要升级难度 |
| 学生已用术语说出自己的理由 | 收束 | 继续追问 | 追问的目的是让理由变具体，不是延长讨论 |
| 出现明显对立 | 定锚 + 施压（把分歧写出来，问各自依据） | 让班委仲裁、投票了事 | 对立本身是资源，投票会把它耗掉 |
| 时间只剩 3 分钟 | 收束（模板 C 直接产出结论清单） | 开新的议题 | 结束要留结论，不留悬念 |

### 模板 C｜追问三层与时间盒（每个施压卡都要填满三层）

| 层级 | 目的 | 句式骨架 | 时长 |
|---|---|---|---|
| 第 1 层 起始问 | 把当前话题变成一个可回答的问题 | "关于 X，你的判断是……，理由是……？" | 30–60 秒 |
| 第 2 层 追问 | 逼出理由的细节（具体化） | "你说的这个'更合适'，具体是指哪一点比另一种更好？" | 60–120 秒 |
| 第 3 层 收敛 | 逼出可迁移的条件或边界 | "这个判断在什么条件下会不成立？" | 60–90 秒 |

规则：第 2 层未出现可观察的具体理由时，不得跳到第 3 层；第 3 层之后必须收束，不得再开第 4 层。

|---|---|---|---|---|
| 定锚 | | | | |
| 开路 | | | | |
| 施压 | | | | |
| 收束 | | | | |
| 合计 | | | 100% | 全班发言人次 ≥ 学生总人数的 60% |

### 模板 E｜话术对照表（批改自己教案时逐条查）

| ❌ 容易写成这样 | 问题 | ✅ 改成这样 |
|---|---|---|
| "这个方案好不好？" | 封闭问题，只能得到"好" | "这个方案在成本、精度、风险三项里，哪一项最可能出问题？" |
| "大家有什么想法？" | 太宽，无人知道说什么 | "先各用一句话说：在这三个限制里，你最想放弃哪一个？" |
| "有没有不同意见？" | 制造表态压力 | "刚才的理由在什么情况下不成立？" |
| "我再问一遍" | 重复提问不是推进 | "刚才说的是结论，能给一个具体例子吗？" |
| "好的，非常好" | 表扬替代了追问 | "你说的这一点，和刚才 A 同学的说法冲突在哪？" |
| "这个我们下节课讲" | 把问题挂起，学生不再参与 | "这正是我们今天要弄清的地方，先记下来，待会儿再看。" |

## 中国高校语境要点

- **学时制**：一节课（45 分钟或 45×2）的对话段建议控制在 12–18 分钟；大班（≥80 人）建议不超过 12 分钟，并配一名巡场助教负责分组。
- **评价制度**：对话质量适合做过程性评价。建议把"课堂发言参与度"折算进过程性成绩（合计不超过 15%），把"对话结论清单"作为随堂小测的评分对象（10%）；终结性考核权重不变，合计仍须为 100%，以课程大纲为准。
- **毕业要求支撑**：对话输出对应毕业要求中"沟通表达""团队协作""终身学习"类指标点的支撑活动，引用本校指标点原文表述。
- **课程思政**：在"施压"类追问里自然融入价值取舍（例如"两种做法都站得住时你按什么排序，为什么"），把讨论落在专业伦理与社会责任上，不额外设"思政讨论"环节。
- **课堂纪律与设备**：大班教室需确认是否有分组讨论区或麦克风；无线麦数量不足时，开路动作改成"写纸条 + 同桌互读"，保证人人开口。
- **教材与参考书**：若引用课堂对话案例教材片段，须给出可核验书目信息（有 ISBN 写 ISBN，无则写"待补充"），不得编造 ISBN。

## 易错点

- ❌ 把"没人说话"当成学生没兴趣，直接讲答案 → ✅ 先用开路动作（两人同时说 20 秒再复述），沉默常常是没准备，不是没兴趣。
- ❌ 追问没有退出条件，讨论从 5 分钟拖到 20 分钟 → ✅ 每张施压卡写死可观察的退出条件，时间到即收。
- ❌ 第 2 层还没问出具体理由就跳到"那你觉得该怎么办" → ✅ 顺序固定：理由 → 例子 → 边界，跳步会让回答空转。
- ❌ 用"有没有不同意见"制造表态压力 → ✅ 换成条件式提问（"这个判断在什么情况下不成立"），把表态变成推理。
- ❌ 全班一致时立刻收束，错失分歧 → ✅ 一致往往是没被追问；用"反例式"问题试一次再收。
- ❌ 每个动作都追求"漂亮答案" → ✅ 对话动作的目的是让理由变得具体和可辩护，学生的粗糙回答本身就是可加工的材料。
- ❌ 对话结束不给结论 → ✅ 收束是强制动作，产出必须是写在黑板/雨课堂/学习通上的结论清单。
- ❌ 发言量只集中在前排 → ✅ 模板 D 用"学生发言人次 ≥ 总人数 60%"做硬指标，达不到就改动作类型。

- [ ] 标出了至少一处必然分歧点
- [ ] 每个动作都归入定锚 / 开路 / 施压 / 收束四类之一
- [ ] 每个动作都有可观察的退出条件
- [ ] 每个施压动作都填满了起始问、追问、收敛三层
- [ ] 第 2 层未达标准时没有跳过到第 3 层
- [ ] 每个动作写好了"学生答不出"的降级动作
- [ ] 单个动作 1–3 分钟，总时长不超过给定对话时间
- [ ] 至少 1 次收束动作，并产出书面结论清单
- [ ] 话术自查通过：没有"好不好""大家有什么想法"这类空问
- [ ] 对话时长与课堂时间、期末考核权重已核对，合计 100%
- [ ] 已安排课后 5 分钟回填模板 F

## 交叉技能

→ `discussion-protocol-selector`（先选讨论协议，再往里填对话动作）
→ `hinge-question-designer`（为施压与收束动作提供转折问题）
→ `socratic-questioning-sequence-generator`（把施压动作展开成逐轮追问脚本）
→ `checking-for-understanding-protocol-designer`（把收束动作换成可判定的理解检查）
→ `formative-assessment-technique-selector`（为对话产出选配套的形成性评价形式）
→ `think-aloud-script-generator`（教师需要时把自己的推理说出来做示范）
