# 教学技能改写规格（原创版 skill 模板）

> 用途：把 `skills/` 下的 50 个教学技能从「上游 CC BY-SA 原文 + 适配段」
> 改写为**本项目原创**的 MIT 技能，使整个仓库只含 MIT + 原创内容，
> 不再承担 ShareAlike 的改编/署名义务。
>
> **唯一合法来源**：公开发表的教育研究文献 + 本项目自己的中国高校实践。
> **不是**来源：上游 SKILL.md 的正文、表格、示例、措辞。

---

## 一、clean-room 铁律

1. **不逐句改写上游**。"同义替换"仍然是改编，仍然受 SA 约束。
   正确做法是：先写下**这个方法在教育学里到底是什么**（从文献出发），
   再用自己的结构与语言组织。
2. **不复制上游的表格结构、agent 列表、示例题目、章节顺序**。
   上游的"具体表达"受著作权保护；"方法本身"（如逆向设计三段）不受保护。
3. **不保留上游的 `skill_id` 字段**。留着它就是在声明"这是上游的改编版"，
   应当移除。溯源信息移到 `references/third-party-provenance.md`
   （说明"曾参考过哪些来源、方法论依据哪些文献"），不放在技能正文里。
4. **先写方法，再写模板**。写"这个技能解决什么"时，脑子里应该是
   Biggs / Black & Wiliam / Sweller / Hattie 这类文献，不是上游文本。
5. **改写后必须跑相似度检查**（`scripts/verify_rewrite.py`）：
   与上游原文的 8-gram Jaccard 相似度 < 0.10，长行重合 < 5%。
   超标 = 改得不够干净，重写。

---

## 二、标准结构（每个技能都长这样）

```markdown
---
name: <kebab-case 技能名>
description: <一句话中文说明 + 触发词，150 字以内>
license: MIT
metadata:
  domain: <所属教学域>
  version: "1.0"
  origin: 原创（方法论依据公开发表的教育研究文献）
---

# <中文标题>

## 这个技能解决什么
（3–6 行：具体的失败场景，不是抽象定义。让读者认出"这就是我上周遇到的事"）

## 什么时候用 / 什么时候不用
（两条列表，各 2–4 条）

## 输入
（必填项逐条列，标注缺省处理方式；可选项另列）

## 执行步骤
（4–7 步。每步是动作，不是名词。可含"先做 X 草稿，再做 Y 校对"这类约束）

## 输出模板
（可直接填写的表格/清单。**这是技能的价值所在，必须具体**）

## 中国高校语境要点
（学时制、评价制度、课程思政、毕业要求支撑、教材 ISBN 核验等适用项）

## 易错点
- ❌ 错误做法 → ✅ 正确做法（每条都要能对照）

## 自检清单
- [ ] 可勾选的交付前检查项

## 交叉技能
（→ 指向本仓库内真实存在的技能名。**不得指向不存在或未安装的技能**）

## 方法论依据
（可公开引用的文献：作者 (年份) 标题。要真实存在，不许编造 DOI）
```

**篇幅参考**：120–220 行 / 8–15 KB。上游平均 19 KB；原创版不必更长，
但**输出模板必须比上游更具体**（这是替代价值的来源）。

## 三、按域的额外要求

| 域 | 额外要求 |
|---|---|
| 教学准备/设计（curriculum-*、explicit-instruction） | 必须产出**可交付的结构化表格**，不是建议 |
| 考核评价（curriculum-assessment） | 必须给**权重合计校验**与"评分等级可观察性"判据 |
| 学生支持（self-regulated-learning、student-learning） | 必须区分「教师布置」与「学生自选」，给出学习者视角的步骤 |
| 记忆与认知负荷 | 必须给**具体的负荷类型判断依据**，不写"要注意认知负荷"这类空话 |
| 提问与讨论 | 必须给**追问层级**（起始问→追问→收敛）与时间盒 |
| 通用学习设计（inclusive-design） | 必须给**可落地的改造动作**，而不是"提供多种选择" |
| 教研与专业发展（professional-learning） | 必须给**课堂观察记录格式**与**证据→结论的推断链** |

---

## 四、禁止事项

- ❌ 编造文献、DOI、ISBN、期刊分区
- ❌ 编造「学段/课时/评价制度」——按 `references/he-context-adapter.md` 的映射表
- ❌ 引用不存在或未安装的技能（`scripts/verify_repo.py` 会查）
- ❌ 把"教师自己判断"包装成技能输出
- ❌ 声称覆盖某个能力格却没有可交付产出物

---

## 五、自检与验收

```bash
python scripts/verify_rewrite.py            # 结构 + 相似度（需 JFA_UPSTREAM 指向上游暂存）
python scripts/verify_repo.py                # 文档↔现实 + 矩阵 + 许可一致性
```
