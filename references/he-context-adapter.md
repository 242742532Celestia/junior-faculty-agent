# 高校语境适配表（K-12 → 中国高校）

上游教学技能（`GarethManning/education-agent-skills`，MIT）以英式 K-12 学段为默认语境。
本 Agent 面向**中国高校教师**，因此所有技能输入中的学段、术语、评价制度都按下表映射后再执行。
**映射不是翻译，是制度替换**——K-12 的 UK National Curriculum 体系、GCSE/A-Level、
Key Stage、班级制导师（form tutor）在中国高校不存在对应物，不要硬造。

## 五、中国高校特有的、必须补上的维度

上游技能完全不覆盖以下内容。产出教学文件时，**若用户所在院校有相关要求，必须主动补齐**，
并在输出里标注这是高校语境补充项（不要伪装成上游方法的产物）：

1. **课程思政融入** —— 每章至少标注 1 个自然融入点，写明融入方式（案例/问题导入/价值讨论），
   不得生硬贴标签。
2. **毕业要求支撑** —— 每个课程目标对应到具体毕业要求指标点（工程教育认证/专业认证语境）。
3. **考核方式构成** —— 平时成绩 / 期末成绩的**百分比分配**必须给出且合计 100%。
4. **教材与参考书** —— 需给出 ISBN 或 ISBN 替代的信息（若无，从公开渠道检索真实书目信息，
   **不得编造 ISBN**）。
5. **实验/实践环节** —— 需注明学时数、分组方式、考核占比。
6. **教学工作量折算** —— 学时数与工作量的对应（若用户需要）。

## 课程目标—毕业要求—核心素养映射（高校侧）

上游技能产出课程目标之后，高校教师常要回答的一条链是：**课程目标 → 毕业要求 → 核心素养**。中国普通本科院校没有 K-12 那种法定统一的"核心素养"框架，因此下表第三列默认留空并标「学校自定口径，待学院确认」，由学院填写。

| 课程目标（可观察动词） | 毕业要求指标点（院系给定，没给留空） | 核心素养维度 | 支撑形式（哪次课 / 哪份作业） |
|---|---|---|---|
| 能够……（可观察动词） | | 学校自定口径，待学院确认 | 第 X 周第 Y 次课 + 第 Z 次作业 |
| | | | |

### 事实澄清

- 中国**普通本科院校**没有 K-12 那种法定统一的"核心素养"框架；**不得**套用或编造 K-12 课标的素养维度名称与条款号。
- 高校里对应的东西通常是学校 / 学院自定的表述：**专业核心能力、课程育人目标、学科核心素养、一课程一目标、毕业要求支撑矩阵**。
- 本表第三列默认标注「学校自定口径，待学院确认」并留空，**由学院填写**；本表**不替院系定义指标点体系**。
- 若院校确实有校级核心素养清单，**以校级清单为准**，填入清单原文的维度名称与编号；**编号必须由用户提供，不得推测**。
- 不得编造"毕业要求 3.2""核心素养 5 项"这类编号；不得把 K-12 的"文化基础 / 语言运用 / 思维发展 / 自主合作"等名称直接当作高校课程目标的素养维度。

### 占位维度（需按学校口径替换）

批判性思维 / 创新意识 / 工程伦理与社会责任 / 团队协作与沟通 / 终身学习与自我管理 / 跨学科整合 / 国际视野 / 数据素养与定量推理。

> 以上为常见维度举例，**不是**任何学校的官方清单；正式映射须以本校 / 本学院文件为准。该栏只作待填占位。

### 怎么填（三步）

1. **先向学院要毕业要求指标点原文** —— 指标点编号、表述、以及本课程对应哪几条，一律照抄原文；拿不到就在该格写「待补充」，不自行编号。
2. **再向学院要课程育人目标 / 核心素养口径** —— 用的是"专业核心能力"表还是"课程育人目标"表，维度名称与条目数由学院文件决定；没有校级清单时，第三列保持标注与留空。
3. **再逐条填支撑形式** —— 为每条课程目标指定至少一个落点（哪一周的课、哪份作业、哪次考核）；落点写不出来说明目标悬空，要么改目标，要么补任务。

## 六、绝对禁止

- ❌ 不要把上游技能里的 "Year 9 生物课自然选择单元" 例子照搬给中国高校教师。
  例子可以保留作方法演示，但**主产出必须是用户自己的课程内容**。
- ❌ 不要把 K-12 的 band/tier 评分体系当成中国高校的及格线。
- ❌ 不要为了"看起来像中国高校"而编造：ISBN、学分号、毕业要求编号、参考文献、
  期刊分区、政策文件编号。**查不到就写"待补充"**。
- ❌ 不要输出英文界面词（formative/summative/rubric）而不给中文对应；
  正文用中文，术语首次出现时中英并列（形成性评价 / formative assessment）。
