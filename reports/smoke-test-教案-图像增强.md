## 二、教学目标

采用可观察行为动词；编号 T1–T5 对应用户给出的课程目标 G1–G3。

| 编号 | 本次课目标（可检验） | 对应课程目标 |
|---|---|---|
| **T1** | 能写出灰度线性变换 `s = αr + β` 与 gamma 校正 `s = c·r^γ` 的映射关系，并预测各自施加后**原图直方图**将发生何种变化（平移 / 斜率改变 / 非线性重映射） | G1 |
| **T2** | 能说明直方图均衡化基于累积分布函数（CDF, Cumulative Distribution Function）的原理，并能指出**至少两种使其失效的图像情形**及其原因 | G1 |
| **T3** | 能解释均值滤波与中值滤波在噪声抑制上的差异根源，并能用**卷积定理**说明"空间域滤波核的傅里叶变换即频域滤波器 H(u,v)"，进而解释低通/高通滤波的作用机理 | G1 |
| **T4** | 面对给定的图像退化现象，能**从方法库中选出**合适增强方法，并按"退化现象 → 方法机理 → 预期效果 → 副作用"四段式完成论证 | G2 |
| **T5** | 能设计一条完整的图像增强处理流程（退化诊断 → 方法选型 → 参数设定 → 效果评估 → 边界与风险说明），其中效果评估须给出**可判定的依据**，不接受"看起来更好" | G3 |

**课程目标原文（【用户】提供，未改动）**
- G1：能解释各类图像增强方法的作用机理
- G2：能根据具体图像退化类型选择合适的增强方法并说明理由
- G3：能设计一个完整的图像增强处理流程

## 三、教学重点与难点

| 类型 | 内容 | 处理策略 |
|---|---|---|
| 重点 1 | 四类增强方法的**机理**与其在直方图/频谱上的可观测表征 | 每个方法一律按"映射关系 → 频谱/直方图上看到什么 → 什么时候失效"三步讲，不做纯公式推导 |
| 重点 2 | **由退化现象反推方法选型**并给出可检验的论证 | 全部教学活动以"退化现象"为主线串联，不按教材顺序平铺方法 |
| 难点 1 | 空间域与频域的**等价性**（学生多能背结论但不会用） | 专门安排 3 分钟做"3×3 均值核 ↔ 频域矩形低通"的当场推导（卷积定理） |
| 难点 2 | 直方图均衡化的**适用边界**与副作用 | 用"双峰/多峰图像"现场演示失败案例，结论从失败中长出来，而不是先给结论再举例 |
| 难点 3 | 从"看到退化"到"**论证方案**"的能力迁移（对应 G2/G3） | 课堂后半段设置同伴互评环节，必须按四段式口头陈述并互评 |

## 四、学情分析

| 类别 | 内容 | 对应教学应对 |
|---|---|---|
| 先备知识 | 灰度级与动态范围、二维离散傅里叶变换、卷积与相关、图像频谱的直观含义 | 直接调用，不重复讲授；导入用"频谱长什么样"做 1 分钟衔接（环节 5） |
| 可能障碍 1 | **混淆"变亮"与"增强对比度"**——加常量偏置 β 能提亮但直方图形状不变、对比度不变 | 环节 2 必做"直方图形状"对照板书；提问 1 专门探测该混淆 |
| 可能障碍 2 | **gamma 方向记反**（γ<1 提亮 vs γ>1 压暗） | 环节 3 用"0.5 → 0.25 的手算"锚定，不靠死记；单选样题把该错误设为干扰项 |
| 可能障碍 3 | 把直方图均衡化误解为"把像素值改成它出现的频次" | 环节 4 先推 CDF，再演示"输出直方图被拉平"，纠正直觉 |
| 可能障碍 4 | 只会背"空间频域等价"，不会在两域之间切换思考 | 环节 7 的 3 分钟当场推导（见难点 1） |
| 可能障碍 5 | 边界填充用补零，导致图像四周压暗，自己却归因于"算法有 bug" | 环节 6 明确演示三种 padding 差异，并让提问 2 覆盖 |
| 认知负荷预判 | 本章 4 类方法 × 2 个域，若按教材顺序平铺，学生在第 2 学时前段会出现"名词堆积、记不住对应关系" | **教学应对**：分两学时、以"退化现象"为主线；每讲完一类方法立即归位到板书右侧"退化→方法"对照列；每个方法只要求记住"1 条公式 + 1 个失效条件" |
| 分层需求 | 基础层：能复述机理并完成选型；进阶层：能论证边界并做参数对比实验 | 环节 8 同伴互评采用"基础层只做选型陈述，进阶层补做副作用论证"的双层任务卡（任务卡见第十节） |

## 七、板书设计

**形式**：主板书（保留至下课，供学生抄写）+ 副板书（临时演算，可擦）

```
┌──────────────────────────────────────────────────────────────────────┐
│ 主板书（保留区）                                                      │
│                                                                      │
│  【一】点运算            【二】直方图        【三】空间滤波 【四】频域   │
│                                                                      │
│  s = αr + β            s_k=(L-1)Σp_r        均值: 线性,模糊边缘        │
│    α→对比度             直方图拉平          中值: 非线性,抗离群      │
│    β→亮度(平移)          失效:双峰/多峰      □ □ □                   │
│                                                                      │
│  s = c·r^γ             ★CDF=查找表          3×3 均值核                │
│    γ<1 提亮暗部                              [1 1 1;1 1 1;1 1 1]        │
│    γ>1 压暗中调         ★边界:复制/镜像/补零                          │
│                         (补零→四周压暗)                               │
│                                                                      │
│  ★非线性:直方图横向重映射 (非仿射)                                     │
│                                                                      │
├──────────────────────────────────────────────────────────────────────┤
│ 副板书（擦除区）                                                      │
│  卷积定理: g=f*h  ⟷  G=F·H      3×3均值 ↔ 矩形低通(sinc²)             │
│  理想低通→振铃;工程用 Butterworth/高斯                                │
│  陷波滤波 → 去水平周期亮线                                             │
├──────────────────────────────────────────────────────────────────────┤
│ 右栏（贯穿两学时，最后回收成表）                                        │
│  退化现象                        选用方法                              │
│  ① 偏暗低对比   [图]             → 线性拉伸 / gamma / 直方图均衡化      │
│  ② 局部过曝     [图]             → 分段线性 / 局部直方图                 │

│  ④ 椒盐噪声     [图]             → 中值                                 │
│  ⑤ 水平亮线     [图]             → 频域陷波                             │
```

**板书演进顺序**【建议】
1. 环节 1：只画右栏，贴 4 张图，不写字（先留白）
2. 环节 2–4：左栏三块依次填满，γ 的手算写在副板书，**擦除**

## A.2 样题与评分细则（节选 4 题，用于示范命题口径）

> 以下样题的题干、选项、数据均为**教学设定情景**，不引用任何真实统计数字或公开数据集的测量值。

### 样题 1（单选｜G1｜理解｜中等｜2 分｜建议 2 分钟）

> 某灰度图像的直方图呈单峰且集中在低灰度区。若希望在**不产生明显灰阶断层**的前提下提亮暗部并提升中间调对比度，最合适的处理是（　）
>
> A. 加常量偏置 b 的线性变换　　B. 幂函数 s = c·r^γ，取 γ > 1
> C. 幂函数 s = c·r^γ，取 γ < 1　　D. 3×3 均值滤波

**答案：C**

**评分细则**：选 C 得 2 分；选 A/B/D 不得分（本题为单选，答案唯一）。

**干扰项对应的典型错误**
- A 选它 = 认为"加偏置能提对比度"（把亮度与对比度混淆）——本教案第二节识别的最高频障碍
- B 选它 = gamma 方向记反
- D 选它 = 把平滑滤波当成对比度增强手段

**讲评常见错误**：学生常在讲评时问"加 β 明明变亮了，为什么不对"——回到 Q1 的板书：直方图**形状不变**，对比度未变。

### 样题 2（简答｜G1｜理解｜中等｜6 分｜建议 8 分钟）

> 说明**均值滤波**与**中值滤波**在抑制噪声能力上的差异，并解释为什么在**椒盐噪声**下中值滤波明显优于均值滤波。

**参考答案（要点式）**
- 均值滤波是线性平滑：输出为邻域像素算术平均，对小幅、零均值扰动抑制效率高
- 中值滤波是非线性排序统计：输出为邻域排序后的中位数，**对离群点不敏感**
- 椒盐噪声是脉冲型离群点；均值把脉冲值摊进整个邻域，造成椒盐污染扩散；中值直接将其剔除

**评分细则**
| 采分点 | 分值 |
|---|---|
| 均值 = 线性平滑，对小幅扰动抑制效率高 | 2 |
| 中值 = 排序统计 / 非线性，对离群点不敏感 | 2 |
| 椒盐为脉冲型离群点；均值造成污染扩散，中值直接剔除 | 2 |
| **合计** | **6** |

**常见错误（讲评用）**
- 只答"中值保边缘更好"而不区分噪声类型 → 扣 2 分
- 认为中值对所有噪声都优于均值 → 扣 2 分
- 混淆"中值滤波是线性滤波器" → 扣 1 分
